  <section>
    <div className="rounded-2xl border border-cyan-500/20 bg-cyan-500/[0.05] p-6 text-[16px] leading-8 text-slate-300"><strong className="text-cyan-400">The Core Idea:</strong> There are two basic ways to find relevant text. <strong className="text-white">Sparse retrieval</strong> matches the exact words of the query, and <strong className="text-white">dense retrieval</strong> matches its meaning through embeddings. Each fails where the other succeeds: keywords miss paraphrases, and embeddings miss exact codes and rare names. <strong className="text-white">Hybrid search</strong> runs both and fuses their rankings, which is why it is the default in many production systems.</div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-blue-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">1. Beginner: Two Ways to Find Text</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>Picture two assistants. The first has the <strong className="text-white">index at the back of a book</strong>: give it a word and it lists every page that contains that exact word. The second is a <strong className="text-white">well-read colleague</strong> who understands what you mean even if you phrase it differently, but who may forget the exact spelling of a part number.</div>
      <div className="grid gap-5 md:grid-cols-2">
        <div className="rounded-xl border border-blue-500/25 bg-blue-500/[0.04] p-5">
          <div className="mb-2 font-semibold text-blue-300">Sparse retrieval</div>
          <div className="text-sm leading-7">Matches words. Fast, exact, easy to explain. Called sparse because each text is a huge vector that is mostly zeros, one slot per possible word.</div>
        </div>
        <div className="rounded-xl border border-violet-500/25 bg-violet-500/[0.04] p-5">
          <div className="mb-2 font-semibold text-violet-300">Dense retrieval</div>
          <div className="text-sm leading-7">Matches meaning. Uses embeddings, short vectors with every slot filled with a number. Called dense for that reason.</div>
        </div>
      </div>
      <div className="rounded-xl border border-blue-500/20 bg-blue-500/[0.05] p-5"><strong className="text-blue-300">Key point:</strong> neither approach is better in general. The real question is what your users ask: concepts and paraphrases, or exact names, codes and phrases.</div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-violet-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">2. Beginner: Sparse Retrieval and BM25</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>Keyword search is built on an <strong className="text-white">inverted index</strong>: for every word, a list of the documents that contain it. At query time the system looks up the query words and scores the documents that contain them. The standard scoring function is <strong className="text-white">BM25</strong>.</div>
      <div>BM25 rewards a document when it contains the query word often (term frequency), when that word is rare across the whole collection (inverse document frequency), and it avoids favoring long documents just for being long:</div>
      <div className="overflow-x-auto rounded-xl border border-white/10 bg-white/[0.03] p-5 text-center">$$\text{score}(q,d) = \sum_{t \in q} \text{IDF}(t) \cdot \dfrac{f(t,d)\,(k_1 + 1)}{f(t,d) + k_1 \left(1 - b + b \dfrac{\lvert d \rvert}{\text{avgdl}}\right)}$$</div>
      <div>Here $f(t,d)$ counts the word $t$ in document $d$, $\lvert d \rvert$ is the document length, avgdl is the average length, and $k_1$ and $b$ are tuning constants, commonly around 1.2 to 2 and 0.75. A rare word such as an error code gets a large IDF, so a single exact match can dominate.</div>
      <div className="rounded-xl border border-violet-500/20 bg-violet-500/[0.05] p-5"><strong className="text-violet-300">Strengths and weakness:</strong> excellent for exact terms, names, identifiers and quoted phrases, and it needs no model. Its weakness is <strong className="text-white">vocabulary mismatch</strong>: a query about a lost login finds nothing if the document says credentials recovery.</div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-emerald-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">3. Intermediate: Dense Retrieval</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>Dense retrieval embeds the query and the chunks and returns the nearest vectors. It bridges vocabulary gaps, because texts with the same meaning land close together.</div>

  <section>
    <h2 className="mb-6 border-l-4 border-orange-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">4. Intermediate: Hybrid Search and Reciprocal Rank Fusion</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>Hybrid search sends the query to both retrievers and merges the results. The difficulty is that their scores live on different scales: a BM25 score of 12 and a cosine similarity of 0.8 cannot be added meaningfully. A robust fix is to combine <strong className="text-white">ranks</strong> instead of scores. <strong className="text-white">Reciprocal Rank Fusion (RRF)</strong> gives every document a point value that shrinks with its rank in each list, then adds the points:</div>
      <div className="overflow-x-auto rounded-xl border border-white/10 bg-white/[0.03] p-5 text-center">$$\text{RRF}(d) = \sum_{r \in R} \dfrac{1}{k + \text{rank}_r(d)}$$</div>
      <div>Here $R$ is the set of ranked lists and $k$ is a smoothing constant, often 60. A document that appears near the top of both lists beats one that is first in only one. A document found by only one retriever still gets credit, so each method can rescue the other.</div>
      <div className="rounded-xl border border-orange-500/20 bg-orange-500/[0.05] p-5"><strong className="text-orange-300">Alternative:</strong> weighted score fusion first normalizes every score to a common range and then takes a weighted average. It can be tuned more finely, but it needs careful normalization and weights. RRF is popular because it works well with no tuning.</div>
    </div>
  </section>

  <section>
    <h2 data-type="code" className="mb-6 border-l-4 border-teal-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">7. Python Implementation: BM25, a Toy Dense Retriever and RRF</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>The program implements BM25 from scratch for the sparse side. For the dense side it uses a small table that maps words to shared concepts, so texts with different words but the same meaning get similar vectors. This stands in for a real embedding model. Reciprocal rank fusion then merges the two rankings. Three queries show the three situations from the lesson.</div>
      <div className="overflow-hidden rounded-2xl border border-white/10 bg-[#060911]">
        <div className="flex items-center justify-between border-b border-white/10 bg-white/[0.03] px-5 py-3"><span className="font-mono text-xs font-semibold text-teal-400">hybrid_retrieval.py</span><span className="font-mono text-[11px] text-slate-400">Python 3.10+ · Standard library only</span></div>
        <pre className="overflow-x-auto p-6 font-mono text-sm leading-7 text-slate-200">
          <code>
            <span className="block">import math</span>
            <span className="block">from collections import Counter</span>
            <span className="block">&nbsp;</span>
            <span className="block">documents = [</span>
            <span className="block">    (&quot;d1&quot;, &quot;how to reset your password using the account page&quot;),</span>
            <span className="block">    (&quot;d2&quot;, &quot;forgot login credentials recovery steps&quot;),</span>
            <span className="block">    (&quot;d3&quot;, &quot;error code E4021 means the payment failed&quot;),</span>
            <span className="block">    (&quot;d4&quot;, &quot;refund policy for returns within 30 days&quot;),</span>
            <span className="block">    (&quot;d5&quot;, &quot;billing and invoice questions&quot;),</span>
            <span className="block">]</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def tokens(text):</span>
            <span className="block">    cleaned = &quot;&quot;.join(ch if ch.isalnum() else &quot; &quot; for ch in text.lower())</span>
            <span className="block">    return cleaned.split()</span>
            <span className="block">&nbsp;</span>
            <span className="block text-slate-500"># ---- Sparse: BM25 on exact words ----</span>
            <span className="block">doc_tokens = [(doc_id, tokens(text)) for doc_id, text in documents]</span>
            <span className="block">avg_len = sum(len(t) for d, t in doc_tokens) / len(doc_tokens)</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def idf(word):</span>
            <span className="block">    n = sum(1 for d, t in doc_tokens if word in t)</span>
            <span className="block">    return math.log(1 + (len(doc_tokens) - n + 0.5) / (n + 0.5))</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def bm25(query, k1=1.5, b=0.75):</span>
            <span className="block">    scores = []</span>
            <span className="block">    for doc_id, t in doc_tokens:</span>
            <span className="block">        score = 0.0</span>
            <span className="block">        for word in set(tokens(query)):</span>
            <span className="block">            tf = t.count(word)</span>
            <span className="block">            if tf:</span>
            <span className="block">                score += idf(word) * tf * (k1 + 1) / (tf + k1 * (1 - b + b * len(t) / avg_len))</span>
            <span className="block">        scores.append((score, doc_id))</span>
            <span className="block">    return scores</span>
            <span className="block">&nbsp;</span>
            <span className="block text-slate-500"># ---- Dense (toy): words mapped to shared concepts ----</span>
            <span className="block">concepts = dict([</span>
            <span className="block">    (&quot;password&quot;, &quot;login&quot;), (&quot;credentials&quot;, &quot;login&quot;), (&quot;login&quot;, &quot;login&quot;), (&quot;account&quot;, &quot;login&quot;),</span>
            <span className="block">    (&quot;forgot&quot;, &quot;recover&quot;), (&quot;reset&quot;, &quot;recover&quot;), (&quot;recovery&quot;, &quot;recover&quot;), (&quot;forgotten&quot;, &quot;recover&quot;),</span>
            <span className="block">    (&quot;lost&quot;, &quot;recover&quot;), (&quot;access&quot;, &quot;login&quot;), (&quot;payment&quot;, &quot;money&quot;), (&quot;billing&quot;, &quot;money&quot;), (&quot;invoice&quot;, &quot;money&quot;), (&quot;refund&quot;, &quot;money&quot;),</span>
            <span className="block">])</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def concept_vector(text):</span>
            <span className="block">    return Counter(concepts[w] for w in tokens(text) if w in concepts)</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def cosine(a, b):</span>
            <span className="block">    dot = sum(a[k] * b[k] for k in a)</span>
            <span className="block">    na = math.sqrt(sum(v * v for v in a.values()))</span>
            <span className="block">    nb = math.sqrt(sum(v * v for v in b.values()))</span>
            <span className="block">    return dot / (na * nb) if na and nb else 0.0</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def dense(query):</span>
            <span className="block">    q = concept_vector(query)</span>
            <span className="block">    return [(cosine(q, concept_vector(text)), doc_id) for doc_id, text in documents]</span>
            <span className="block">&nbsp;</span>
            <span className="block text-slate-500"># ---- Hybrid: reciprocal rank fusion ----</span>
            <span className="block text-cyan-300">def ranking(scores):</span>
            <span className="block">    ordered = sorted(scores, key=lambda s: (-s[0], s[1]))</span>
            <span className="block">    return [doc_id for score, doc_id in ordered if score &gt; 0]</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def rrf(rankings, k=60):</span>
            <span className="block">    fused = Counter()</span>
            <span className="block">    for ranked in rankings:</span>
            <span className="block">        for position, doc_id in enumerate(ranked):</span>
            <span className="block">            fused[doc_id] += 1 / (k + position + 1)</span>
            <span className="block">    return [doc_id for doc_id, s in sorted(fused.items(), key=lambda x: (-x[1], x[0]))]</span>
            <span className="block">&nbsp;</span>
            <span className="block">for query in [&quot;I lost my access&quot;, &quot;E4021&quot;, &quot;forgot password&quot;]:</span>
            <span className="block">    sparse_rank = ranking(bm25(query))</span>
            <span className="block">    dense_rank = ranking(dense(query))</span>
            <span className="block">    print(&quot;Query:&quot;, query)</span>
            <span className="block">    print(&quot;  Sparse (BM25):&quot;, sparse_rank[:3])</span>
            <span className="block">    print(&quot;  Dense (toy)  :&quot;, dense_rank[:3])</span>
            <span className="block">    print(&quot;  Hybrid (RRF) :&quot;, rrf([sparse_rank, dense_rank])[:3])</span>
          </code>
        </pre>
      </div>
