    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>There are two ways to make an image, a table or a recording searchable.</div>
      <div className="grid gap-5 md:grid-cols-2">
        <div className="rounded-xl border border-blue-500/25 bg-blue-500/[0.04] p-5">
          <div className="mb-2 font-semibold text-blue-300">Convert to text</div>
          <div className="text-sm leading-7">Run OCR on scans, write captions for images, transcribe audio, turn tables into sentences. Then index the text like any other. Simple and works with any text retriever.</div>
        </div>
        <div className="rounded-xl border border-violet-500/25 bg-violet-500/[0.04] p-5">
          <div className="mb-2 font-semibold text-violet-300">Embed natively</div>
          <div className="text-sm leading-7">Use a multimodal embedding model that places images and text in one shared space, so a text query can retrieve a picture directly. Keeps visual detail that captions miss.</div>
        </div>
      </div>
      <div className="rounded-xl border border-blue-500/20 bg-blue-500/[0.05] p-5"><strong className="text-blue-300">Common practice:</strong> start with conversion to text, which is cheaper and easier to debug. Add native image embeddings when captions lose information your users ask about. Either way, store the original file and a locator with every record.</div>

    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div><strong className="text-white">Image RAG</strong> retrieves pictures, charts and diagrams. With the convert-to-text strategy, each image gets a caption and any text read from it, and those are searched. With native embeddings, the image vector is compared to the query vector directly.</div>
      <div><strong className="text-white">Multimodal RAG</strong> then sends the retrieved images, together with text, to a model that can read images, so it can answer questions about a chart or a screenshot. The same discipline applies: the answer should cite the image file, and a person should be able to open it.</div>
      <div className="rounded-xl border border-emerald-500/20 bg-emerald-500/[0.05] p-5"><strong className="text-emerald-300">Watch out:</strong> captions are written by a model and can be wrong or vague. Review a sample, and keep captions specific, for example bar chart of quarterly revenue with the Q3 growth value, not just a chart.</div>

    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div><strong className="text-white">Code RAG</strong> treats a function or class, not a fixed number of lines, as a chunk, because a cut through the middle of a function is meaningless. A syntax tree gives the exact boundaries. Each chunk should include the file path, the signature and the docstring, since developers search by what code does, and those parts describe it.</div>
      <div><strong className="text-white">Audio RAG</strong> begins with speech-to-text. The transcript is chunked by time or by topic, and each chunk keeps its start time and, when available, the speaker. Answers can then link to the exact moment of a recording. Transcription errors on names and technical words are common, so spell-check against a glossary when possible.</div>

  <section>
    <h2 data-type="code" className="mb-6 border-l-4 border-teal-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">7. Python Implementation: One Index for Code, Audio, Images and Tables</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>The program builds a single list of records from four kinds of content. Python code is split into functions with the standard ast module, and each function becomes a record from its name and docstring. An audio transcript becomes records with time stamps. Two images are represented by captions. Table rows become sentences. Every record has a modality, a locator and text, so one simple search can rank across all of them.</div>
      <div className="overflow-hidden rounded-2xl border border-white/10 bg-[#060911]">
        <div className="flex items-center justify-between border-b border-white/10 bg-white/[0.03] px-5 py-3"><span className="font-mono text-xs font-semibold text-teal-400">mixed_format_rag.py</span><span className="font-mono text-[11px] text-slate-400">Python 3.10+ · Standard library only</span></div>
        <pre className="overflow-x-auto p-6 font-mono text-sm leading-7 text-slate-200">
          <code>
            <span className="block">import ast</span>
            <span className="block">&nbsp;</span>
            <span className="block">stop_words = set([&quot;the&quot;, &quot;a&quot;, &quot;of&quot;, &quot;how&quot;, &quot;is&quot;, &quot;do&quot;, &quot;does&quot;, &quot;in&quot;, &quot;to&quot;, &quot;what&quot;, &quot;for&quot;, &quot;and&quot;, &quot;show&quot;, &quot;me&quot;])</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def words(text):</span>
            <span className="block">    cleaned = &quot;&quot;.join(ch if ch.isalnum() else &quot; &quot; for ch in text.lower()).split()</span>
            <span className="block">    return set(w[:-1] if w.endswith(&quot;s&quot;) and len(w) &gt; 3 else w for w in cleaned if w not in stop_words)</span>
            <span className="block">&nbsp;</span>
            <span className="block">records = []</span>
            <span className="block">&nbsp;</span>
            <span className="block text-slate-500"># 1. Code: one chunk per function, found with the ast module</span>
            <span className="block">source = chr(10).join([</span>
            <span className="block">    &quot;def refund_total(price, tax):&quot;,</span>
            <span className="block">    &apos;    &quot;&quot;&quot;Return the refund amount including tax.&quot;&quot;&quot;&apos;,</span>
            <span className="block">    &quot;    return price + tax&quot;,</span>
            <span className="block">    &quot;&quot;,</span>
            <span className="block">    &quot;def shipping_cost(weight):&quot;,</span>
            <span className="block">    &apos;    &quot;&quot;&quot;Return the shipping fee for a parcel weight in kilograms.&quot;&quot;&quot;&apos;,</span>
            <span className="block">    &quot;    return 5 + 2 * weight&quot;,</span>
            <span className="block">])</span>
            <span className="block">for node in ast.parse(source).body:</span>
            <span className="block">    if isinstance(node, ast.FunctionDef):</span>
            <span className="block">        doc = ast.get_docstring(node)</span>
            <span className="block">        records.append((&quot;code&quot;, &quot;function &quot; + node.name, node.name.replace(chr(95), &quot; &quot;) + &quot; &quot; + doc))</span>
            <span className="block">&nbsp;</span>
            <span className="block text-slate-500"># 2. Audio transcript: chunks keep their timestamps</span>
            <span className="block">transcript = [(0, &quot;Welcome to the product demo.&quot;), (45, &quot;Premium members get free shipping on every order.&quot;), (95, &quot;Refunds take five business days to arrive.&quot;)]</span>
            <span className="block">for start, text in transcript:</span>
            <span className="block">    stamp = str(start // 60).zfill(2) + &quot;:&quot; + str(start % 60).zfill(2)</span>
            <span className="block">    records.append((&quot;transcript&quot;, &quot;at &quot; + stamp, text))</span>
            <span className="block">&nbsp;</span>
            <span className="block text-slate-500"># 3. Images: searched through captions or text read from the image</span>
            <span className="block">images = [(&quot;chart_q3.png&quot;, &quot;bar chart showing quarterly revenue growth of 12 percent&quot;), (&quot;diagram_flow.png&quot;, &quot;diagram of the order shipping workflow&quot;)]</span>
            <span className="block">for name, caption in images:</span>
