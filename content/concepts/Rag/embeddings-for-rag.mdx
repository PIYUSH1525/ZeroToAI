  <section>
    <div className="rounded-2xl border border-cyan-500/20 bg-cyan-500/[0.05] p-6 text-[16px] leading-8 text-slate-300"><strong className="text-cyan-400">The Core Idea:</strong> Computers cannot compare meanings directly, but they can compare numbers. An <strong className="text-white">embedding</strong> is a list of numbers that represents the meaning of a piece of text, learned so that texts with similar meaning get similar numbers. RAG uses embeddings to find passages that mean the same thing as the question, even when they share none of its words.</div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-blue-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">1. Beginner: From Words to Coordinates</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>Think of a map. Every city has coordinates, and cities that are close together have similar coordinates. You can find the nearest city to any point just by comparing numbers. An embedding does the same for text: it gives every sentence a position in a space of meaning, and sentences about similar things sit near each other.</div>
      <div>A map needs 2 numbers per place. An embedding needs many more, often hundreds or thousands, because meaning has far more directions than north-south and east-west.</div>
      <div className="rounded-xl border border-blue-500/20 bg-blue-500/[0.05] p-5"><strong className="text-blue-300">Key point:</strong> an embedding is not a summary and not a code you can read. It is a position. Its only job is to make similar meanings close and different meanings far apart.</div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-violet-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">2. Beginner: Meaning Beyond Keywords</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>Keyword search looks for the same words. Embedding search looks for the same meaning. Consider a user asking about a puppy while the document talks about a young dog: the two texts share no important word, yet they are about the same thing.</div>
      <div className="overflow-x-auto rounded-xl border border-white/10">

            <tr><td className="px-4 py-3 font-semibold text-white">car will not start</td><td className="px-4 py-3">automobile engine troubleshooting</td><td className="px-4 py-3 text-rose-300">No shared words</td><td className="px-4 py-3 text-emerald-300">Strong match by meaning</td></tr>
          </tbody>
        </table>
      </div>
      <div>Embedding models learn this from huge amounts of text. They are trained so that texts used in similar contexts, or that answer one another, end up with nearby vectors.</div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-emerald-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">3. Intermediate: Embedding Space and Dimensions</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>The number of values in an embedding is its <strong className="text-white">dimension</strong>. Common models produce vectors with a few hundred to a few thousand dimensions. You cannot read a single dimension as a human concept like animal or vehicle. Meaning is spread across all of them together.</div>
      <div>More dimensions can store finer distinctions, but they cost memory and search time. Storage is easy to estimate. If each number takes 4 bytes (a 32-bit float), then $N$ chunks of dimension $d$ need about:</div>
      <div className="overflow-x-auto rounded-xl border border-white/10 bg-white/[0.03] p-5 text-center">$$N \times d \times 4 \text{ bytes}$$</div>
      <div>For example, 1,000,000 chunks with 768 dimensions need $1{,}000{,}000 \times 768 \times 4 = 3{,}072{,}000{,}000$ bytes, about 3 gigabytes, before any index structures. This is why dimension and storage format matter in production.</div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-orange-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">4. Intermediate: Similarity Intuition</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>Once texts are vectors, similarity is geometry. Two vectors pointing in nearly the same direction represent similar meanings. The most common score, <strong className="text-white">cosine similarity</strong>, measures the angle between vectors: 1 means same direction, 0 means unrelated, negative values mean opposite directions.</div>
      <div className="grid gap-5 md:grid-cols-3">
        <div className="rounded-xl border border-emerald-500/25 bg-emerald-500/[0.04] p-5">
          <div className="mb-2 font-semibold text-emerald-300">High score</div>

        </div>

          <div className="mb-2 font-semibold text-amber-300">Middling score</div>
          <div className="text-sm leading-7">Related but not the same, or only partly overlapping topics.</div>
        </div>
        <div className="rounded-xl border border-rose-500/25 bg-rose-500/[0.04] p-5">
          <div className="mb-2 font-semibold text-rose-300">Low score</div>
          <div className="text-sm leading-7">Probably unrelated. The retriever should not return this text.</div>
        </div>
      </div>
      <div className="rounded-xl border border-orange-500/20 bg-orange-500/[0.05] p-5"><strong className="text-orange-300">Careful:</strong> a similarity score is not a probability or a measure of correctness. A score of 0.8 from one model can mean something different from 0.8 from another, so thresholds must be tuned for each model.</div>
    </div>
  </section>

      <div>Real embeddings come from a trained neural network. To see the idea without any download, this program uses a tiny hand-made word vector table with four dimensions (animal, vehicle, food, technology).         <div className="flex items-center justify-between border-b border-white/10 bg-white/[0.03] px-5 py-3"><span className="font-mono text-xs font-semibold text-teal-400">toy_embeddings.py</span><span className="font-mono text-[11px] text-slate-400">Python 3.10+ · Standard library only</span></div>

          <code>
            <span className="block">import math</span>
            <span className="block">&nbsp;</span>
            <span className="block">word_vectors = dict([</span>
            <span className="block">    (&quot;cat&quot;, [0.9, 0.0, 0.0, 0.0]), (&quot;kitten&quot;, [0.85, 0.0, 0.0, 0.0]), (&quot;dog&quot;, [0.9, 0.0, 0.05, 0.0]), (&quot;puppy&quot;, [0.85, 0.0, 0.05, 0.0]),</span>
            <span className="block">    (&quot;car&quot;, [0.0, 0.9, 0.0, 0.1]), (&quot;automobile&quot;, [0.0, 0.9, 0.0, 0.1]), (&quot;engine&quot;, [0.0, 0.7, 0.0, 0.3]),</span>
            <span className="block">    (&quot;banana&quot;, [0.0, 0.0, 0.9, 0.0]), (&quot;apple&quot;, [0.0, 0.0, 0.9, 0.05]),</span>
            <span className="block">    (&quot;laptop&quot;, [0.0, 0.1, 0.0, 0.9]), (&quot;phone&quot;, [0.0, 0.1, 0.0, 0.9]),</span>
            <span className="block">])</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def embed(text):</span>
            <span className="block">    known = [word_vectors[w] for w in text.lower().split() if w in word_vectors]</span>
            <span className="block">    if not known:</span>
            <span className="block">        return [0.0, 0.0, 0.0, 0.0]</span>
            <span className="block">    return [sum(v[i] for v in known) / len(known) for i in range(4)]</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def cosine(a, b):</span>
            <span className="block">    dot = sum(x * y for x, y in zip(a, b))</span>
            <span className="block">    na = math.sqrt(sum(x * x for x in a))</span>
            <span className="block">    nb = math.sqrt(sum(y * y for y in b))</span>
            <span className="block">    if na == 0 or nb == 0:</span>
            <span className="block">        return 0.0</span>
            <span className="block">    return dot / (na * nb)</span>
            <span className="block">&nbsp;</span>
            <span className="block">documents = [</span>
            <span className="block">    &quot;the kitten sleeps&quot;,</span>
            <span className="block">    &quot;an automobile engine&quot;,</span>
            <span className="block">    &quot;a ripe banana&quot;,</span>
