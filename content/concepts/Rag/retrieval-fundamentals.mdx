  <section>
    <h2 className="mb-6 border-l-4 border-blue-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">1. Beginner: What Retrieval Is</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div><strong className="text-white">Retrieval</strong> takes a query and returns the chunks from the knowledge base that are most likely to help answer it. It is the librarian of the RAG system: it does not write answers, it fetches the right pages.</div>
      <div className="grid gap-5 md:grid-cols-3">
        <div className="rounded-xl border border-blue-500/25 bg-blue-500/[0.04] p-5">
          <div className="mb-2 font-semibold text-blue-300">Input</div>
          <div className="text-sm leading-7">A user question, often transformed or rewritten first.</div>
        </div>
        <div className="rounded-xl border border-violet-500/25 bg-violet-500/[0.04] p-5">
          <div className="mb-2 font-semibold text-violet-300">Process</div>
          <div className="text-sm leading-7">Score every candidate chunk, or the promising ones, against the query.</div>
        </div>
        <div className="rounded-xl border border-emerald-500/25 bg-emerald-500/[0.04] p-5">
          <div className="mb-2 font-semibold text-emerald-300">Output</div>
          <div className="text-sm leading-7">A ranked list of chunks with scores and metadata.</div>
        </div>
      </div>
      <div className="rounded-xl border border-blue-500/20 bg-blue-500/[0.05] p-5"><strong className="text-blue-300">Why it is the bottleneck:</strong> the generator can only use what it is given. A perfect model with the wrong passages still answers wrongly or admits it does not know.</div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-violet-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">2. Beginner: Similarity Search and Top-k</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>In the simplest retriever the query is embedded, compared with every stored chunk vector, and the <strong className="text-white">k</strong> best-scoring chunks are returned. This number k is called <strong className="text-white">top-k</strong>.</div>
      <div className="overflow-x-auto rounded-xl border border-white/10">
        <table className="w-full text-left text-sm">
          <thead className="bg-white/[0.04] text-slate-200">
            <tr><th className="px-4 py-3">Choice</th><th className="px-4 py-3">Too small</th><th className="px-4 py-3">Too large</th></tr>
          </thead>
          <tbody className="divide-y divide-white/10">
            <tr><td className="px-4 py-3 font-semibold text-white">Value of k</td><td className="px-4 py-3 text-rose-300">The needed passage may be missed</td><td className="px-4 py-3 text-rose-300">Noise fills the prompt and costs more</td></tr>
            <tr><td className="px-4 py-3 font-semibold text-white">Typical starting range</td><td className="px-4 py-3">A few results</td><td className="px-4 py-3">Tens of results for later reranking</td></tr>
          </tbody>
        </table>
      </div>
      <div>A <strong className="text-white">score threshold</strong> adds a second control: results below a minimum similarity are dropped even if they are in the top k. This lets the system say it found nothing relevant instead of returning weak matches.</div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-emerald-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">3. Intermediate: From Candidates to Context</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>Real systems rarely go straight from search to prompt. They work as a funnel that starts wide and narrows. Early stages are cheap and favor not missing anything, later stages are precise but more expensive.</div>
      <div className="space-y-3">
        <div className="rounded-xl border border-white/10 bg-white/[0.03] p-4"><strong className="text-emerald-300">Stage 1, candidate retrieval.</strong> Fetch a generous set, for example the top 30 to 100 chunks, using fast similarity search.</div>
        <div className="rounded-xl border border-white/10 bg-white/[0.03] p-4"><strong className="text-emerald-300">Stage 2, filtering.</strong> Remove chunks that break rules such as wrong date, status or permission.</div>
        <div className="rounded-xl border border-white/10 bg-white/[0.03] p-4"><strong className="text-emerald-300">Stage 3, reranking.</strong> Re-score the survivors with a more accurate model and keep the best few.</div>
        <div className="rounded-xl border border-white/10 bg-white/[0.03] p-4"><strong className="text-emerald-300">Stage 4, context selection.</strong> Choose, order and trim the final passages to fit the prompt budget.</div>
      </div>
      <div>The next lessons in this phase cover each stage in turn.</div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-orange-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">4. Intermediate: Recall vs Precision</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>Two simple questions describe how good a ranked list of $k$ results is. How much of what is good did we find? And how much of what we returned is good?</div>
      <div className="overflow-x-auto rounded-xl border border-white/10 bg-white/[0.03] p-5 text-center">$$\text{precision@}k = \dfrac{\text{relevant results in top } k}{k} \qquad \text{recall@}k = \dfrac{\text{relevant results in top } k}{\text{all relevant chunks}}$$</div>
      <div>They pull in opposite directions. Returning more results raises recall but usually lowers precision. In RAG the first stage should favor <strong className="text-white">recall</strong>, because a missed passage is lost forever, while later stages such as reranking restore <strong className="text-white">precision</strong>.</div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-cyan-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">5. Advanced: Measuring Retrieval Properly</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>Retrieval should be evaluated on its own, before the generator is involved. Build a small test set of real questions, each labeled with the chunks that answer it. Then compute three numbers.</div>
      <div className="overflow-x-auto rounded-xl border border-white/10">
        <table className="w-full text-left text-sm">
          <thead className="bg-white/[0.04] text-slate-200">
            <tr><th className="px-4 py-3">Metric</th><th className="px-4 py-3">Meaning</th><th className="px-4 py-3">Question it answers</th></tr>
          </thead>
          <tbody className="divide-y divide-white/10">
            <tr><td className="px-4 py-3 font-semibold text-white">Hit rate@k</td><td className="px-4 py-3">Share of questions with at least one relevant chunk in the top k</td><td className="px-4 py-3">How often does retrieval give the model a chance?</td></tr>
            <tr><td className="px-4 py-3 font-semibold text-white">Recall@k</td><td className="px-4 py-3">Share of all relevant chunks that appear in the top k</td><td className="px-4 py-3">Did we find everything needed?</td></tr>
            <tr><td className="px-4 py-3 font-semibold text-white">MRR</td><td className="px-4 py-3">Average of 1 divided by the rank of the first relevant result</td><td className="px-4 py-3">How near the top does the first good chunk appear?</td></tr>
          </tbody>
        </table>
      </div>
      <div className="overflow-x-auto rounded-xl border border-white/10 bg-white/[0.03] p-5 text-center">$$\text{MRR} = \dfrac{1}{\lvert Q \rvert} \sum_{i=1}^{\lvert Q \rvert} \dfrac{1}{\text{rank}_i}$$</div>
      <div>A question whose first relevant chunk is ranked 1, 1, 1 and 2 gives $\text{MRR} = (1 + 1 + 1 + 0.5) / 4 = 0.875$. When a metric is poor, look at the failures one by one: was the chunk badly cut, badly embedded, filtered out, or just outranked?</div>
    </div>
  </section>

    <h2 data-type="code" className="mb-6 border-l-4 border-teal-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">7. Python Implementation: Measuring Precision, Recall, Hit Rate and MRR</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>The program builds a tiny retriever that scores chunks by the number of shared words, using a stop word list and a crude plural rule. It then evaluates the retriever on four labeled questions for k from 1 to 4. Finally it reports the rank of the first relevant chunk for every question and the resulting MRR.</div>
      <div className="overflow-hidden rounded-2xl border border-white/10 bg-[#060911]">
        <div className="flex items-center justify-between border-b border-white/10 bg-white/[0.03] px-5 py-3"><span className="font-mono text-xs font-semibold text-teal-400">retrieval_metrics.py</span><span className="font-mono text-[11px] text-slate-400">Python 3.10+ · Standard library only</span></div>
        <pre className="overflow-x-auto p-6 font-mono text-sm leading-7 text-slate-200">
          <code>
            <span className="block">stop_words = set([&quot;how&quot;, &quot;do&quot;, &quot;i&quot;, &quot;is&quot;, &quot;my&quot;, &quot;the&quot;, &quot;to&quot;, &quot;a&quot;, &quot;when&quot;, &quot;can&quot;, &quot;are&quot;, &quot;your&quot;, &quot;from&quot;, &quot;long&quot;, &quot;does&quot;, &quot;fast&quot;])</span>
            <span className="block">&nbsp;</span>
            <span className="block">documents = [</span>
            <span className="block">    (&quot;d1&quot;, &quot;refund policy allows returns within 30 days&quot;),</span>
            <span className="block">    (&quot;d2&quot;, &quot;refund requests are processed within 5 business days&quot;),</span>
            <span className="block">    (&quot;d3&quot;, &quot;standard shipping takes 5 to 7 business days&quot;),</span>
            <span className="block">    (&quot;d4&quot;, &quot;express shipping takes 2 days&quot;),</span>
            <span className="block">    (&quot;d5&quot;, &quot;premium members get free shipping&quot;),</span>
            <span className="block">    (&quot;d6&quot;, &quot;support is open monday to friday&quot;),</span>
            <span className="block">    (&quot;d7&quot;, &quot;reset your password from the account page&quot;),</span>
            <span className="block">    (&quot;d8&quot;, &quot;passwords must contain 12 characters&quot;),</span>
            <span className="block">]</span>
            <span className="block">&nbsp;</span>
            <span className="block">tests = [</span>
            <span className="block">    (&quot;how long do refunds take&quot;, set([&quot;d2&quot;])),</span>
            <span className="block">    (&quot;how fast is shipping&quot;, set([&quot;d3&quot;, &quot;d4&quot;])),</span>
            <span className="block">    (&quot;how do i reset my password&quot;, set([&quot;d7&quot;])),</span>
            <span className="block">    (&quot;when can i call support&quot;, set([&quot;d6&quot;])),</span>
            <span className="block">]</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def stem(word):</span>
            <span className="block">    if word.endswith(&quot;s&quot;) and len(word) &gt; 3:</span>
            <span className="block">        return word[:-1]</span>
            <span className="block">    return word</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def terms(text):</span>
            <span className="block">    return set(stem(w) for w in text.lower().split() if w not in stop_words)</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def retrieve(question, k):</span>
            <span className="block">    q = terms(question)</span>
            <span className="block">    scored = [(len(q &amp; terms(text)), doc_id) for doc_id, text in documents]</span>
            <span className="block">    scored.sort(key=lambda s: (-s[0], s[1]))</span>
            <span className="block">    return [doc_id for score, doc_id in scored[:k]]</span>
            <span className="block">&nbsp;</span>
            <span className="block">print(&quot;k | precision@k | recall@k | hit rate@k&quot;)</span>
            <span className="block">for k in (1, 2, 3, 4):</span>
            <span className="block">    p = r = h = 0.0</span>
            <span className="block">    for question, relevant in tests:</span>
            <span className="block">        got = retrieve(question, k)</span>
            <span className="block">        found = relevant &amp; set(got)</span>
            <span className="block">        p += len(found) / k</span>
            <span className="block">        r += len(found) / len(relevant)</span>
            <span className="block">        h += 1 if found else 0</span>
            <span className="block">    n = len(tests)</span>
            <span className="block">    print(k, &quot;|&quot;, round(p / n, 2), &quot;|&quot;, round(r / n, 2), &quot;|&quot;, round(h / n, 2))</span>

            <span className="block">rr = 0.0</span>
            <span className="block">for question, relevant in tests:</span>
            <span className="block">    got = retrieve(question, len(documents))</span>
            <span className="block">    rank = min(got.index(d) for d in relevant) + 1</span>
            <span className="block">    rr += 1 / rank</span>
            <span className="block">    print(&quot;  &quot;, question.ljust(28), &quot;first relevant rank:&quot;, rank)</span>
            <span className="block">print(&quot;MRR:&quot;, round(rr / len(tests), 2))</span>

        </pre>
