  <section>
    <h2 className="mb-6 border-l-4 border-blue-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">1. Intermediate: RAG That Checks Itself</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>In a plain pipeline, a bad retrieval produces a bad answer, silently. The ideas in this lesson add three kinds of control.</div>
      <div className="grid gap-5 md:grid-cols-3">
        <div className="rounded-xl border border-blue-500/25 bg-blue-500/[0.04] p-5">
          <div className="mb-2 font-semibold text-blue-300">Corrective</div>
          <div className="text-sm leading-7">Grade the retrieved passages. If they are poor, fix the retrieval or look somewhere else.</div>
        </div>
        <div className="rounded-xl border border-violet-500/25 bg-violet-500/[0.04] p-5">
          <div className="mb-2 font-semibold text-violet-300">Self-reflective</div>
          <div className="text-sm leading-7">The system critiques its own retrieval decisions and its own draft answer, and retries if the critique fails.</div>
        </div>
        <div className="rounded-xl border border-emerald-500/25 bg-emerald-500/[0.04] p-5">
          <div className="mb-2 font-semibold text-emerald-300">Adaptive</div>
          <div className="text-sm leading-7">Choose the amount of retrieval effort per question: none, one search, or several steps.</div>
        </div>
      </div>
      <div className="rounded-xl border border-blue-500/20 bg-blue-500/[0.05] p-5"><strong className="text-blue-300">Shared principle:</strong> put a checkpoint where a silent failure could happen, and give the system an alternative action when the check fails.</div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-violet-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">2. Intermediate: Corrective RAG (CRAG)</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div><strong className="text-white">Corrective RAG</strong> adds a <strong className="text-white">retrieval evaluator</strong> between retrieval and generation. It scores how relevant the retrieved passages are to the question and sorts the result into one of three cases, each with its own action.</div>
      <div className="overflow-x-auto rounded-xl border border-white/10">
        <table className="w-full text-left text-sm">
          <thead className="bg-white/[0.04] text-slate-200">
            <tr><th className="px-4 py-3">Verdict</th><th className="px-4 py-3">Meaning</th><th className="px-4 py-3">Action</th></tr>
          </thead>
          <tbody className="divide-y divide-white/10">
            <tr><td className="px-4 py-3 font-semibold text-white">Correct</td><td className="px-4 py-3">The passages clearly answer the question</td><td className="px-4 py-3">Use them, optionally trimming irrelevant parts</td></tr>
            <tr><td className="px-4 py-3 font-semibold text-white">Ambiguous</td><td className="px-4 py-3">Partly relevant, not convincing</td><td className="px-4 py-3">Use with caution, or combine with another source</td></tr>
            <tr><td className="px-4 py-3 font-semibold text-white">Incorrect</td><td className="px-4 py-3">The passages do not help</td><td className="px-4 py-3">Discard them and fall back, for example to another index or a web search</td></tr>
          </tbody>
        </table>
      </div>
      <div>The evaluator can be a small trained model, a reranker score with thresholds, or a language model prompt. Its decisions are only as good as its calibration, so thresholds must be tuned on labeled examples.</div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-emerald-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">3. Intermediate: Self-RAG</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div><strong className="text-white">Self-RAG</strong> is a research approach in which the language model itself learns to make retrieval decisions and to critique them. Instead of always retrieving, it decides whether retrieval is needed. After retrieval it judges whether each passage is relevant, and after writing it judges whether its answer is supported by the passages and useful.</div>
      <div>In practice you can imitate this behavior with prompts and checks around a standard model: ask whether retrieval is needed, grade passages, draft, then verify. The trained version builds these judgments into the model, which can make them cheaper and more consistent.</div>
      <div className="rounded-xl border border-emerald-500/20 bg-emerald-500/[0.05] p-5"><strong className="text-emerald-300">Self-reflection loop:</strong> draft the answer, check that each claim is supported by the context, and if not, retry with a different query or different passages, up to a fixed number of attempts.</div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-orange-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">4. Intermediate: Adaptive RAG</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div><strong className="text-white">Adaptive RAG</strong> classifies the incoming question and routes it to the cheapest strategy that is likely to work.</div>
      <div className="overflow-x-auto rounded-xl border border-white/10">
        <table className="w-full text-left text-sm">
          <thead className="bg-white/[0.04] text-slate-200">

          </thead>
          <tbody className="divide-y divide-white/10">
            <tr><td className="px-4 py-3 font-semibold text-white">Needs no knowledge base</td><td className="px-4 py-3">Hello, or a general language question</td><td className="px-4 py-3">Answer directly without retrieval</td></tr>
            <tr><td className="px-4 py-3 font-semibold text-white">Simple factual</td><td className="px-4 py-3">What is the refund policy?</td><td className="px-4 py-3">One retrieval step</td></tr>
            <tr><td className="px-4 py-3 font-semibold text-white">Complex or multi-hop</td><td className="px-4 py-3">Who manages the team that owns billing?</td><td className="px-4 py-3">Several retrieval steps</td></tr>
          </tbody>
        </table>
      </div>
      <div>The router can be rules, a small classifier or a language model prompt. Routing saves money and time on easy questions and spends effort only where it helps. A wrong route is costly, though: sending a hard question down the cheap path produces a confident but incomplete answer.</div>
    </div>
  </section>

    <h2 data-type="code" className="mb-6 border-l-4 border-teal-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">7. Python Implementation: Routing, Grading, Fallback and a Retry Check</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>The program has an internal knowledge base and a separate set of fallback documents standing in for a web search. A router sends greetings straight to a reply, and everything else to retrieval. A grader turns the best match score into correct, ambiguous or incorrect, and each verdict triggers a different action: use the passage, warn about low confidence, fall back to the second source, or abstain. The last lines show a self-check: a draft answer is verified against the evidence, and a failing draft triggers a retry.</div>
      <div className="overflow-hidden rounded-2xl border border-white/10 bg-[#060911]">
        <div className="flex items-center justify-between border-b border-white/10 bg-white/[0.03] px-5 py-3"><span className="font-mono text-xs font-semibold text-teal-400">corrective_rag.py</span><span className="font-mono text-[11px] text-slate-400">Python 3.10+ · Standard library only</span></div>
        <pre className="overflow-x-auto p-6 font-mono text-sm leading-7 text-slate-200">
          <code>
            <span className="block">internal = [</span>
            <span className="block">    &quot;Refunds are issued within 5 business days of an approved return.&quot;,</span>
            <span className="block">    &quot;Standard shipping takes 5 to 7 business days.&quot;,</span>
            <span className="block">]</span>
            <span className="block">web = [</span>
            <span className="block">    &quot;The Atlas laptop launched in October 2026 with 32 GB of memory.&quot;,</span>
            <span className="block">]</span>
            <span className="block">stop_words = set([&quot;the&quot;, &quot;is&quot;, &quot;are&quot;, &quot;a&quot;, &quot;what&quot;, &quot;when&quot;, &quot;did&quot;, &quot;of&quot;, &quot;for&quot;, &quot;an&quot;, &quot;about&quot;, &quot;me&quot;, &quot;tell&quot;])</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def stem(word):</span>
            <span className="block">    return word[:-1] if word.endswith(&quot;s&quot;) and len(word) &gt; 3 else word</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def words(text):</span>
            <span className="block">    cleaned = &quot;&quot;.join(ch if ch.isalnum() or ch == &quot; &quot; else &quot; &quot; for ch in text.lower()).split()</span>
            <span className="block">    return set(stem(w) for w in cleaned if w not in stop_words)</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def best(query, docs):</span>
            <span className="block">    q = words(query)</span>
            <span className="block">    scored = [(len(q &amp; words(d)) / len(q), d) for d in docs]</span>
            <span className="block">    return max(scored)</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def route(query):</span>
            <span className="block">    greetings = [&quot;hello&quot;, &quot;hi&quot;, &quot;thanks&quot;]</span>
            <span className="block">    if query.lower().strip(&quot; ?!&quot;) in greetings:</span>
            <span className="block">        return &quot;no retrieval&quot;</span>
            <span className="block">    if &quot; and &quot; in query.lower():</span>
            <span className="block">        return &quot;multi-step&quot;</span>
            <span className="block">    return &quot;single retrieval&quot;</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def grade(score):</span>
            <span className="block">    if score &gt;= 0.5:</span>
            <span className="block">        return &quot;correct&quot;</span>
            <span className="block">    if score &gt;= 0.25:</span>
            <span className="block">        return &quot;ambiguous&quot;</span>
            <span className="block">    return &quot;incorrect&quot;</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def answer(query):</span>
            <span className="block">    path = route(query)</span>
            <span className="block">    if path == &quot;no retrieval&quot;:</span>
            <span className="block">        return path, &quot;-&quot;, &quot;Hello! How can I help?&quot;</span>
            <span className="block">    score, doc = best(query, internal)</span>
            <span className="block">    verdict = grade(score)</span>
            <span className="block">    if verdict == &quot;correct&quot;:</span>
            <span className="block">        return path, verdict, doc</span>
            <span className="block">    if verdict == &quot;ambiguous&quot;:</span>
            <span className="block">        return path, verdict, doc + &quot; (low confidence, please verify)&quot;</span>
            <span className="block">    web_score, web_doc = best(query, web)</span>
            <span className="block">    if web_score &gt;= 0.25:</span>
