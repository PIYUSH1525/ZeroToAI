    <h2 data-type="code" className="mb-6 border-l-4 border-teal-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">7. Python Implementation: Naive vs Advanced vs Modular with Ablations</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>The program defines five tiny documents, one of which is an outdated vacation policy, and four test questions with known answers. Naive RAG searches once with the raw question. The advanced and modular pipelines are built from two modules: a normalizer that expands abbreviations such as PTO and WFH, and a filter that keeps only active documents. Because the modules are plain functions in a list, the program can remove one at a time and measure the result.</div>
      <div className="overflow-hidden rounded-2xl border border-white/10 bg-[#060911]">
        <div className="flex items-center justify-between border-b border-white/10 bg-white/[0.03] px-5 py-3"><span className="font-mono text-xs font-semibold text-teal-400">rag_evolution.py</span><span className="font-mono text-[11px] text-slate-400">Python 3.10+ · Standard library only</span></div>
        <pre className="overflow-x-auto p-6 font-mono text-sm leading-7 text-slate-200">
          <code>
            <span className="block">rewrites = dict([(&quot;pto&quot;, &quot;paid time off&quot;), (&quot;wfh&quot;, &quot;work from home&quot;), (&quot;2fa&quot;, &quot;two factor authentication&quot;)])</span>
            <span className="block">stop_words = set([&quot;how&quot;, &quot;many&quot;, &quot;do&quot;, &quot;to&quot;, &quot;when&quot;, &quot;what&quot;, &quot;is&quot;, &quot;a&quot;, &quot;the&quot;])</span>
            <span className="block">&nbsp;</span>
            <span className="block">documents = [</span>
            <span className="block">    (&quot;d1&quot;, &quot;active&quot;, &quot;vacation policy 2025 employees receive 20 days of paid time off&quot;),</span>
            <span className="block">    (&quot;d2&quot;, &quot;superseded&quot;, &quot;vacation policy 2023 employees get 15 days of paid time off&quot;),</span>
            <span className="block">    (&quot;d3&quot;, &quot;active&quot;, &quot;work from home policy remote work two days per week&quot;),</span>
            <span className="block">    (&quot;d4&quot;, &quot;active&quot;, &quot;security policy enable two factor authentication&quot;),</span>
            <span className="block">    (&quot;d5&quot;, &quot;active&quot;, &quot;expense policy submit receipts within 30 days&quot;),</span>
            <span className="block">]</span>
            <span className="block">&nbsp;</span>
            <span className="block">tests = [</span>
            <span className="block">    (&quot;how many PTO days do employees get&quot;, &quot;d1&quot;),</span>
            <span className="block">    (&quot;WFH rules&quot;, &quot;d3&quot;),</span>
            <span className="block">    (&quot;2FA requirements&quot;, &quot;d4&quot;),</span>
            <span className="block">    (&quot;when to submit receipts&quot;, &quot;d5&quot;),</span>
            <span className="block">]</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def words(text):</span>
            <span className="block">    return &quot;&quot;.join(ch if ch.isalnum() or ch == &quot; &quot; else &quot; &quot; for ch in text.lower()).split()</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def top1(query, docs):</span>
            <span className="block">    q = set(w for w in words(query) if w not in stop_words)</span>
            <span className="block">    scored = [(len(q &amp; set(words(text))), doc_id) for doc_id, status, text in docs]</span>
            <span className="block">    scored.sort(key=lambda s: (-s[0], s[1]))</span>
            <span className="block">    return scored[0][1] if scored and scored[0][0] &gt; 0 else None</span>
            <span className="block">&nbsp;</span>
            <span className="block text-slate-500"># Naive RAG: one search with the raw question</span>
            <span className="block text-cyan-300">def naive(query, docs):</span>
            <span className="block">    return top1(query, docs)</span>
            <span className="block">&nbsp;</span>
            <span className="block text-slate-500"># Modules: each takes (query, docs) and returns (query, docs)</span>
            <span className="block text-cyan-300">def normalize(query, docs):</span>
            <span className="block">    return &quot; &quot;.join(rewrites.get(w, w) for w in words(query)), docs</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def only_active(query, docs):</span>
            <span className="block">    return query, [d for d in docs if d[1] == &quot;active&quot;]</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def run(modules, query, docs):</span>
            <span className="block">    for module in modules:</span>
            <span className="block">        query, docs = module(query, docs)</span>
            <span className="block">    return top1(query, docs)</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def score(label, fn):</span>
            <span className="block">    hits = sum(1 for question, gold in tests if fn(question) == gold)</span>
