  <section>
    <h2 className="mb-6 border-l-4 border-orange-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">4. Intermediate: Updates, Deletions, Freshness and Versioned Knowledge Bases</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div><strong className="text-white">Updates</strong> must replace the old chunks of a document, not add to them, or both versions will be retrieved. <strong className="text-white">Deletions</strong> must remove every chunk of the document, which matters for compliance when content has to disappear on request.</div>
      <div><strong className="text-white">Freshness</strong> is the delay between a change in the source and the new content being searchable. Define a target, such as new documents searchable within 15 minutes, measure it, and alert when it is missed.</div>
      <div className="space-y-3">
        <div className="rounded-xl border border-white/10 bg-white/[0.03] p-4"><strong className="text-orange-300">Snapshot.</strong> Treat each published state of the knowledge base as a named version.</div>
        <div className="rounded-xl border border-white/10 bg-white/[0.03] p-4"><strong className="text-orange-300">Build beside.</strong> Create a new index version next to the live one instead of editing the live index.</div>
        <div className="rounded-xl border border-white/10 bg-white/[0.03] p-4"><strong className="text-orange-300">Test.</strong> Run the golden set against the new version.</div>
        <div className="rounded-xl border border-white/10 bg-white/[0.03] p-4"><strong className="text-orange-300">Switch.</strong> Point the service at the new version, for example by moving an alias.</div>
        <div className="rounded-xl border border-white/10 bg-white/[0.03] p-4"><strong className="text-orange-300">Roll back.</strong> Keep the previous version available so you can switch back in seconds.</div>

    <h2 data-type="code" className="mb-6 border-l-4 border-teal-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">7. Python Implementation: Incremental Ingestion, Snapshots, Freshness and Fallback</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>The program keeps a small index of document ids with fingerprint, version and update day. An ingestion function compares each incoming document with the index and decides to add, update, skip or delete. After each run a snapshot of the index is saved. A freshness report flags documents older than 30 days, a rollback restores an earlier snapshot, and a fallback chain serves a query from keyword search when the primary retrieval raises a timeout.</div>
      <div className="overflow-hidden rounded-2xl border border-white/10 bg-[#060911]">
        <div className="flex items-center justify-between border-b border-white/10 bg-white/[0.03] px-5 py-3"><span className="font-mono text-xs font-semibold text-teal-400">production_patterns.py</span><span className="font-mono text-[11px] text-slate-400">Python 3.10+ · Standard library only</span></div>
        <pre className="overflow-x-auto p-6 font-mono text-sm leading-7 text-slate-200">
          <code>
            <span className="block">import hashlib</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def fingerprint(text):</span>
            <span className="block">    return hashlib.sha256(text.encode(&quot;utf-8&quot;)).hexdigest()[:6]</span>
            <span className="block">&nbsp;</span>
            <span className="block">index = dict()</span>
            <span className="block">snapshots = dict()</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def ingest(source_docs, today):</span>
            <span className="block">    actions = []</span>
            <span className="block">    for doc_id, text in source_docs:</span>
            <span className="block">        fp = fingerprint(text)</span>
            <span className="block">        if doc_id not in index:</span>
            <span className="block">            index[doc_id] = (fp, 1, today)</span>
            <span className="block">            actions.append(&quot;add &quot; + doc_id)</span>
            <span className="block">        elif index[doc_id][0] != fp:</span>
            <span className="block">            index[doc_id] = (fp, index[doc_id][1] + 1, today)</span>
            <span className="block">            actions.append(&quot;update &quot; + doc_id)</span>
            <span className="block">        else:</span>
            <span className="block">            actions.append(&quot;skip &quot; + doc_id)</span>
            <span className="block">    present = set(doc_id for doc_id, text in source_docs)</span>
            <span className="block">    for doc_id in list(index):</span>
            <span className="block">        if doc_id not in present:</span>
            <span className="block">            del index[doc_id]</span>
            <span className="block">            actions.append(&quot;delete &quot; + doc_id)</span>
            <span className="block">    return actions</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def take_snapshot(name):</span>
            <span className="block">    snapshots[name] = dict(index)</span>
            <span className="block">&nbsp;</span>
            <span className="block">print(&quot;Day 1 :&quot;, ingest([(&quot;a&quot;, &quot;refund policy v1&quot;), (&quot;b&quot;, &quot;shipping times&quot;), (&quot;c&quot;, &quot;old faq&quot;)], 1))</span>
            <span className="block">take_snapshot(&quot;kb-1&quot;)</span>
            <span className="block">print(&quot;Day 40:&quot;, ingest([(&quot;a&quot;, &quot;refund policy v1&quot;), (&quot;b&quot;, &quot;shipping times updated&quot;), (&quot;d&quot;, &quot;new support guide&quot;)], 40))</span>
            <span className="block">take_snapshot(&quot;kb-2&quot;)</span>
            <span className="block">&nbsp;</span>
            <span className="block">print(&quot;&quot;)</span>
            <span className="block">for doc_id in sorted(index):</span>
            <span className="block">    fp, version, updated = index[doc_id]</span>
            <span className="block">    age = 40 - updated</span>
            <span className="block">    flag = &quot;STALE&quot; if age &gt; 30 else &quot;fresh&quot;</span>
            <span className="block">    print(&quot;doc&quot;, doc_id, &quot;| version&quot;, version, &quot;| age&quot;, age, &quot;days |&quot;, flag)</span>
            <span className="block">&nbsp;</span>
