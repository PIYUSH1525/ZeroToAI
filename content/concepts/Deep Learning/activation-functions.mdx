  <section>
    <h2 className="mb-6 border-l-4 border-blue-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
      1. Beginner Foundations: What is an Activation Function and Why Do We Need It?
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        Inside every artificial neuron, the first step is a linear weighted sum: $z = \mathbf{w} \cdot \mathbf{x} + b$. That raw number $z$ (called the <strong className="text-white">pre-activation</strong> or <strong className="text-blue-300">logit</strong>) can be anything from $-\infty$ to $+\infty$.
      </div>
      <div>
        Before passing that signal to the next layer, the neuron feeds $z$ through an <strong className="text-cyan-300">Activation Function $\sigma(z)$</strong> to produce the final neuron output $a$:
      </div>
      <div className="my-6 rounded-2xl border border-blue-400/20 bg-blue-400/[0.04] px-6 py-8 text-center text-lg">
        <div>$$z = \mathbf{w} \cdot \mathbf{x} + b \quad \Longrightarrow \quad a = \sigma(z)$$</div>
      </div>
      <div className="grid gap-5 md:grid-cols-2">
        <div className="rounded-xl border border-rose-500/25 bg-rose-500/[0.04] p-6">
          <div className="mb-2 text-lg font-bold text-rose-300">Without Activation Functions (Linear Only)</div>
          <div className="mb-4 text-sm leading-relaxed text-slate-300">
            Multiplying two linear matrices together just produces another linear matrix: $\mathbf{W}_2(\mathbf{W}_1\mathbf{x}) = \mathbf{W}_{\text{combined}}\mathbf{x}$. No matter how many layers you stack, the network can only draw <strong className="text-white">flat straight lines</strong>!
          </div>
          <div className="rounded-lg border border-white/10 bg-slate-950 p-3 text-center font-mono text-xs text-rose-300">
            100 Linear Layers = 1 Single Linear Layer
          </div>
        </div>
        <div className="rounded-xl border border-emerald-500/25 bg-emerald-500/[0.04] p-6">
          <div className="mb-2 text-lg font-bold text-emerald-300">With Non-Linear Activation Functions</div>
          <div className="mb-4 text-sm leading-relaxed text-slate-300">
            Inserting a non-linear function $\sigma(\cdot)$ between layers breaks linearity: $\mathbf{W}_2 \, \sigma(\mathbf{W}_1\mathbf{x})$. Each layer can now <strong className="text-white">bend and fold</strong> the coordinate grid to fit any curve or boundary!
          </div>
          <div className="rounded-lg border border-white/10 bg-slate-950 p-3 text-center font-mono text-xs text-emerald-300">
            Universal Function Approximator ✓
          </div>
        </div>
      </div>
      <div className="rounded-xl border border-white/10 bg-white/[0.03] p-5">
        <div className="mb-2 font-bold text-white">
          Why Not Use a Simple Step Function ($0$ or $1$)?
        </div>
        <div className="text-sm leading-relaxed text-slate-300">
          Early 1950s Perceptrons used a hard step switch ($1$ if $z \ge 0$, else $0$). Because a flat step has a <strong className="text-rose-300">derivative (slope) of $0$ everywhere</strong>, Gradient Descent has no idea which way is downhill! Modern networks require <strong className="text-cyan-300">smooth, differentiable activation functions</strong> so backpropagation can compute gradients.
        </div>
      </div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-violet-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
      2. Beginner: Classical S-Curve Activations (Sigmoid &amp; Tanh)
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        The first generation of deep neural networks used smooth, S-shaped squashing functions that compress any input $z \in (-\infty, +\infty)$ into a fixed bounded range:
      </div>
      <div className="grid gap-5 md:grid-cols-2">
        <div className="rounded-xl border border-cyan-500/25 bg-cyan-500/[0.04] p-6">
          <div className="mb-1 flex items-center justify-between">
            <span className="font-bold text-cyan-300">1. Sigmoid (Logistic Function)</span>
            <span className="rounded bg-cyan-950/80 px-2 py-0.5 font-mono text-xs text-cyan-300">Range: (0, 1)</span>
          </div>
          <div className="mb-4 text-xs leading-relaxed text-slate-300">
            Squashes large negative numbers to $0$, zero to $0.5$, and large positive numbers to $1$. Ideal for turning a final output logit into a <strong className="text-white">binary probability</strong>!
          </div>
          <div className="rounded-lg bg-slate-950 px-4 py-4 text-center text-sm">
            <div>$$\sigma(z) = \dfrac{1}{1 + e^{-z}}$$</div>
            <div className="mt-3 text-xs text-slate-400">Derivative: $\sigma^\prime(z) = \sigma(z)\big(1 - \sigma(z)\big) \le 0.25$</div>
          </div>
        </div>
        <div className="rounded-xl border border-violet-500/25 bg-violet-500/[0.04] p-6">
          <div className="mb-1 flex items-center justify-between">
            <span className="font-bold text-violet-300">2. Tanh (Hyperbolic Tangent)</span>
            <span className="rounded bg-violet-950/80 px-2 py-0.5 font-mono text-xs text-violet-300">Range: (-1, +1)</span>
          </div>
          <div className="mb-4 text-xs leading-relaxed text-slate-300">
            A rescaled Sigmoid centered at $0$ ($\tanh(0) = 0$). Because its outputs average around zero (<strong className="text-white">zero-centered</strong>), it converges faster than Sigmoid in recurrent layers and LSTMs.
          </div>
          <div className="rounded-lg bg-slate-950 px-4 py-4 text-center text-sm">
            <div>$$\tanh(z) = \dfrac{e^z - e^{-z}}{e^z + e^{-z}}$$</div>
            <div className="mt-3 text-xs text-slate-400">Derivative: $\tanh^\prime(z) = 1 - \tanh^2(z) \le 1.0$</div>
          </div>
        </div>
      </div>
      <div className="rounded-2xl border border-rose-500/25 bg-rose-950/[0.15] p-6">
        <h3 className="mb-2 text-lg font-bold text-rose-300">Why Sigmoid and Tanh Fail in Deep Hidden Layers: Saturation!</h3>
        <div className="text-sm leading-relaxed text-slate-300">
          When $|z|$ is large (for example, $z = 10$ or $z = -10$), both Sigmoid and Tanh flatten out completely (<strong className="text-white">saturate</strong>), making their derivative $\sigma^\prime(z) \approx 0$. Even at its steepest center ($z = 0$), Sigmoid&apos;s maximum slope is only $0.25$. Multiplying $0.25 \times 0.25 \times \dots$ across $10$ layers via the Chain Rule crushes the gradient to zero (<strong className="text-rose-300">Vanishing Gradients</strong>), freezing early layers!
        </div>
      </div>
      <div className="mt-8 rounded-2xl border border-amber-500/25 bg-[#0A0D16] p-6 shadow-[0_0_25px_rgba(245,158,11,0.05)]">
        <div className="mb-2 flex items-center gap-2 text-xs font-bold uppercase tracking-widest text-amber-400">
          <span>⚡ Knowledge Check </span>
        </div>
        <div className="mb-5 text-base font-semibold text-white">
          Why is Sigmoid still widely used on the final output neuron of a Binary Classification model (like Spam vs. Not Spam), even though we avoid using it inside deep hidden layers?
        </div>
        <div className="grid gap-4 md:grid-cols-2">
          <details className="group">
            <summary className="flex cursor-pointer items-center justify-between rounded-xl border border-white/10 bg-white/[0.03] px-4 py-3 text-sm font-semibold text-slate-200 transition-colors hover:bg-white/[0.06] marker:content-['']">
              <span>A) Its output range (0, 1) directly represents a valid probability P(y = 1 | x)</span>
              <span className="text-amber-400 transition group-open:rotate-180">▼</span>
            </summary>
            <div className="mt-3 rounded-xl border border-emerald-500/30 bg-emerald-500/10 p-4 text-sm leading-relaxed text-slate-300">
              <strong className="mb-1 block text-emerald-400">✓ Correct!</strong>
              <span>On the final output layer, Sigmoid maps any real logit $z$ cleanly into a probability between $0$ and $1$, and when paired with Binary Cross-Entropy loss, the log cancels the exponential so the output gradient $\hat{y} - y$ never vanishes!</span>
            </div>
          </details>
          <details className="group">
            <summary className="flex cursor-pointer items-center justify-between rounded-xl border border-white/10 bg-white/[0.03] px-4 py-3 text-sm font-semibold text-slate-200 transition-colors hover:bg-white/[0.06] marker:content-['']">
              <span>B) Because Sigmoid can output negative numbers</span>
              <span className="text-amber-400 transition group-open:rotate-180">▼</span>
            </summary>
            <div className="mt-3 rounded-xl border border-rose-500/30 bg-rose-500/10 p-4 text-sm leading-relaxed text-slate-300">
              <strong className="mb-1 block text-rose-400">✕ Incorrect.</strong>
              <span>Sigmoid outputs strictly positive numbers in $(0, 1)$; it is Tanh that outputs numbers in $(-1, +1)$.</span>
            </div>
          </details>
        </div>
      </div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-emerald-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
      3. Intermediate: The ReLU Revolution &amp; Fixing &quot;Dying ReLUs&quot;
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        In 2010–2012 (AlexNet), researchers solved the vanishing gradient problem and unlocked modern Deep Learning with an astonishingly simple function called <strong className="text-emerald-300">ReLU (Rectified Linear Unit)</strong>: if the input is positive, pass it through unchanged; if it is negative, output $0$:
      </div>
      <div className="my-6 rounded-2xl border border-emerald-400/20 bg-emerald-400/[0.04] px-6 py-8 text-center text-lg">
        <div>$$\text{ReLU}(z) = \max(0, z) \quad \Longrightarrow \quad \text{ReLU}^\prime(z) = 1 \text{ (for } z \gt 0\text{)} \quad \text{or} \quad 0 \text{ (for } z \lt 0\text{)}$$</div>
      </div>
      <div className="grid gap-4 md:grid-cols-3">
        <div className="rounded-xl border border-emerald-500/25 bg-emerald-500/[0.05] p-5">
          <div className="mb-1 font-bold text-emerald-300">1. No Positive Saturation</div>
          <div className="text-xs leading-relaxed text-slate-300">
            For any $z \gt 0$, the derivative is a <strong className="text-white">constant $1.0$</strong>. Gradients flow backward through $100+$ layers without shrinking ($1 \times 1 \times 1 = 1$)!
          </div>
        </div>
        <div className="rounded-xl border border-cyan-500/25 bg-cyan-500/[0.05] p-5">
          <div className="mb-1 font-bold text-cyan-300">2. Blazing Fast on GPUs</div>
          <div className="text-xs leading-relaxed text-slate-300">
            Sigmoid and Tanh require expensive $e^z$ exponential hardware instructions. ReLU is just a simple <code>if z &gt; 0</code> comparison!
          </div>
        </div>
        <div className="rounded-xl border border-violet-500/25 bg-violet-500/[0.05] p-5">
          <div className="mb-1 font-bold text-violet-300">3. True Sparsity</div>
          <div className="text-xs leading-relaxed text-slate-300">
            Negative neurons output an exact $0.0$, allowing only a sparse, specialized subset of neurons to activate for any given input.
          </div>
        </div>
      </div>
      <h3 className="mt-8 text-xl font-bold text-white">The &quot;Dying ReLU&quot; Problem and Leaky ReLU / ELU</h3>
      <div>
        ReLU has one catch: for all negative inputs ($z \lt 0$), its output is $0$ and its <strong className="text-rose-300">slope is exactly $0$</strong>. If a large gradient nudge pushes a neuron&apos;s bias strongly negative so that $z \lt 0$ for every training sample, that neuron outputs $0$ forever, receives $0$ gradient forever, and permanently dies!
      </div>
      <div className="grid gap-5 md:grid-cols-2">
        <div className="rounded-xl border border-amber-500/25 bg-amber-500/[0.04] p-6">
          <div className="mb-2 font-bold text-amber-300">Leaky ReLU &amp; PReLU (Non-Zero Negative Slope)</div>
          <div className="mb-4 text-sm text-slate-300">
            Instead of flat zero for $z \lt 0$, Leaky ReLU gives negative inputs a tiny trickle slope $\alpha$ (typically $\alpha = 0.01$) so dead neurons can recover! In <strong className="text-white">PReLU</strong>, $\alpha$ is a learnable parameter.
          </div>
          <div className="rounded-lg bg-slate-950 p-3 text-center text-sm">
            <div>$$\text{LeakyReLU}(z) = \max(\alpha z, z)$$</div>
          </div>
        </div>
        <div className="rounded-xl border border-blue-500/25 bg-blue-500/[0.04] p-6">
          <div className="mb-2 font-bold text-blue-300">ELU (Exponential Linear Unit)</div>
          <div className="mb-4 text-sm text-slate-300">
            Uses a smooth exponential curve $\alpha(e^z - 1)$ for negative values, pushing average activations closer to zero while avoiding a sharp corner at $z=0$.
          </div>
          <div className="rounded-lg bg-slate-950 p-3 text-center text-sm">
            <div>$$\text{ELU}(z) = z \text{ (for } z \gt 0\text{)} \quad \text{or} \quad \alpha(e^z - 1) \text{ (for } z \le 0\text{)}$$</div>
          </div>
        </div>
      </div>
      <div className="mt-8 rounded-2xl border border-amber-500/25 bg-[#0A0D16] p-6 shadow-[0_0_25px_rgba(245,158,11,0.05)]">
        <div className="mb-2 flex items-center gap-2 text-xs font-bold uppercase tracking-widest text-amber-400">
          <span>⚡ Knowledge Check </span>
        </div>
        <div className="mb-5 text-base font-semibold text-white">
          You set your learning rate too high ($\text{lr} = 1.0$) while training a deep ReLU network. After a few steps, $60\%$ of your hidden neurons output $0.0$ for every single input in the dataset and never update again. What happened, and what is the easiest activation fix?
        </div>
        <div className="grid gap-4 md:grid-cols-2">
          <details className="group">
            <summary className="flex cursor-pointer items-center justify-between rounded-xl border border-white/10 bg-white/[0.03] px-4 py-3 text-sm font-semibold text-slate-200 transition-colors hover:bg-white/[0.06] marker:content-['']">
              <span>A) Dying ReLU problem; lower the learning rate or switch to Leaky ReLU / GELU</span>
              <span className="text-amber-400 transition group-open:rotate-180">▼</span>
            </summary>
            <div className="mt-3 rounded-xl border border-emerald-500/30 bg-emerald-500/10 p-4 text-sm leading-relaxed text-slate-300">
              <strong className="mb-1 block text-emerald-400">✓ Correct!</strong>
              <span>A huge gradient step pushed the weights into the $z \lt 0$ region where $\text{ReLU}^\prime(z) = 0$. Switching to Leaky ReLU ($\alpha = 0.01$) or GELU ensures a non-zero gradient so neurons can climb back out.</span>
            </div>
          </details>
          <details className="group">
            <summary className="flex cursor-pointer items-center justify-between rounded-xl border border-white/10 bg-white/[0.03] px-4 py-3 text-sm font-semibold text-slate-200 transition-colors hover:bg-white/[0.06] marker:content-['']">
              <span>B) Exploding gradients; switch all hidden layers to Sigmoid</span>
              <span className="text-amber-400 transition group-open:rotate-180">▼</span>
            </summary>
            <div className="mt-3 rounded-xl border border-rose-500/30 bg-rose-500/10 p-4 text-sm leading-relaxed text-slate-300">
              <strong className="mb-1 block text-rose-400">✕ Incorrect.</strong>
              <span>Constant $0.0$ outputs with zero updates is the signature of dead ReLU neurons, and replacing ReLU with Sigmoid in deep networks reintroduces severe vanishing gradients.</span>
            </div>
          </details>
        </div>
      </div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-orange-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
      4. Advanced: Modern Transformer &amp; LLM Activations (GELU, SiLU/Swish, and SwiGLU)
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        If you inspect the source code of <strong className="text-white">BERT, GPT-4, Claude, Gemini, or Llama-3</strong>, you will notice they do <em>not</em> use standard ReLU! Why? Because ReLU has a sharp, non-differentiable corner at $z = 0$ and completely zeroes out slightly negative values. Modern Large Language Models use <strong className="text-orange-300">smooth, probabilistic gated activations</strong>:
      </div>
      <div className="grid gap-5 md:grid-cols-3">
        <div className="rounded-xl border border-cyan-500/25 bg-cyan-500/[0.04] p-5">
          <div className="mb-1 font-bold text-cyan-300">1. SiLU / Swish (Vision &amp; Diffusion)</div>
          <div className="mb-3 text-xs leading-relaxed text-slate-300">
            Discovered by Google Brain: multiplies $z$ by its own Sigmoid gate! Smooth everywhere and allows small negative values (around $z \approx -1.2$) to pass through.
          </div>
          <div className="rounded-lg bg-slate-950 p-3 text-center text-xs">
            <div>$$\text{SiLU}(z) = z \cdot \sigma(z) = \dfrac{z}{1 + e^{-z}}$$</div>
          </div>
        </div>
        <div className="rounded-xl border border-violet-500/25 bg-violet-500/[0.04] p-5">
          <div className="mb-1 font-bold text-violet-300">2. GELU (GPT &amp; BERT Standard)</div>
          <div className="mb-3 text-xs leading-relaxed text-slate-300">
            <strong className="text-white">Gaussian Error Linear Unit:</strong> weights input $z$ by the Gaussian Cumulative Distribution $\Phi(z)$. Smoothly curves through zero with no sharp corner!
          </div>
          <div className="rounded-lg bg-slate-950 p-3 text-center text-xs">
            <div>$$\text{GELU}(z) = z \cdot \Phi(z) \approx z \cdot \sigma(1.702z)$$</div>
          </div>
        </div>
        <div className="rounded-xl border border-emerald-500/25 bg-emerald-500/[0.04] p-5">
          <div className="mb-1 font-bold text-emerald-300">3. SwiGLU (Llama-3, PaLM &amp; DeepSeek)</div>
          <div className="mb-3 text-xs leading-relaxed text-slate-300">
            <strong className="text-white">Swish-Gated Linear Unit:</strong> splits the layer into two parallel projections ($\mathbf{x}\mathbf{W}_{\text{gate}}$ and $\mathbf{x}\mathbf{W}_{\text{up}}$) and multiplies them element-wise!
          </div>
          <div className="rounded-lg bg-slate-950 p-3 text-center text-xs">
            <div>$$\text{SwiGLU}(\mathbf{x}) = \text{SiLU}(\mathbf{x}\mathbf{W}_g) \odot (\mathbf{x}\mathbf{W}_u)$$</div>
          </div>
        </div>
      </div>
      <div className="rounded-xl border border-white/10 bg-white/[0.03] p-5">
        <strong className="text-white">Why SwiGLU Dominates Modern LLMs:</strong> In standard ReLU or GELU, a neuron only gates based on its own single linear sum. In <strong className="text-emerald-300">SwiGLU</strong>, the model learns a dedicated <strong className="text-cyan-300">Gate Matrix $\mathbf{W}_g$</strong> that decides how much of the <strong className="text-violet-300">Content Matrix $\mathbf{W}_u$</strong> to let through via element-wise multiplication ($\odot$), consistently achieving lower perplexity per FLOP in Transformer pretraining!
      </div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-cyan-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
      5. Master Comparison: Choosing Hidden vs. Output Activations
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        In architecture design, you always make <strong className="text-white">two separate choices</strong>: which activation to put inside <strong className="text-cyan-300">Hidden Layers</strong> (to extract features) versus which activation to put on the <strong className="text-emerald-300">Final Output Layer</strong> (to match your target format):
      </div>
      <div className="my-6 overflow-x-auto rounded-2xl border border-white/10">
        <table className="w-full min-w-[760px] border-collapse text-left text-sm">
          <thead className="bg-white/[0.06] text-white">
            <tr>
              <th className="border-b border-white/10 px-5 py-4 font-semibold">Activation</th>
              <th className="border-b border-white/10 px-5 py-4 font-semibold">Output Range</th>
              <th className="border-b border-white/10 px-5 py-4 font-semibold">Vanishing Gradient?</th>
              <th className="border-b border-white/10 px-5 py-4 font-semibold">Where to Use It in Practice</th>
            </tr>
          </thead>
          <tbody className="text-slate-300">
            <tr className="border-b border-white/10">
              <td className="px-5 py-4 font-semibold text-emerald-300">ReLU</td>
              <td className="px-5 py-4 font-mono text-xs">$[0, +\infty)$</td>
              <td className="px-5 py-4 text-emerald-300">No (for $z \gt 0$)</td>
              <td className="px-5 py-4"><strong className="text-white">Default Hidden Layer</strong> for MLPs and CNNs.</td>
            </tr>
            <tr className="border-b border-white/10">
              <td className="px-5 py-4 font-semibold text-violet-300">GELU / SwiGLU</td>
              <td className="px-5 py-4 font-mono text-xs">$(-0.17, +\infty)$</td>
              <td className="px-5 py-4 text-emerald-300">No (Smooth Gate)</td>
              <td className="px-5 py-4"><strong className="text-white">Default Hidden Layer</strong> for Transformers, ViTs, and LLMs.</td>
            </tr>
            <tr className="border-b border-white/10">
              <td className="px-5 py-4 font-semibold text-amber-300">Leaky ReLU</td>
              <td className="px-5 py-4 font-mono text-xs">$(-\infty, +\infty)$</td>
              <td className="px-5 py-4 text-emerald-300">No (Never Dies)</td>
              <td className="px-5 py-4"><strong className="text-white">Hidden Layers</strong> in GAN discriminators and deep nets prone to dead neurons.</td>
            </tr>
            <tr className="border-b border-white/10">
              <td className="px-5 py-4 font-semibold text-cyan-300">Sigmoid</td>
              <td className="px-5 py-4 font-mono text-xs">$(0, 1)$</td>
              <td className="px-5 py-4 text-rose-300">Yes (Severe)</td>
              <td className="px-5 py-4"><strong className="text-white">Output Layer ONLY</strong> for Binary Classification &amp; Multi-Label Classification, or LSTM gates.</td>
            </tr>
            <tr className="border-b border-white/10">
              <td className="px-5 py-4 font-semibold text-pink-300">Softmax</td>
              <td className="px-5 py-4 font-mono text-xs">$(0, 1)$, $\sum p_k = 1$</td>
              <td className="px-5 py-4 text-emerald-300">No (with Cross-Entropy)</td>
              <td className="px-5 py-4"><strong className="text-white">Output Layer ONLY</strong> for Multi-Class Classification &amp; LLM next-token probabilities, plus Attention weights.</td>
            </tr>
            <tr>
              <td className="px-5 py-4 font-semibold text-slate-200">Linear (Identity)</td>
              <td className="px-5 py-4 font-mono text-xs">$(-\infty, +\infty)$</td>
              <td className="px-5 py-4 text-emerald-300">N/A</td>
              <td className="px-5 py-4"><strong className="text-white">Output Layer ONLY</strong> for Continuous Regression (predicting price, temperature).</td>
            </tr>
          </tbody>
        </table>

          <span>Activation functions introduce essential non-linearity between matrix multiplications; without them, any deep neural network collapses into a single linear matrix.</span>
        </div>
        <div className="flex items-start gap-3">
          <span className="mt-0.5 font-bold text-emerald-400">✓</span>
          <span>Sigmoid squashes values into $(0, 1)$ and Tanh squashes values into $(-1, +1)$, but both saturate at large $|z|$ values, causing vanishing gradients in deep hidden layers.</span>
        </div>
        <div className="flex items-start gap-3">
          <span className="mt-0.5 font-bold text-emerald-400">✓</span>
          <span>ReLU ($\max(0, z)$) solved vanishing gradients for positive inputs by maintaining a constant slope of $1.0$, becoming the default choice for MLPs and CNNs.</span>
        </div>
        <div className="flex items-start gap-3">
          <span className="mt-0.5 font-bold text-emerald-400">✓</span>
          <span>Leaky ReLU ($\max(\alpha z, z)$) fixes the &quot;Dying ReLU&quot; problem by providing a small non-zero slope (e.g., $\alpha = 0.01$) for negative inputs.</span>
        </div>
        <div className="flex items-start gap-3">
          <span className="mt-0.5 font-bold text-emerald-400">✓</span>
          <span>Modern Transformers and LLMs use smooth gated activations—specifically GELU ($z\Phi(z)$), SiLU/Swish ($z\sigma(z)$), and SwiGLU—for smoother optimization landscapes and stronger representation capacity.</span>
        </div>
        <div className="flex items-start gap-3">
          <span className="mt-0.5 font-bold text-emerald-400">✓</span>
          <span>Always match your final output layer activation to your loss function: Linear for Regression, Sigmoid for Binary/Multi-Label Classification, and Softmax for mutually exclusive Multi-Class Classification.</span>

      Common Mistakes
    </h2>
    <div className="rounded-2xl border border-rose-500/25 bg-rose-950/[0.15] p-6 sm:p-8">
      <div className="space-y-6">
        <div>
          <div className="mb-1.5 font-bold text-rose-400">
            ✕ Using Sigmoid in the hidden layers of a deep neural network.
          </div>
          <div className="text-sm leading-relaxed text-slate-300">
            Because Sigmoid outputs are not zero-centered and its maximum derivative is $0.25$, stacking Sigmoid hidden layers causes gradients to vanish rapidly. Use ReLU, Leaky ReLU, or GELU in hidden layers instead.
          </div>
        </div>
        <div>
          <div className="mb-1.5 font-bold text-rose-400">
            ✕ Putting ReLU on the final output layer when predicting unrestricted continuous numbers.
          </div>
          <div className="text-sm leading-relaxed text-slate-300">
            ReLU clips all negative outputs to $0.0$. If your target (such as temperature changes, financial returns, or normalized $Z$-scores) can be negative, a final ReLU makes negative predictions mathematically impossible!
          </div>
        </div>
        <div>
          <div className="mb-1.5 font-bold text-rose-400">
            ✕ Using Softmax for Multi-Label Classification where multiple classes can be true at once.
          </div>
          <div className="text-sm leading-relaxed text-slate-300">
            Softmax forces outputs to compete so their sum equals $1.0$. When multiple labels can co-occur in the same sample, use independent Sigmoid activations with <code>nn.BCEWithLogitsLoss()</code>.
          </div>
        </div>
        <div>
          <div className="mb-1.5 font-bold text-rose-400">
            ✕ Using an overly high learning rate with standard ReLU without gradient clipping.
          </div>
          <div className="text-sm leading-relaxed text-slate-300">
            A single huge gradient update can slam weights into the negative region for all training data, permanently killing a large fraction of your network&apos;s ReLU neurons.
          </div>
        </div>
