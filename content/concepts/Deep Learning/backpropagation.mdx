Backpropagation (short for &quot;Backward Propagation of Errors&quot;) is the algorithm that solves this Credit Assignment Problem—walking backward from the final Loss layer by layer using the Chain Rule so every single weight learns its exact share of the blame in a single pass.

  <section>
    <h2 className="mb-6 border-l-4 border-blue-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
      1. Beginner Foundations: The Credit Assignment Problem &amp; The Relay Race
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        Imagine a factory assembly line with three workers in a row: <strong className="text-cyan-300">Worker 1</strong> cuts the wood, <strong className="text-violet-300">Worker 2</strong> assembles the chair, and <strong className="text-emerald-300">Worker 3</strong> paints it. At the end of the line, the quality inspector measures the final product and finds an error (<strong className="text-rose-300">The Loss $L$</strong>).
      </div>
      <div>
        Who is to blame, and how should each worker adjust their work? We cannot just yell at Worker 3! Instead, the inspector tells Worker 3 how much the paint contributed to the error, Worker 3 passes the remaining blame back to Worker 2, and Worker 2 passes the blame back to Worker 1. That two-way process is how every neural network trains:
      </div>
      <div className="grid gap-5 md:grid-cols-2">
        <div className="rounded-xl border border-cyan-500/25 bg-cyan-500/[0.04] p-6">
          <div className="mb-2 text-lg font-bold text-cyan-300">1. The Forward Pass (Left to Right →)</div>
          <div className="mb-4 text-sm leading-relaxed text-slate-300">
            Input data $\mathbf{x}$ flows forward through every layer to produce a prediction $\hat{y}$ and measure the error $L(\hat{y}, y)$. Along the way, each layer <strong className="text-white">saves (caches) its intermediate activations</strong> in memory.
          </div>
          <div className="rounded-lg border border-white/10 bg-slate-950 p-3 text-center font-mono text-xs text-cyan-300">
            Input x → Layer 1 → Layer 2 → Prediction → Loss L
          </div>
        </div>
        <div className="rounded-xl border border-rose-500/25 bg-rose-500/[0.04] p-6">
          <div className="mb-2 text-lg font-bold text-rose-300">2. The Backward Pass (Right to Left ←)</div>
          <div className="mb-4 text-sm leading-relaxed text-slate-300">
            Starting at the Loss $L$, error signals (<strong className="text-white">gradients</strong>) flow backward from the output layer to the first layer, multiplying local slopes via the <strong className="text-white">Chain Rule</strong> to compute $\dfrac{\partial L}{\partial w}$ for every weight.
          </div>
          <div className="rounded-lg border border-white/10 bg-slate-950 p-3 text-center font-mono text-xs text-rose-300">
            dL/dW1 ← Layer 1 ← Layer 2 ← dL/dPrediction ← Loss L
          </div>
        </div>
      </div>
      <div className="rounded-xl border border-white/10 bg-white/[0.03] p-5">
        <div className="mb-2 font-bold text-white">
          Backpropagation vs. Gradient Descent (Do Not Confuse Them!)
        </div>
        <div className="text-sm leading-relaxed text-slate-300">
          Beginners often think Backpropagation and Gradient Descent are the same thing. They are two separate steps: <strong className="text-cyan-300">Backpropagation</strong> is the algorithm that <strong className="text-white">calculates the gradients</strong> ($\nabla L$, the compass reading) using the Chain Rule. <strong className="text-emerald-300">Gradient Descent</strong> (or Adam) is the optimizer that <strong className="text-white">uses those gradients to update the weights</strong> ($w_{\text{new}} = w - \alpha \nabla L$)!
        </div>
      </div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-violet-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
      2. Beginner Walkthrough: Backpropagation Through One Neuron by Hand
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        Let us trace the exact numbers of a Forward Pass and Backward Pass through a single neuron with input $x = 2$, weight $w = 3$, bias $b = 1$, ReLU activation $a = \text{ReLU}(z)$, and target $y = 10$ using Squared Error Loss $L = (a - y)^2$:
      </div>
      <div className="my-6 rounded-2xl border border-violet-400/20 bg-violet-400/[0.04] px-6 py-8 text-center">
        <div>$$z = wx + b \quad \longrightarrow \quad a = \text{ReLU}(z) \quad \longrightarrow \quad L = (a - y)^2$$</div>
      </div>
      <div className="grid gap-5 md:grid-cols-2">
        <div className="rounded-xl border border-cyan-500/25 bg-cyan-500/[0.04] p-6">
          <div className="mb-3 font-bold text-cyan-300">Step A: Forward Pass (Compute &amp; Save)</div>
          <div className="space-y-3 text-sm text-slate-300">
            <div>1. Linear sum: $z = (3)(2) + 1 = 7$</div>
            <div>2. ReLU switch: $a = \max(0, 7) = 7$</div>
            <div>3. Error (Loss): $L = (7 - 10)^2 = (-3)^2 = 9$</div>
          </div>
        </div>
        <div className="rounded-xl border border-rose-500/25 bg-rose-500/[0.04] p-6">
          <div className="mb-3 font-bold text-rose-300">Step B: Backward Pass (Right to Left)</div>
          <div className="space-y-3 text-sm text-slate-300">
            <div>1. Loss slope: $\dfrac{\partial L}{\partial a} = 2(a - y) = 2(7 - 10) = -6$</div>
            <div>2. Through ReLU ($z \gt 0 \implies \text{slope } 1$): $\dfrac{\partial L}{\partial z} = (-6)(1) = -6$</div>
            <div>3. Weight &amp; Bias gradients: $\dfrac{\partial L}{\partial w} = \dfrac{\partial L}{\partial z} \cdot x = (-6)(2) = -12$, and $\dfrac{\partial L}{\partial b} = -6$</div>
          </div>
        </div>
      </div>
      <div className="mt-8 rounded-2xl border border-amber-500/25 bg-[#0A0D16] p-6 shadow-[0_0_25px_rgba(245,158,11,0.05)]">
        <div className="mb-2 flex items-center gap-2 text-xs font-bold uppercase tracking-widest text-amber-400">
          <span>⚡ Knowledge Check </span>
        </div>
        <div className="mb-5 text-base font-semibold text-white">
          In the neuron example above ($z = wx + b$), why did we need to know the forward input value $x = 2$ during the Backward Pass when calculating $\dfrac{\partial L}{\partial w}$?
        </div>
        <div className="grid gap-4 md:grid-cols-2">
          <details className="group">
            <summary className="flex cursor-pointer items-center justify-between rounded-xl border border-white/10 bg-white/[0.03] px-4 py-3 text-sm font-semibold text-slate-200 transition-colors hover:bg-white/[0.06] marker:content-['']">
              <span>A) Because the local derivative dz/dw equals x, so dL/dw = (dL/dz) * x</span>
              <span className="text-amber-400 transition group-open:rotate-180">▼</span>
            </summary>
            <div className="mt-3 rounded-xl border border-emerald-500/30 bg-emerald-500/10 p-4 text-sm leading-relaxed text-slate-300">
              <strong className="mb-1 block text-emerald-400">✓ Correct!</strong>
              <span>Because $z = wx + b$, the partial derivative $\dfrac{\partial z}{\partial w}$ is literally the input $x$! That is why neural networks must store forward activations in GPU RAM until backpropagation finishes.</span>
            </div>
          </details>
          <details className="group">
            <summary className="flex cursor-pointer items-center justify-between rounded-xl border border-white/10 bg-white/[0.03] px-4 py-3 text-sm font-semibold text-slate-200 transition-colors hover:bg-white/[0.06] marker:content-['']">
              <span>B) Because we are updating the input data x instead of w</span>
              <span className="text-amber-400 transition group-open:rotate-180">▼</span>
            </summary>
            <div className="mt-3 rounded-xl border border-rose-500/30 bg-rose-500/10 p-4 text-sm leading-relaxed text-slate-300">
              <strong className="mb-1 block text-rose-400">✕ Incorrect.</strong>
              <span>Input data $x$ is fixed. We use $x$ purely because the sensitivity of a multiplier gate ($w \cdot x$) with respect to $w$ is the other multiplier $x$.</span>
            </div>
          </details>
        </div>
      </div>

  <section>
    <h2 className="mb-6 border-l-4 border-emerald-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
      3. Intermediate: The Four Fundamental Equations of Backpropagation
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        Now let us scale up from a single neuron to a <strong className="text-white">Multilayer Neural Network</strong> with layers $l = 1, 2, \dots, L$. At every layer $l$, we define an <strong className="text-emerald-300">Error Signal Vector $\boldsymbol{\delta}^{(l)} = \dfrac{\partial \mathcal{L}}{\partial \mathbf{z}^{(l)}}$</strong>, which represents the gradient of the Loss with respect to that layer&apos;s pre-activation logits $\mathbf{z}^{(l)}$.
      </div>
      <div>
        All of backpropagation across any deep network boils down to <strong className="text-white">four famous equations</strong> (where $\odot$ is element-wise multiplication):
      </div>
      <div className="grid gap-5 sm:grid-cols-2">
        <div className="rounded-xl border border-rose-500/25 bg-rose-500/[0.04] p-6">
          <div className="mb-2 font-bold text-rose-300">Equation 1: Output Layer Error ($\boldsymbol{\delta}^{(L)}$)</div>
          <div className="mb-4 text-xs leading-relaxed text-slate-300">
            Computes the error signal at the final layer $L$. When using <strong className="text-white">Softmax + Cross-Entropy</strong> (or Sigmoid + BCE), the derivative simplifies miraculously to just <strong className="text-emerald-300">Prediction minus Truth</strong>!
          </div>
          <div className="rounded-lg bg-slate-950 p-3 text-center text-sm">
            <div>$$\boldsymbol{\delta}^{(L)} = \dfrac{\partial \mathcal{L}}{\partial \mathbf{z}^{(L)}} = \hat{\mathbf{y}} - \mathbf{y}$$</div>
          </div>
        </div>
        <div className="rounded-xl border border-violet-500/25 bg-violet-500/[0.04] p-6">
          <div className="mb-2 font-bold text-violet-300">Equation 2: Pass Error to Previous Layer ($\boldsymbol{\delta}^{(l)}$)</div>
          <div className="mb-4 text-xs leading-relaxed text-slate-300">
            Routes the next layer&apos;s error $\boldsymbol{\delta}^{(l+1)}$ backward through the <strong className="text-white">transposed weight matrix</strong> $(\mathbf{W}^{(l+1)})^T$ and multiplies element-wise by the activation slope $\sigma^\prime(\mathbf{z}^{(l)})$:
          </div>
          <div className="rounded-lg bg-slate-950 p-3 text-center text-sm">
            <div>$$\boldsymbol{\delta}^{(l)} = \left(\boldsymbol{\delta}^{(l+1)} \left(\mathbf{W}^{(l+1)}\right)^T\right) \odot \sigma^\prime\left(\mathbf{z}^{(l)}\right)$$</div>
          </div>
        </div>
        <div className="rounded-xl border border-cyan-500/25 bg-cyan-500/[0.04] p-6">
          <div className="mb-2 font-bold text-cyan-300">Equation 3: Weight Matrix Gradient ($\dfrac{\partial \mathcal{L}}{\partial \mathbf{W}^{(l)}}$)</div>
          <div className="mb-4 text-xs leading-relaxed text-slate-300">
            Once layer $l$ knows its error signal $\boldsymbol{\delta}^{(l)}$, the gradient for its weight matrix $\mathbf{W}^{(l)}$ is simply the outer product (matrix multiply) of its <strong className="text-white">incoming activations</strong> and its <strong className="text-white">error signal</strong>:
          </div>
          <div className="rounded-lg bg-slate-950 p-3 text-center text-sm">
            <div>$$\dfrac{\partial \mathcal{L}}{\partial \mathbf{W}^{(l)}} = \left(\mathbf{a}^{(l-1)}\right)^T \boldsymbol{\delta}^{(l)}$$</div>
          </div>
        </div>
        <div className="rounded-xl border border-amber-500/25 bg-amber-500/[0.04] p-6">
          <div className="mb-2 font-bold text-amber-300">Equation 4: Bias Vector Gradient ($\dfrac{\partial \mathcal{L}}{\partial \mathbf{b}^{(l)}}$)</div>
          <div className="mb-4 text-xs leading-relaxed text-slate-300">
            Because the bias $\mathbf{b}^{(l)}$ is added directly to $\mathbf{z}^{(l)} = \mathbf{a}^{(l-1)}\mathbf{W}^{(l)} + \mathbf{b}^{(l)}$ with a local slope of $1$, the bias gradient is just the error signal summed across the batch!
          </div>
          <div className="rounded-lg bg-slate-950 p-3 text-center text-sm">
            <div>$$\dfrac{\partial \mathcal{L}}{\partial \mathbf{b}^{(l)}} = \sum_{\text{batch}} \boldsymbol{\delta}^{(l)}$$</div>
          </div>
        </div>
      </div>
      <div className="rounded-xl border border-white/10 bg-white/[0.03] p-5">
        <div className="mb-2 font-bold text-white">
          Why Does Equation 2 Multiply by the Transposed Weight Matrix $\mathbf{W}^T$?
        </div>
        <div className="text-sm leading-relaxed text-slate-300">
          During the <strong className="text-cyan-300">Forward Pass</strong>, matrix $\mathbf{W}$ of shape $(d_{\text{in}}, d_{\text{out}})$ projects signals forward from $d_{\text{in}}$ neurons to $d_{\text{out}}$ neurons. During the <strong className="text-rose-300">Backward Pass</strong>, we need to send error signals in the exact opposite direction—from $d_{\text{out}}$ neurons back to $d_{\text{in}}$ neurons—which requires multiplying by $\mathbf{W}^T$ of shape $(d_{\text{out}}, d_{\text{in}})$!
        </div>
      </div>
    </div>
  </section>

        </div>
        <div className="mb-5 text-base font-semibold text-white">
          In a hidden layer, the incoming activation batch $\mathbf{A}^{(l-1)}$ has shape $(32, 128)$ and the upstream error signal $\boldsymbol{\delta}^{(l)}$ has shape $(32, 64)$. What is the shape of the weight gradient $\dfrac{\partial \mathcal{L}}{\partial \mathbf{W}^{(l)}} = \left(\mathbf{A}^{(l-1)}\right)^T \boldsymbol{\delta}^{(l)}$?
        </div>
        <div className="grid gap-4 md:grid-cols-2">
          <details className="group">

              <span>A) (128, 64) — matching the exact shape of the weight matrix W!</span>
              <span className="text-amber-400 transition group-open:rotate-180">▼</span>

            </div>
          </details>
          <details className="group">
            <summary className="flex cursor-pointer items-center justify-between rounded-xl border border-white/10 bg-white/[0.03] px-4 py-3 text-sm font-semibold text-slate-200 transition-colors hover:bg-white/[0.06] marker:content-['']">

    <h2 className="mb-6 border-l-4 border-cyan-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
      5. Advanced Production Backprop: Activation Memory, Checkpointing &amp; Gradient Clipping
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        When training Large Language Models (like Llama-3 or GPT-4) on GPU clusters, senior AI engineers face three critical systems-level challenges directly caused by Backpropagation:
      </div>
      <div className="grid gap-5 md:grid-cols-2">
        <div className="rounded-xl border border-cyan-500/25 bg-cyan-500/[0.04] p-6">
          <div className="mb-2 font-bold text-cyan-300">1. Why Training Uses 10x More VRAM Than Inference</div>
          <div className="mb-3 text-sm text-slate-300">
            Because Equation 3 ($\mathbf{A}^T \boldsymbol{\delta}$) requires every layer&apos;s forward activation $\mathbf{A}^{(l)}$ during the backward pass, PyTorch must <strong className="text-white">keep all intermediate activations from all layers in GPU VRAM</strong>! During inference, activations are discarded immediately after each layer.
          </div>
          <div className="rounded-lg bg-slate-950 p-3 font-mono text-xs text-cyan-300">
            Training VRAM = Weights + Gradients + Optimizer + All Activations!
          </div>
        </div>
        <div className="rounded-xl border border-violet-500/25 bg-violet-500/[0.04] p-6">
          <div className="mb-2 font-bold text-violet-300">2. Activation (Gradient) Checkpointing</div>
          <div className="mb-3 text-sm text-slate-300">
            How do we train a 70B LLM without running out of GPU memory? <strong className="text-white">Activation Checkpointing</strong> discards most intermediate activations during the forward pass and <strong className="text-emerald-300">recomputes them on the fly</strong> during the backward pass—trading $\approx 25\%$ extra compute to slash activation VRAM by $70\%+$!
          </div>
          <div className="rounded-lg bg-slate-950 p-3 font-mono text-xs text-violet-300">
            torch.utils.checkpoint.checkpoint(layer_block, x)
          </div>
        </div>
      </div>
      <div className="rounded-xl border border-white/10 bg-white/[0.03] p-5">
        <div className="mb-2 font-bold text-white">
          3. Stabilizing Backprop in Deep Networks: Gradient Clipping &amp; Residual Highways
        </div>
        <div className="text-sm leading-relaxed text-slate-300">
          When training Transformers or RNNs, an unlucky batch can cause the backward product of matrices to spike (<strong className="text-rose-300">Exploding Gradients</strong>). Before calling <code>optimizer.step()</code>, production training loops cap the global gradient norm to $1.0$ using <strong className="text-emerald-300"><code>torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)</code></strong> so a single bad batch never destroys the model&apos;s learned weights.
        </div>
      </div>
      <div className="mt-8 rounded-2xl border border-amber-500/25 bg-[#0A0D16] p-6 shadow-[0_0_25px_rgba(245,158,11,0.05)]">
        <div className="mb-2 flex items-center gap-2 text-xs font-bold uppercase tracking-widest text-amber-400">
          <span>⚡ Knowledge Check </span>
        </div>
        <div className="mb-5 text-base font-semibold text-white">
          Your 7-Billion parameter LLM fits easily on a single 24GB GPU during inference (<code>with torch.no_grad():</code>), but immediately crashes with <code>CUDA out of memory</code> on the exact same GPU when you try to run training with batch size $8$. Why?
        </div>
        <div className="grid gap-4 md:grid-cols-2">
          <details className="group">
            <summary className="flex cursor-pointer items-center justify-between rounded-xl border border-white/10 bg-white/[0.03] px-4 py-3 text-sm font-semibold text-slate-200 transition-colors hover:bg-white/[0.06] marker:content-['']">
              <span>A) Backprop must cache forward activations for all layers, plus store gradients and optimizer states</span>
              <span className="text-amber-400 transition group-open:rotate-180">▼</span>
            </summary>
            <div className="mt-3 rounded-xl border border-emerald-500/30 bg-emerald-500/10 p-4 text-sm leading-relaxed text-slate-300">
              <strong className="mb-1 block text-emerald-400">✓ Correct!</strong>
              <span>During inference, layer $1$&apos;s activations are overwritten as soon as layer $2$ finishes. During training, every layer&apos;s activations must be kept in VRAM until the backward pass reaches that layer. Enabling Activation Checkpointing solves this!</span>
            </div>
          </details>
          <details className="group">
            <summary className="flex cursor-pointer items-center justify-between rounded-xl border border-white/10 bg-white/[0.03] px-4 py-3 text-sm font-semibold text-slate-200 transition-colors hover:bg-white/[0.06] marker:content-['']">
              <span>B) Because training duplicates the input dataset 100 times in VRAM</span>
              <span className="text-amber-400 transition group-open:rotate-180">▼</span>
            </summary>
            <div className="mt-3 rounded-xl border border-rose-500/30 bg-rose-500/10 p-4 text-sm leading-relaxed text-slate-300">
              <strong className="mb-1 block text-rose-400">✕ Incorrect.</strong>
              <span>Only one mini-batch of data is loaded into VRAM at a time; the memory spike comes from cached intermediate layer activations, parameter gradients, and Adam optimizer momentum buffers.</span>
            </div>

  <section>
    <h2 className="mb-6 border-l-4 border-indigo-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
      6. Visual Explanation: The Complete Forward &amp; Backward Pass Loop
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        Look at how signals travel forward through the network to cache activations and compute the Loss, and how error signals $\boldsymbol{\delta}$ travel backward through transposed weights to compute parameter gradients:

        <div className="flex items-start gap-3">
          <span className="mt-0.5 font-bold text-emerald-400">✓</span>
          <span>Backpropagation is the reverse-mode automatic differentiation algorithm that computes the gradient $\nabla \mathcal{L}$ for every weight in a neural network in a single backward pass.</span>
        </div>
        <div className="flex items-start gap-3">
          <span className="mt-0.5 font-bold text-emerald-400">✓</span>
          <span>Backpropagation only <em>computes</em> the gradients; an optimizer like SGD or AdamW then uses those gradients to update the weights[cite: 10].</span>
        </div>
        <div className="flex items-start gap-3">
          <span className="mt-0.5 font-bold text-emerald-400">✓</span>
          <span>The four equations of matrix backpropagation compute: (1) output error $\boldsymbol{\delta}^{(L)}$, (2) hidden error $\boldsymbol{\delta}^{(l)} = (\boldsymbol{\delta}^{(l+1)}(\mathbf{W}^{(l+1)})^T) \odot \sigma^\prime(\mathbf{z}^{(l)})$, (3) weight gradient $(\mathbf{A}^{(l-1)})^T \boldsymbol{\delta}^{(l)}$, and (4) bias gradient $\sum \boldsymbol{\delta}^{(l)}$.</span>
        </div>
        <div className="flex items-start gap-3">
          <span className="mt-0.5 font-bold text-emerald-400">✓</span>
          <span>By caching and reusing intermediate derivatives from right to left (Dynamic Programming), Backpropagation computes $N$ parameter gradients in $\mathcal{O}(1)$ passes instead of $\mathcal{O}(N)$ passes.</span>
        </div>
        <div className="flex items-start gap-3">
          <span className="mt-0.5 font-bold text-emerald-400">✓</span>
          <span>Because computing $\dfrac{\partial \mathcal{L}}{\partial \mathbf{W}^{(l)}}$ requires the forward activation $\mathbf{A}^{(l-1)}$, training a deep model consumes far more GPU memory than inference unless Activation Checkpointing is enabled.</span>
        </div>

      Common Mistakes
    </h2>
    <div className="rounded-2xl border border-rose-500/25 bg-rose-950/[0.15] p-6 sm:p-8">
      <div className="space-y-6">
        <div>
          <div className="mb-1.5 font-bold text-rose-400">
            ✕ Confusing Backpropagation with Gradient Descent.
          </div>
          <div className="text-sm leading-relaxed text-slate-300">
            Backpropagation is the algorithm that calculates $\dfrac{\partial \mathcal{L}}{\partial \mathbf{W}}$ via the Chain Rule (called by <code>loss.backward()</code>). Gradient Descent / Adam is the optimization rule that steps downhill using those gradients (called by <code>optimizer.step()</code>)[cite: 10].
          </div>
        </div>
        <div>
          <div className="mb-1.5 font-bold text-rose-400">
            ✕ Using matrix multiplication (@) instead of element-wise multiplication (*) for activation derivatives.
          </div>
          <div className="text-sm leading-relaxed text-slate-300">
            In Equation 2, $\left(\boldsymbol{\delta}^{(l+1)} (\mathbf{W}^{(l+1)})^T\right)$ is a matrix multiplication, but multiplying by the activation slope $\sigma^\prime(\mathbf{z}^{(l)})$ is strictly <strong className="text-white">element-wise ($\odot$)</strong> because each neuron gates its own signal.
          </div>
        </div>
        <div>
          <div className="mb-1.5 font-bold text-rose-400">
            ✕ Forgetting to divide the output gradient by batch_size when using mean loss.
          </div>
          <div className="text-sm leading-relaxed text-slate-300">
            If your forward loss averages error over $B$ batch samples ($\frac{1}{B}\sum \mathcal{L}_i$), your backward output error $\boldsymbol{\delta}^{(L)}$ must also be divided by $B$ so gradient magnitudes do not scale up when you change the batch size!
          </div>
        </div>
        <div>
          <div className="mb-1.5 font-bold text-rose-400">
            ✕ Modifying forward activations in-place before backpropagation runs.
          </div>
          <div className="text-sm leading-relaxed text-slate-300">
            Overwriting cached forward tensors with in-place operations (like <code>a += 1</code>) corrupts the values needed for Equation 3 ($\mathbf{A}^T \boldsymbol{\delta}$), causing PyTorch&apos;s Autograd engine to throw a <code>RuntimeError</code>.
          </div>
        </div>
      </div>
    </div>
