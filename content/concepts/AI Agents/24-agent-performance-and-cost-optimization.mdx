    <h2 data-type="code" className="mb-6 border-l-4 border-teal-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
      7. Python Implementation: A Cost Model for a 12-Step Agent Run
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        This script models the input and output cost of a 12-step run where every step re-sends the history. It compares the baseline with prompt caching, history summarization, a cheaper model for half of the steps, and all three together, and shows the latency gain of parallel tool calls. The prices are made-up examples.
      </div>
      <div className="overflow-hidden rounded-2xl border border-white/10 bg-[#060911]">
        <div className="flex items-center justify-between border-b border-white/10 bg-white/[0.03] px-5 py-3">
          <span className="font-mono text-xs font-semibold text-teal-400">agent_cost_model.py</span>
          <span className="font-mono text-[11px] text-slate-400">Python 3.10+ · standard library only</span>
        </div>
        <pre className="overflow-x-auto p-6 font-mono text-sm leading-7 text-slate-200">
          <code>
            <span className="block text-slate-500"># Cost of one agent run: every step re-sends the growing history</span>
            <span className="block">IN&#95;PRICE, OUT&#95;PRICE = 3.0, 15.0            # example prices in USD per million tokens (not real quotes)</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def run&#95;cost(steps=12, system=1000, per&#95;step=400, output=150, cached=False, summarize&#95;cap=None, cheap&#95;share=0.0):</span>
            <span className="block">    total = 0.0</span>
            <span className="block">    for i in range(1, steps + 1):</span>
            <span className="block">        history = (i - 1) &#42; per&#95;step</span>
            <span className="block">        if summarize&#95;cap:</span>
            <span className="block">            history = min(history, summarize&#95;cap)             # old steps are compressed into a short summary</span>
            <span className="block">        prefix = system + history</span>
            <span className="block">        if cached:</span>
            <span className="block">            input&#95;cost = prefix &#42; IN&#95;PRICE &#42; 0.1 + per&#95;step &#42; IN&#95;PRICE      # repeated prefix at an example 90% discount</span>
            <span className="block">        else:</span>
            <span className="block">            input&#95;cost = (prefix + per&#95;step) &#42; IN&#95;PRICE</span>
            <span className="block">        step&#95;cost = (input&#95;cost + output &#42; OUT&#95;PRICE) / 1&#95;000&#95;000</span>
            <span className="block">        if i / steps &lt;= cheap&#95;share:</span>
            <span className="block">            step&#95;cost &#42;= 0.1                                  # easy steps use a model that costs a tenth</span>
