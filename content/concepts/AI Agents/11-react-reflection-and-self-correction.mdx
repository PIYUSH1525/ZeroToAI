      1. Beginner: What Is ReAct?
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        <strong className="text-white">ReAct</strong> (Reason + Act) is a pattern in which the agent <strong className="text-white">alternates</strong> between reasoning in words and taking an action. The reasoning guides which action to take. The action returns an observation that guides the next reasoning step.
      </div>
      <div className="overflow-x-auto rounded-2xl border border-white/10">
        <table className="w-full text-left text-sm">
          <thead className="bg-white/[0.04] text-xs uppercase tracking-wider text-slate-400">

              <th className="px-5 py-3">With ReAct</th>
            </tr>
          </thead>
          <tbody className="divide-y divide-white/5 text-slate-300">
            <tr><td className="px-5 py-3 font-semibold text-white">Think everything through first, then act</td><td className="px-5 py-3">Think a little, act, look, think again</td></tr>
            <tr><td className="px-5 py-3 font-semibold text-white">Mistakes are found at the end</td><td className="px-5 py-3">Mistakes are noticed as soon as an observation surprises the agent</td></tr>
            <tr><td className="px-5 py-3 font-semibold text-white">Hard to see why an action was chosen</td><td className="px-5 py-3">The thoughts explain each action</td></tr>
          </tbody>
        </table>
      </div>
      <div className="rounded-xl border border-cyan-500/20 bg-cyan-500/[0.05] p-5 text-sm leading-relaxed">
        <strong className="text-cyan-300">Why it works:</strong> Real information from tools <strong className="text-white">corrects</strong> the model&apos;s guesses at every step, and the written thoughts keep the plan on track.
      </div>
    </div>
  </section>
