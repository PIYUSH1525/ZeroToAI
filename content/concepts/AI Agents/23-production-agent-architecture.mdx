    <h2 data-type="code" className="mb-6 border-l-4 border-teal-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
      7. Python Implementation: A Durable Job Queue and Capacity Planning
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        This script builds a small durable job queue in a database with status transitions, retries with a limit, a give-up state and an idempotency key that ignores duplicate submissions. It ends with a capacity calculation based on Little&apos;s law.
      </div>
      <div className="overflow-hidden rounded-2xl border border-white/10 bg-[#060911]">
        <div className="flex items-center justify-between border-b border-white/10 bg-white/[0.03] px-5 py-3">
          <span className="font-mono text-xs font-semibold text-teal-400">agent_backend.py</span>
          <span className="font-mono text-[11px] text-slate-400">Python 3.10+ · standard library only</span>
        </div>
        <pre className="overflow-x-auto p-6 font-mono text-sm leading-7 text-slate-200">
          <code>
            <span className="block">import json, sqlite3</span>
            <span className="block">&nbsp;</span>
            <span className="block text-slate-500"># A durable job queue in a database: the heart of a production agent backend</span>
            <span className="block">db = sqlite3.connect(&quot;:memory:&quot;)</span>
            <span className="block">db.execute(&quot;&quot;&quot;CREATE TABLE jobs (id INTEGER PRIMARY KEY, idem&#95;key TEXT UNIQUE, payload TEXT,</span>
            <span className="block">              status TEXT, attempts INTEGER DEFAULT 0, result TEXT)&quot;&quot;&quot;)</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def submit(idem&#95;key, payload):</span>
            <span className="block">    try:</span>
            <span className="block">        cursor = db.execute(&quot;INSERT INTO jobs (idem&#95;key, payload, status) VALUES (?, ?, &apos;queued&apos;)&quot;, (idem&#95;key, json.dumps(payload)))</span>
            <span className="block">        return &quot;queued as job &quot; + str(cursor.lastrowid)</span>
            <span className="block">    except sqlite3.IntegrityError:</span>
            <span className="block">        return &quot;duplicate request ignored (same idempotency key)&quot;</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def claim&#95;next():</span>
            <span className="block">    row = db.execute(&quot;SELECT id, payload, attempts FROM jobs WHERE status = &apos;queued&apos; ORDER BY id LIMIT 1&quot;).fetchone()</span>
            <span className="block">    if row:</span>
            <span className="block">        db.execute(&quot;UPDATE jobs SET status = &apos;running&apos;, attempts = attempts + 1 WHERE id = ?&quot;, (row&#91;0&#93;,))</span>
            <span className="block">    return row</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def run&#95;agent(payload, attempt):</span>
            <span className="block">    if attempt &lt;= payload&#91;&quot;fail&#95;times&quot;&#93;:</span>
            <span className="block">        raise RuntimeError(&quot;tool timeout&quot;)</span>
            <span className="block">    return &quot;report for &quot; + payload&#91;&quot;topic&quot;&#93;</span>
            <span className="block">&nbsp;</span>
            <span className="block">MAX&#95;ATTEMPTS = 3</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def worker&#95;loop():</span>
            <span className="block">    while True:</span>
            <span className="block">        row = claim&#95;next()</span>
            <span className="block">        if row is None:</span>
            <span className="block">            return</span>
