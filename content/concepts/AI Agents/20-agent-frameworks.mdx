      3. Medium: LangGraph and Graph-Based Agents
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        <strong className="text-white">LangGraph</strong> models an agent as a <strong className="text-white">graph</strong>: nodes are steps (call the model, run a tool, check a result), edges say which step comes next, and a <strong className="text-white">shared state</strong> flows through the graph. Conditional edges choose the next node from the state, which allows loops and branches.
      </div>
      <div>
        The code in this lesson builds a tiny graph engine in about twenty lines. Nodes return updates that are <strong className="text-white">merged into the state</strong>, a conditional edge decides whether to loop or end, and a step limit protects against endless runs.
      </div>
      <div className="rounded-xl border border-emerald-500/20 bg-emerald-500/[0.05] p-5 text-sm leading-relaxed">
        <strong className="text-emerald-300">Why graphs are popular:</strong> They make control flow <strong className="text-white">explicit</strong>: you can draw the agent, test each node, add checkpoints between nodes, pause for a human, and resume. This matches the workflow and state machine lesson.
      </div>
    </div>
  </section>
