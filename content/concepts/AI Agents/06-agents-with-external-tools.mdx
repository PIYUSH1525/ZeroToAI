      1. Beginner: Why Agents Need External Tools
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        A model alone knows only its training data and can only write text. External tools give it <strong className="text-white">fresh data</strong>, <strong className="text-white">exact computation</strong> and the ability to <strong className="text-white">act</strong>. The six most common kinds are:
      </div>
      <div className="overflow-x-auto rounded-2xl border border-white/10">
        <table className="w-full text-left text-sm">
          <thead className="bg-white/[0.04] text-xs uppercase tracking-wider text-slate-400">
            <tr>
              <th className="px-5 py-3">Tool kind</th>
              <th className="px-5 py-3">What it gives the agent</th>
              <th className="px-5 py-3">Main risk</th>
            </tr>
          </thead>
          <tbody className="divide-y divide-white/5 text-slate-300">
            <tr><td className="px-5 py-3 font-semibold text-white">APIs</td><td className="px-5 py-3">Live data and services such as weather or payments</td><td className="px-5 py-3">Leaked keys, runaway calls</td></tr>
            <tr><td className="px-5 py-3 font-semibold text-white">Databases</td><td className="px-5 py-3">Business data</td><td className="px-5 py-3">Data leaks, destructive queries</td></tr>
            <tr><td className="px-5 py-3 font-semibold text-white">Web search</td><td className="px-5 py-3">Fresh public information</td><td className="px-5 py-3">Wrong or hostile content</td></tr>
            <tr><td className="px-5 py-3 font-semibold text-white">Code execution</td><td className="px-5 py-3">Exact math, data work, plots</td><td className="px-5 py-3">Running harmful code</td></tr>
            <tr><td className="px-5 py-3 font-semibold text-white">File operations</td><td className="px-5 py-3">Reading and writing documents</td><td className="px-5 py-3">Reading or overwriting the wrong files</td></tr>
            <tr><td className="px-5 py-3 font-semibold text-white">External services</td><td className="px-5 py-3">Email, calendar, tickets, chat</td><td className="px-5 py-3">Real-world side effects</td></tr>
          </tbody>
        </table>
      </div>
      <div className="rounded-xl border border-cyan-500/20 bg-cyan-500/[0.05] p-5 text-sm leading-relaxed">
        <strong className="text-cyan-300">Design rule:</strong> The more a tool can <strong className="text-white">change</strong> in the world, the more checks it needs.
      </div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-violet-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
      2. Beginner: APIs and Databases
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        <strong className="text-white">APIs</strong> are the most general tool: a wrapper function sends an HTTP request and returns only the useful fields. Keep the API key on the server, hide it from the model and shape the output small.
      </div>
      <div>
        A <strong className="text-white">database tool</strong> lets the agent answer questions about business data. The safest design is <strong className="text-white">read-only</strong>: accept only a single SELECT statement, run it with a database user that has no write rights, and limit the number of rows returned.
      </div>
      <div className="rounded-xl border border-amber-500/20 bg-amber-500/[0.05] p-5 text-sm leading-relaxed">
        <strong className="text-amber-300">In the code:</strong> The query tool accepts a SELECT and rejects DROP TABLE. The best protection is also a <strong className="text-white">read-only database account</strong>, because code checks can have gaps.
      </div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-emerald-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
      3. Medium: Web Search and Code Execution
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        <strong className="text-white">Web search</strong> lets the agent find fresh information. Treat results as <strong className="text-white">untrusted</strong>: pages can be wrong, outdated, or contain hidden instructions. Return short snippets with their sources so the agent can cite them.
      </div>
      <div>
        <strong className="text-white">Code execution</strong> is powerful because the model can write exact calculations instead of guessing them. It is also dangerous, so it must run in a <strong className="text-white">sandbox</strong>: a separate process or container with a time limit, no secrets, limited memory and often no network.
      </div>
      <div className="overflow-x-auto rounded-2xl border border-white/10">
        <table className="w-full text-left text-sm">
          <thead className="bg-white/[0.04] text-xs uppercase tracking-wider text-slate-400">
            <tr>
              <th className="px-5 py-3">Sandbox control</th>
              <th className="px-5 py-3">Why</th>
            </tr>
          </thead>
          <tbody className="divide-y divide-white/5 text-slate-300">
            <tr><td className="px-5 py-3 font-semibold text-white">Separate process or container</td><td className="px-5 py-3">A crash or attack cannot reach the main app</td></tr>
            <tr><td className="px-5 py-3 font-semibold text-white">Time and memory limit</td><td className="px-5 py-3">Stops infinite loops</td></tr>
            <tr><td className="px-5 py-3 font-semibold text-white">No access to secrets</td><td className="px-5 py-3">Nothing valuable to steal</td></tr>
            <tr><td className="px-5 py-3 font-semibold text-white">Network off by default</td><td className="px-5 py-3">Prevents data leaving</td></tr>
            <tr><td className="px-5 py-3 font-semibold text-white">Capture output only</td><td className="px-5 py-3">The agent gets results, not control</td></tr>
          </tbody>
        </table>
      </div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-orange-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
      4. Medium: File Operations and External Services
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        <strong className="text-white">File tools</strong> let the agent read and write documents. Confine them to <strong className="text-white">one working folder</strong>, resolve paths before checking them (so ../ tricks fail), and prefer <strong className="text-white">new files</strong> over overwriting existing ones.
      </div>
      <div>
        <strong className="text-white">External services</strong> such as email, calendars and ticket systems cause <strong className="text-white">real side effects</strong> that cannot be undone. Use an <strong className="text-white">approval gate</strong>: the agent can <em>prepare</em> an email, but a human must approve sending it.
      </div>
      <div className="rounded-xl border border-rose-500/20 bg-rose-500/[0.05] p-5 text-sm leading-relaxed">
        <strong className="text-rose-300">Golden rule:</strong> Reading is cheap and reversible. Writing, sending and paying are not. Put the strongest guards on the actions that cannot be undone.
      </div>
    </div>
  </section>
