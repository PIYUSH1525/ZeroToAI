      7. Python Implementation: Tool Retrieval and a Browser-Style Action Loop
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        This script shows two ideas. First, a tool-rich agent retrieves the three most relevant tools from a catalog of 30 and compares the prompt sizes. Second, a browser-style agent observes a page as a list of elements, acts by typing and clicking, and observes the changed page.
      </div>

        <div className="flex items-center justify-between border-b border-white/10 bg-white/[0.03] px-5 py-3">

          <span className="font-mono text-[11px] text-slate-400">Python 3.10+ · standard library only</span>
        </div>
        <pre className="overflow-x-auto p-6 font-mono text-sm leading-7 text-slate-200">
          <code>
            <span className="block text-slate-500"># 1. A tool-rich agent: retrieve only the few relevant tools instead of showing all of them</span>
            <span className="block">verbs = &#91;&quot;get&quot;, &quot;create&quot;, &quot;delete&quot;, &quot;update&quot;, &quot;list&quot;&#93;</span>
            <span className="block">nouns = &#91;&quot;invoice&quot;, &quot;ticket&quot;, &quot;customer&quot;, &quot;order&quot;, &quot;report&quot;, &quot;calendar&quot;&#93;</span>
            <span className="block">TOOLS = &#91;(v + &quot;&#95;&quot; + n, v + &quot; a &quot; + n + &quot; record in the system&quot;) for v in verbs for n in nouns&#93;</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def words(text):</span>
            <span className="block">    return &#123;w.rstrip(&quot;s&quot;) for w in text.lower().replace(&quot;&#95;&quot;, &quot; &quot;).split()&#125;</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def select&#95;tools(query, k=3):</span>
            <span className="block">    q = words(query)</span>
            <span className="block">    scored = sorted(TOOLS, key=lambda tool: len(q &amp; words(tool&#91;0&#93; + &quot; &quot; + tool&#91;1&#93;)), reverse=True)</span>
            <span className="block">    return &#91;name for name, &#95; in scored&#91;:k&#93;&#93;</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def prompt&#95;tokens(tools):</span>
            <span className="block">    return sum(round(len((n + &quot; &quot; + d).split()) / 0.75) for n, d in tools)</span>
            <span className="block">&nbsp;</span>
            <span className="block">query = &quot;show me the list of orders&quot;</span>
            <span className="block">print(&quot;Tools available:&quot;, len(TOOLS), &quot;| tokens if all are shown:&quot;, prompt&#95;tokens(TOOLS))</span>
            <span className="block">chosen = select&#95;tools(query)</span>
            <span className="block">print(&quot;Query:&quot;, query, &quot;-&gt; shown to the model:&quot;, chosen, &quot;| tokens:&quot;, prompt&#95;tokens(&#91;t for t in TOOLS if t&#91;0&#93; in chosen&#93;))</span>
            <span className="block">&nbsp;</span>
            <span className="block text-slate-500"># 2. A browser agent: the page is turned into a list of elements the agent can act on</span>
