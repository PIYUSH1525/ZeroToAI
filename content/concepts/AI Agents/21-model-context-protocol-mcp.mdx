  <section>
    <h2 className="mb-6 border-l-4 border-blue-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
      1. Beginner: MCP Fundamentals
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        Before MCP, connecting an AI application to a new tool or data source meant writing a custom integration for each pair. With <strong className="text-white">N</strong> applications and <strong className="text-white">M</strong> tools, that is up to N × M integrations. MCP replaces this with <strong className="text-white">one standard</strong>: each application speaks MCP once, and each tool exposes MCP once.
      </div>
      <div className="rounded-xl border border-cyan-500/20 bg-cyan-500/[0.05] p-5 text-sm leading-relaxed">
        <strong className="text-cyan-300">Analogy:</strong> Think of USB. Instead of a different cable for every device and computer, one standard port connects them all.
      </div>
      <div className="overflow-x-auto rounded-2xl border border-white/10">
        <table className="w-full text-left text-sm">
          <thead className="bg-white/[0.04] text-xs uppercase tracking-wider text-slate-400">
            <tr>
              <th className="px-5 py-3">Without a standard</th>
              <th className="px-5 py-3">With MCP</th>
            </tr>
          </thead>
          <tbody className="divide-y divide-white/5 text-slate-300">
            <tr><td className="px-5 py-3 font-semibold text-white">Custom integration per app and tool</td><td className="px-5 py-3">One protocol both sides understand</td></tr>
            <tr><td className="px-5 py-3 font-semibold text-white">Work is repeated by every team</td><td className="px-5 py-3">A server is written once and reused</td></tr>
            <tr><td className="px-5 py-3 font-semibold text-white">Hard to swap tools</td><td className="px-5 py-3">Plug in a different server</td></tr>
          </tbody>
        </table>
      </div>
      <div>
        MCP was introduced by Anthropic as an open standard and is now supported by many AI applications and tool providers. The protocol keeps evolving, so check the official specification for current details.
      </div>
    </div>
