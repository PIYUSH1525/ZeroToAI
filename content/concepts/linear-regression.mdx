    <section>
      <h2 className="mb-6 border-l-4 border-blue-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
        1. What is Linear Regression?
      </h2>

      <div className="space-y-5 text-[16px] leading-8 text-slate-300">
        <div>
          Linear Regression is a supervised learning algorithm used to predict a <strong className="font-semibold text-white">continuous numerical value</strong>.
        </div>

        <div>
          It learns the relationship between an input feature $X$ and an output target $Y$ by fitting a straight line through the observed training data.
        </div>

        <div className="my-7 rounded-xl border border-blue-400/15 bg-blue-400/[0.06] p-6">
          <div className="mb-3 font-semibold text-blue-200">For example:</div>

          <div className="space-y-3 text-center text-slate-200">
            <div><strong>Years of Experience → Monthly Salary</strong></div>
            <div><strong>House Size ($m^2$) → Market Price ($)</strong></div>
          </div>
        </div>

        <div>
          If you know how much the input variable changes, the model discovers the exact rate of change so you can predict the outcome for new, unseen data points.
        </div>
      </div>
    </section>

    <section>
      <h2 className="mb-6 border-l-4 border-violet-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">

      </h2>

        <div>

        </div>

        <div className="my-8 overflow-hidden rounded-2xl border border-white/10 bg-slate-950/50 p-5">
<div className="my-8 rounded-2xl border border-white/10 bg-slate-950/60 p-6">
  <div className="mb-5 text-center text-xs font-semibold uppercase tracking-[0.18em] text-slate-500">
    Feature Space
  </div>
  <div className="grid gap-4 md:grid-cols-3">
    <div className="rounded-xl border border-blue-400/20 bg-blue-400/[0.06] px-4 py-5 text-center font-mono text-sm text-blue-100">
      Data Point (x1, y1)

          </div>

          <div className="border-l-2 border-emerald-400/60 pl-4">
            <div><strong className="text-white">Core Objective:</strong> Shift and tilt the line until the cumulative sum of these squared residuals is minimized.</div>

      </div>
    </section>

    <section>
      <h2 className="mb-6 border-l-4 border-emerald-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
        3. How Does It Make a Prediction?
      </h2>

      <div className="space-y-6 text-[16px] leading-8 text-slate-300">
        <div>
          Linear Regression uses the standard slope-intercept algebraic formula:
        </div>

        <div className="my-8 rounded-2xl border border-emerald-400/15 bg-emerald-400/[0.04] px-6 py-8 text-center text-xl">
          $$
          \hat{y} = wx + b
          $$
        </div>

        <div className="rounded-xl border border-white/10 bg-white/[0.03] p-6">
          <div className="mb-4 font-semibold text-white">Where:</div>

          <ul className="space-y-3 pl-5">
            <li><code>$x$</code> = input feature (e.g., house square footage)</li>
            <li><code>$\hat{y}$</code> = predicted value (e.g., estimated price)</li>
            <li><code>$w$</code> = weight or slope (rate of change per unit of $x$)</li>
            <li><code>$b$</code> = bias or y-intercept (baseline value when $x = 0$)</li>
          </ul>
        </div>

        <div className="mt-8 rounded-2xl border border-blue-400/15 bg-blue-400/[0.05] p-6 sm:p-8">
          <h3 className="mb-5 text-xl font-bold text-white">
            Step-by-Step Worked Example:
          </h3>

          <div className="space-y-5">
            <div>
              Suppose our fitted model discovers $w = 900$ and $b = 2{,}100$:
            </div>

            <div className="rounded-xl border border-white/10 bg-slate-950/60 px-5 py-4 text-center">
              $$
              \text{Salary} = (900 \times \text{Experience}) + 2{,}100
              $$
            </div>

            <div>
              If an applicant has $x = 4$ years of experience:
            </div>

            <div className="rounded-xl border border-white/10 bg-slate-950/60 px-5 py-4 text-center">
              $$
              \hat{y} = (900)(4) + 2{,}100 = 3{,}600 + 2{,}100 = \$5{,}700
              $$
            </div>
          </div>
        </div>

        <div>
          The data pipeline runs through the following sequence:
        </div>

        <div className="my-8 overflow-hidden rounded-2xl border border-white/10 bg-slate-950/50 p-5">
<div className="my-8 rounded-2xl border border-white/10 bg-slate-950/60 p-5">
  <div className="flex flex-col items-stretch justify-center gap-3 md:flex-row md:items-center">
    <div className="rounded-xl border border-blue-400/25 bg-blue-400/[0.06] px-5 py-4 text-center font-semibold text-blue-100">
      Input: x
    </div>
    <div className="text-center text-xl text-slate-500">→</div>
    <div className="rounded-xl border border-violet-400/25 bg-violet-400/[0.06] px-5 py-4 text-center font-semibold text-violet-100">
      Multiply by w
    </div>
    <div className="text-center text-xl text-slate-500">→</div>
    <div className="rounded-xl border border-orange-400/25 bg-orange-400/[0.06] px-5 py-4 text-center font-semibold text-orange-100">
      Add bias b
    </div>
    <div className="text-center text-xl text-slate-500">→</div>
    <div className="rounded-xl border border-emerald-400/25 bg-emerald-400/[0.06] px-5 py-4 text-center font-semibold text-emerald-100">
      Prediction: y_hat
    </div>
  </div>
</div>
        </div>
      </div>
    </section>

    <section>
      <h2 className="mb-6 border-l-4 border-orange-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
        4. How Does It Learn the Best Line?
      </h2>

      <div className="space-y-6 text-[16px] leading-8 text-slate-300">
        <div>
          The model starts with initial guesses for $w$ and $b$, then iteratively refines them through an optimization loop:
        </div>

        <div className="my-8 overflow-hidden rounded-2xl border border-white/10 bg-slate-950/50 p-5">
<div className="my-8 rounded-2xl border border-white/10 bg-slate-950/60 p-6">
  <div className="mx-auto flex max-w-2xl flex-col items-center gap-3">
    <div className="w-full rounded-xl border border-blue-400/25 bg-blue-400/[0.06] px-5 py-4 text-center font-semibold text-blue-100">
      1. Initialize weights w and b
    </div>
    <div className="text-xl text-slate-500">↓</div>
    <div className="w-full rounded-xl border border-violet-400/25 bg-violet-400/[0.06] px-5 py-4 text-center font-semibold text-violet-100">
      2. Compute Predictions y_hat
    </div>
    <div className="text-xl text-slate-500">↓</div>
    <div className="w-full rounded-xl border border-orange-400/25 bg-orange-400/[0.06] px-5 py-4 text-center font-semibold text-orange-100">
      3. Calculate Loss via MSE
    </div>
    <div className="text-xl text-slate-500">↓</div>
    <div className="w-full rounded-xl border border-pink-400/25 bg-pink-400/[0.06] px-5 py-4 text-center font-semibold text-pink-100">
      4. Compute Gradients
    </div>
    <div className="text-xl text-slate-500">↓</div>
    <div className="w-full rounded-xl border border-cyan-400/25 bg-cyan-400/[0.06] px-5 py-4 text-center font-semibold text-cyan-100">
      5. Update w and b via Learning Rate
    </div>
    <div className="my-1 rounded-xl border border-yellow-400/30 bg-yellow-400/[0.06] px-5 py-4 text-center font-semibold text-yellow-100">

    </div>
    <div className="grid w-full gap-3 sm:grid-cols-2">
      <div className="rounded-xl border border-red-400/20 bg-red-400/[0.05] px-4 py-3 text-center text-sm text-red-100">

      <div className="rounded-xl border border-emerald-400/25 bg-emerald-400/[0.06] px-4 py-3 text-center text-sm text-emerald-100">

          MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2

        </div>

        <div>Squaring the errors achieves two critical objectives:</div>

        <ol className="list-decimal space-y-3 pl-6">
          <li>It eliminates negative signs so errors in opposite directions do not cancel out.</li>
          <li>It penalizes large deviations much more severely than small ones.</li>
        </ol>
      </div>

      <div className="text-center text-sm leading-6 text-slate-300">

      <div className="mb-3 text-center font-semibold text-amber-100">Bias (b): Y-Intercept</div>

          </div>

          <div className="rounded-xl border border-white/10 bg-white/[0.03] p-5">
            <div><strong className="text-white">Bias ($b$):</strong> The point where the line crosses the vertical axis when $x = 0$. Without a bias term, the model would be constrained to always pass through $(0, 0)$.</div>
          </div>
        </div>
      </div>
    </section>

    <section>
      <h2 className="mb-6 border-l-4 border-pink-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">

      <div className="space-y-6 text-[16px] leading-8 text-slate-300">
        <div>
          There are two primary mathematical approaches for finding the optimal weights:

<div className="my-8 rounded-2xl border border-white/10 bg-slate-950/60 p-6">

      </div>

        Solves directly via Normal Equation:<br />
        beta = (X^T X)^(-1) X^T y

    </div>
    <div className="rounded-xl border border-emerald-400/20 bg-emerald-400/[0.05] p-5">
      <div className="mb-3 text-center text-xs font-semibold uppercase tracking-wider text-emerald-300">
        Large / Streaming Datasets
      </div>
      <div className="mb-4 rounded-lg border border-white/10 bg-white/[0.03] px-4 py-3 text-center font-semibold text-white">
        Gradient Descent (Iterative)
      </div>
      <div className="text-center font-mono text-xs leading-6 text-slate-400">

    </div>
  </div>
</div>
        </div>

        <div className="space-y-4">
          <div className="rounded-xl border border-white/10 bg-white/[0.03] p-6">
            <div><strong className="text-white">1. Normal Equation (Closed-form):</strong> Computes the exact minimum directly in one matrix operation. Very fast for smaller datasets, but matrix inversion scales with $\mathcal{O}(p^3)$ complexity as features grow.</div>
          </div>

          <div className="rounded-xl border border-white/10 bg-white/[0.03] p-6">
            <div><strong className="text-white">2. Gradient Descent (Iterative):</strong> Takes gradual downhill steps along the convex error surface. Scales effectively to millions of samples and dimensions.</div>
          </div>
        </div>
      </div>
    </section>

              <tr className="border-b border-white/10">

              </tr>
              <tr>
                <td className="px-5 py-4 font-semibold text-white">No Multicollinearity</td>
                <td className="px-5 py-4">Input features are not highly correlated with each other</td>
                <td className="px-5 py-4">Parameter weights fluctuate wildly</td>
              </tr>
            </tbody>
          </table>
