### 1. What is it?
Linear Regression models the relationship between an input feature $X$ and a continuous outcome $Y$ by fitting a straight line through observed data points.

### 2. Why do we need it?
When we need to predict continuous values—such as housing prices, temperature fluctuations, or sales forecasts—classification models fail. Linear regression provides a mathematically transparent baseline.

### 4. Mathematical Explanation
The hypothesis function is formulated as:

$$y = wx + b$$

Where:
* $w$ represents the slope (weight).
* $b$ represents the y-intercept (bias).
