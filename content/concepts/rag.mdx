      <h2 className="mb-6 border-l-4 border-blue-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
        1. What is RAG?
      </h2>

      <div className="space-y-5 text-[16px] leading-8 text-slate-300">
        <div>
          Retrieval-Augmented Generation (RAG) is an architectural pattern used to improve the <strong className="font-semibold text-white">quality, accuracy, and reliability</strong> of Large Language Models (LLMs).
        </div>

        <div>
          Instead of relying solely on the frozen knowledge the model memorized during its initial training, RAG bridges the gap by connecting the LLM to a live, external knowledge database.
        </div>

        <div className="my-7 rounded-xl border border-blue-400/15 bg-blue-400/[0.06] p-6">
          <div className="mb-3 font-semibold text-blue-200">The core mechanism:</div>
          <div className="space-y-3 text-slate-200">
            <div><strong>1. Retrieve:</strong> Search a private database for documents relevant to the user's query.</div>
            <div><strong>2. Augment:</strong> Inject those retrieved documents directly into the prompt.</div>
            <div><strong>3. Generate:</strong> Have the LLM answer the question using *only* the injected context.</div>
          </div>
        </div>
      </div>
    </section>

        3. The 4 Core Benefits of RAG
      </h2>

      <div className="space-y-6 text-[16px] leading-8 text-slate-300">
        <div className="grid gap-4 md:grid-cols-2">
          <div className="rounded-xl border border-white/10 bg-white/[0.03] p-6">
            <div className="mb-2 font-bold text-emerald-400">1. Reduces Hallucinations</div>
            <p className="text-sm leading-relaxed text-slate-400">LLMs don't know when they don't know something, which causes them to invent (hallucinate) facts. RAG forces the model to ground its answers strictly in the provided text.</p>
          </div>
          
          <div className="rounded-xl border border-white/10 bg-white/[0.03] p-6">
            <div className="mb-2 font-bold text-emerald-400">2. Keeps Knowledge Up-to-Date</div>
            <p className="text-sm leading-relaxed text-slate-400">A model trained in 2021 knows nothing about events in 2024. RAG allows you to query real-time data without needing to retrain the underlying model.</p>
          </div>

          <div className="rounded-xl border border-white/10 bg-white/[0.03] p-6">
            <div className="mb-2 font-bold text-emerald-400">3. Cost Effective</div>
            <p className="text-sm leading-relaxed text-slate-400">Training or fine-tuning an LLM is a massively expensive process. Updating a vector database with new documents is extremely cheap and instantaneous.</p>
          </div>

          <div className="rounded-xl border border-white/10 bg-white/[0.03] p-6">
            <div className="mb-2 font-bold text-emerald-400">4. Enterprise Data Privacy</div>
            <p className="text-sm leading-relaxed text-slate-400">Companies cannot expose sensitive private data to public LLMs. RAG only retrieves the specific snippets needed for a query, keeping the broader database secure.</p>
          </div>
        </div>
      </div>
    </section>

        6. The Mathematics of Retrieval (Similarity Search)
      </h2>

      <div className="space-y-6 text-[16px] leading-8 text-slate-300">
        <div>
          How does the database know which chunks match the query? An Embedding Model translates both the text chunks and the user's query into high-dimensional numerical vectors.
        </div>

        <div>
          The database then calculates the distance between the Query Vector ($\mathbf{A}$) and all Document Vectors ($\mathbf{B}$) using <strong className="font-semibold text-white">Cosine Similarity</strong>:
        </div>

        <div className="my-8 rounded-2xl border border-pink-400/15 bg-pink-400/[0.04] px-6 py-8 text-center text-xl">
          $$
          \text{Similarity} = \cos(\theta) = \frac{\mathbf{A} \cdot \mathbf{B}}{\|\mathbf{A}\| \|\mathbf{B}\|}
          $$
        </div>

        <div className="space-y-4">
          <div className="rounded-xl border border-white/10 bg-white/[0.03] p-5">
            <div><strong className="text-white">Why Cosine?</strong> It measures the *angle* between two vectors rather than their magnitude. This means a short user query ("Revenue growth") can perfectly match a long document paragraph about financial returns, as long as they point in the same semantic direction.</div>
          </div>
        </div>
      </div>
