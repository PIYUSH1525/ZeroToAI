      <div className="rounded-xl border border-amber-500/25 bg-[#0A0D16] p-5"><strong className="text-amber-300">Mental model:</strong><span className="text-slate-300"> logits are raw preference scores before normalization.</span></div>

    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>Softmax transforms logits into a probability distribution. The probabilities are non-negative and sum to 1.</div>

      <div className="rounded-2xl border border-amber-500/25 bg-amber-500/[0.04] p-6">
        <div className="mb-4 text-center font-mono text-xs font-bold uppercase tracking-widest text-amber-300">Logits → Softmax → Probabilities</div>

          <div className="rounded-xl border border-emerald-500/30 bg-emerald-500/10 p-5 text-center"><div className="text-[10px] uppercase text-emerald-400">Raw scores</div><div className="mt-3 font-mono text-xs">[8.4, 5.1, 4.7, -2.3]</div></div>

          <div className="rounded-xl border border-cyan-500/30 bg-cyan-500/10 p-5 text-center"><div className="text-[10px] uppercase text-cyan-400">Distribution</div><div className="mt-3 font-mono text-xs">[high, lower, lower, tiny]</div></div>
        </div>
      </div>

      <div>The decoding stage uses this distribution to decide which token becomes the next part of the response.</div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-violet-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">7. Intermediate: Top-k Sampling</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div><strong className="text-violet-300">Top-k sampling</strong> keeps only the k highest-probability candidates and samples from that smaller set.</div>
      <div className="rounded-2xl border border-violet-500/25 bg-violet-500/[0.04] p-6">
        <div className="mb-4 text-center font-mono text-xs font-bold uppercase tracking-widest text-violet-300">Example: k = 3</div>
        <div className="space-y-2 font-mono text-sm">
          <div className="rounded-lg border border-emerald-500/30 bg-emerald-500/10 p-3">1. Token A — 0.42</div>

          <div className="rounded-lg border border-emerald-500/30 bg-emerald-500/10 p-3">3. Token C — 0.17</div>
          <div className="rounded-lg border border-violet-500/30 bg-violet-500/10 p-3 text-violet-200">Keep A, B, C → sample from them</div>
          <div className="rounded-lg border border-white/10 bg-white/[0.03] p-3 text-slate-500">Other candidates → excluded</div>
        </div>
      </div>
      <div>Top-k controls the <strong className="text-white">number of candidates</strong>. After filtering, the remaining distribution can be renormalized for sampling.</div>
    </div>
  </section>

  <section>

    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div><strong className="text-indigo-300">Top-p</strong>, or nucleus sampling, keeps the smallest set of high-probability tokens whose cumulative probability reaches a chosen threshold p.</div>
      <div className="rounded-2xl border border-indigo-500/25 bg-indigo-500/[0.04] p-6">
        <div className="mb-4 text-center font-mono text-xs font-bold uppercase tracking-widest text-indigo-300">Example</div>
        <div className="space-y-2 font-mono text-sm">
          <div className="rounded-lg border border-indigo-500/30 bg-indigo-500/10 p-3">A — 0.50</div>
          <div className="rounded-lg border border-indigo-500/30 bg-indigo-500/10 p-3">B — 0.27</div>
          <div className="rounded-lg border border-indigo-500/30 bg-indigo-500/10 p-3">C — 0.12</div>
          <div className="rounded-lg border border-indigo-500/30 bg-indigo-500/10 p-3">D — 0.06</div>
          <div className="rounded-lg border border-indigo-500/30 bg-indigo-500/10 p-3">E — 0.05</div>
          <div className="rounded-lg border border-emerald-500/30 bg-emerald-500/10 p-3 text-emerald-200">p = 0.89 → keep enough candidates to reach the threshold</div>
        </div>
      </div>
      <div>Unlike top-k, the number of retained tokens can change at every generation step because the probability distribution changes.</div>
      <div className="grid gap-4 md:grid-cols-2">
        <div className="rounded-xl border border-violet-500/25 bg-violet-500/[0.04] p-5"><div className="mb-2 font-bold text-violet-300">Top-k</div><div className="text-sm text-slate-300">Fixed number of candidates.</div></div>
        <div className="rounded-xl border border-indigo-500/25 bg-indigo-500/[0.04] p-5"><div className="mb-2 font-bold text-indigo-300">Top-p</div><div className="text-sm text-slate-300">Variable number of candidates based on cumulative probability.</div></div>

    </div>
