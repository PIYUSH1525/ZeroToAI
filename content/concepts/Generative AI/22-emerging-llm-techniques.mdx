      3. Medium: Self-Consistency and Best-of-N
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        Two simple ways to use extra compute need no new training:
      </div>
      <div className="space-y-3">
        <div className="flex items-start gap-4 rounded-xl border border-blue-500/20 bg-blue-500/[0.04] p-4">
          <span className="flex h-8 w-8 shrink-0 items-center justify-center rounded-full bg-blue-500/20 font-mono text-sm font-bold text-blue-300">1</span>
          <div className="text-sm leading-relaxed"><strong className="text-white">Self-consistency:</strong> Ask the same question several times with randomness, then take the <strong className="text-white">most common</strong> final answer (a majority vote).</div>
        </div>
        <div className="flex items-start gap-4 rounded-xl border border-violet-500/20 bg-violet-500/[0.04] p-4">
          <span className="flex h-8 w-8 shrink-0 items-center justify-center rounded-full bg-violet-500/20 font-mono text-sm font-bold text-violet-300">2</span>
          <div className="text-sm leading-relaxed"><strong className="text-white">Best-of-N:</strong> Generate N answers and let a <strong className="text-white">verifier</strong> (a checker or a scoring model) pick the best one.</div>
        </div>
      </div>
      <div>
        Both work because errors are usually <strong className="text-white">scattered</strong> while the right answer tends to <strong className="text-white">repeat</strong>. If a single answer is right with probability $p > 0.5$ and the tries are independent, a majority vote gets more reliable as you add tries.
      </div>
      <div className="rounded-xl border border-emerald-500/20 bg-emerald-500/[0.05] p-5 text-sm leading-relaxed">
        <strong className="text-emerald-300">Real example from the code:</strong> If one answer is right 70% of the time, a majority vote of 21 tries is right about 97% of the time.
      </div>
      <div className="rounded-xl border border-amber-500/20 bg-amber-500/[0.05] p-5 text-sm leading-relaxed">
        <strong className="text-amber-300">Limits:</strong> Votes help only when the model is <em>usually</em> right. If it is usually wrong in the same way, more tries just repeat the same mistake.
      </div>
    </div>
  </section>

  <section>
    <h2 data-type="code" className="mb-6 border-l-4 border-teal-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
      7. Python Implementation: Majority Voting, Best-of-N and Distillation
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        This script calculates the accuracy of majority voting and best-of-N sampling with exact probabilities, then computes the soft teacher probabilities used in distillation and measures how close three different students are to the teacher with a KL distance.
      </div>
      <div className="overflow-hidden rounded-2xl border border-white/10 bg-[#060911]">
        <div className="flex items-center justify-between border-b border-white/10 bg-white/[0.03] px-5 py-3">
          <span className="font-mono text-xs font-semibold text-teal-400">test_time_compute.py</span>
          <span className="font-mono text-[11px] text-slate-400">Python 3.10+ · NumPy and the standard library</span>
        </div>
        <pre className="overflow-x-auto p-6 font-mono text-sm leading-7 text-slate-200">
          <code>
            <span className="block">import numpy as np</span>
            <span className="block">from math import comb</span>
            <span className="block">&nbsp;</span>
            <span className="block text-slate-500"># 1. Self-consistency: ask several times, take the majority answer</span>
            <span className="block text-cyan-300">def majority&#95;correct(p, n):</span>
            <span className="block text-slate-500">    # chance that more than half of n independent answers are right (n is odd)</span>
            <span className="block">    return sum(comb(n, k) &#42; p &#42;&#42; k &#42; (1 - p) &#42;&#42; (n - k) for k in range(n // 2 + 1, n + 1))</span>
            <span className="block">&nbsp;</span>
            <span className="block">for p in &#91;0.6, 0.7&#93;:</span>
            <span className="block">    print(&quot;single answer right&quot;, p, &quot;-&gt; majority of 5:&quot;, round(majority&#95;correct(p, 5), 3), &quot;| of 21:&quot;, round(majority&#95;correct(p, 21), 3))</span>
            <span className="block">&nbsp;</span>
            <span className="block text-slate-500"># 2. Best-of-n with a verifier: chance that at least one of n samples is correct</span>
            <span className="block">for p in &#91;0.1, 0.3&#93;:</span>
            <span className="block">    print(&quot;one sample right&quot;, p, &quot;-&gt; best of 8 (perfect verifier):&quot;, round(1 - (1 - p) &#42;&#42; 8, 3))</span>
            <span className="block">&nbsp;</span>
            <span className="block text-slate-500"># 3. Distillation: the student learns from the teacher&apos;s soft probabilities</span>
            <span className="block text-cyan-300">def softmax(z, T=1.0):</span>
            <span className="block">    z = np.array(z) / T</span>
            <span className="block">    e = np.exp(z - z.max())</span>
            <span className="block">    return e / e.sum()</span>
            <span className="block">&nbsp;</span>
            <span className="block">teacher&#95;logits = &#91;4.0, 2.0, 0.5&#93;</span>
            <span className="block">for T in &#91;1.0, 3.0&#93;:</span>
            <span className="block">    print(&quot;teacher probabilities at temperature&quot;, T, &quot;-&gt;&quot;, np.round(softmax(teacher&#95;logits, T), 3))</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def kl(p, q):</span>
            <span className="block">    return float(np.sum(p &#42; np.log(p / q)))</span>
            <span className="block">&nbsp;</span>
