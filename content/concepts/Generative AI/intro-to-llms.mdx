    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        A <strong className="text-white">Large Language Model (LLM)</strong> is a machine learning model designed to understand, process, and generate human language. Modern LLMs (such as GPT-4, Claude, Gemini, and Llama-3) are built using the <strong className="text-cyan-300">Transformer</strong> architecture.

          <div className="text-xs leading-relaxed text-slate-300">

          </div>
        </div>

        <div className="rounded-xl border border-violet-500/25 bg-violet-500/[0.04] p-5">
          <div className="mb-1 font-mono text-xs font-bold uppercase text-violet-400">Scale #2 · Dataset Size</div>
          <div className="mb-2 text-base font-bold text-white">Trillions of Words</div>
          <div className="text-xs leading-relaxed text-slate-300">

          <div className="text-xs leading-relaxed text-slate-300">
            Adjusting billions of parameters across trillions of words requires thousands of specialized AI chips (GPUs/TPUs) running parallel matrix math for weeks or months.

        <h3 className="mb-3 text-xl font-bold text-white">What Does an LLM Actually Learn During Training?</h3>
        <div>
          During training, an autoregressive LLM plays the <strong className="text-cyan-300">Next-Token Prediction Game</strong> billions of times: it reads a partial sentence, guesses the next token, checks the real answer, and nudges its parameters to be slightly more accurate next time:

      <div>
        By trying to predict the next token across trillions of sentences, the model&apos;s numerical parameters automatically absorb <strong className="text-white">three layers of patterns</strong>:

          </div>
        </div>
        <div className="rounded-xl border border-violet-500/25 bg-violet-500/[0.04] p-5">
          <div className="mb-2 font-bold text-violet-300">2. Concept Associations</div>

    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        Here is a clean, beginner-friendly PyTorch script that brings every concept from this lesson to life in 30 lines of code—showing how text turns into <strong className="text-cyan-300">Tokens</strong>, how a tiny Language Model holds <strong className="text-violet-300">Parameters</strong>, and the exact code difference between <strong className="text-emerald-300">Training</strong> (updating parameters) and <strong className="text-amber-300">Inference</strong> (generating the next token with frozen parameters):
      </div>

      <div className="overflow-hidden rounded-2xl border border-white/10 bg-[#060911]">
        <div className="flex items-center justify-between border-b border-white/10 bg-white/[0.03] px-5 py-3">
          <span className="font-mono text-xs font-semibold text-teal-400">intro_to_llms_demo.py</span>
          <span className="font-mono text-[11px] text-slate-400">Python 3.11+ · PyTorch 2.x</span>
        </div>
        <pre className="overflow-x-auto p-6 font-mono text-sm leading-7 text-slate-200">
          <code>
            <span className="block text-cyan-300">import torch</span>
            <span className="block text-cyan-300">import torch.nn as nn</span>
            <span className="block">import torch.nn.functional as F</span>
            <span className="block">&nbsp;</span>
            <span className="block text-slate-500"># 1. Mini Vocabulary: Map Words to Token IDs</span>
            <span className="block">vocab = [&quot;Machine&quot;, &quot;learning&quot;, &quot;is&quot;, &quot;useful&quot;, &quot;&lt;EOS&gt;&quot;]</span>
            <span className="block">wordToId = &#123;w: i for i, w in enumerate(vocab)&#125;</span>
            <span className="block">&nbsp;</span>
            <span className="block text-slate-500"># 2. Define a Tiny Next-Token Language Model</span>
            <span className="block text-cyan-300">class TinyLanguageModel(nn.Module):</span>
            <span className="block">    def __init__(self, vocabSize: int, embedDim: int = 16):</span>
            <span className="block">        super().__init__()</span>
            <span className="block text-violet-300">        self.tokenEmbed = nn.Embedding(vocabSize, embedDim)</span>
            <span className="block text-violet-300">        self.nextTokenHead = nn.Linear(embedDim, vocabSize)</span>
            <span className="block">&nbsp;</span>
            <span className="block">    def forward(self, tokenIds: torch.Tensor) -&gt; torch.Tensor:</span>
            <span className="block">        # Average context embeddings and predict scores (logits) for the next token</span>
            <span className="block">        contextVec = self.tokenEmbed(tokenIds).mean(dim=0)</span>
            <span className="block">        return self.nextTokenHead(contextVec)</span>
            <span className="block">&nbsp;</span>
            <span className="block">torch.manual_seed(42)</span>
            <span className="block">model = TinyLanguageModel(vocabSize=len(vocab))</span>
            <span className="block">totalParams = sum(p.numel() for p in model.parameters())</span>
            <span className="block text-emerald-300">print(f&quot;Total Learned Parameters in Model: &#123;totalParams&#125;&quot;)</span>
            <span className="block">&nbsp;</span>
            <span className="block text-slate-500"># 3. TRAINING PHASE: Adjust parameters to predict &quot;useful&quot; after &quot;Machine learning is&quot;</span>
            <span className="block">promptIds = torch.tensor([wordToId[&quot;Machine&quot;], wordToId[&quot;learning&quot;], wordToId[&quot;is&quot;]])</span>
            <span className="block">targetId  = torch.tensor(wordToId[&quot;useful&quot;])</span>
            <span className="block">optimizer = torch.optim.Adam(model.parameters(), lr=0.1)</span>
            <span className="block">&nbsp;</span>
            <span className="block">for step in range(30):</span>
            <span className="block">    optimizer.zero_grad()</span>
            <span className="block">    loss = F.cross_entropy(model(promptIds), targetId)</span>
            <span className="block">    loss.backward()</span>
            <span className="block text-violet-300">    optimizer.step()   # &lt;-- Updates the model&apos;s parameters!</span>
            <span className="block">&nbsp;</span>
            <span className="block text-slate-500"># 4. INFERENCE PHASE: Freeze parameters (torch.no_grad) and generate the next word!</span>
            <span className="block text-cyan-300">with torch.no_grad():</span>
            <span className="block">    probs = F.softmax(model(promptIds), dim=-1)</span>
            <span className="block">    predictedId = int(torch.argmax(probs).item())</span>
            <span className="block text-emerald-300">print(&quot;Prompt: &apos;Machine learning is&apos; -&gt; Predicted Next Token:&quot;, vocab[predictedId], f&quot;(&#123;probs[predictedId]:.1%&#125; confidence)&quot;)</span>
          </code>
        </pre>
      </div>

      <div className="rounded-xl border border-teal-500/20 bg-teal-500/[0.05] p-5 text-sm leading-7 text-slate-300">
        <div className="mb-2 font-bold text-teal-300">
          Pro Tip (Look at Step 3 vs. Step 4 in the Code Above!):
        </div>
        <div>
          In <strong>Step 3 (Training)</strong>, calling <code>loss.backward()</code> and <code>optimizer.step()</code> modifies the model&apos;s parameters so it learns that <code>&quot;useful&quot;</code> follows <code>&quot;Machine learning is&quot;</code>. In <strong>Step 4 (Inference)</strong>, wrapping the call in <strong className="text-white"><code>with torch.no_grad():</code></strong> freezes the parameters and simply predicts the next token with $99.8\%$ confidence!
