      <div className="space-y-5 text-[16px] leading-8 text-slate-300">
        <div>A <strong>Large Language Model (LLM)</strong> is a machine learning model designed to process and generate human language. Modern LLMs are predominantly built with the <strong>Transformer</strong> architecture and contain a very large number of learned parameters.</div>
        <div>The word <em>"large"</em> does not describe only one thing. It usually refers to the scale of the model and the scale of the data and computation used to train it.</div>

        <div className="my-6 grid gap-4 md:grid-cols-2">
          <div className="rounded-xl border border-slate-700/50 bg-slate-800/20 p-5">
            <div className="mb-3 font-semibold text-white">Large Model</div>
            <div className="text-sm leading-relaxed text-slate-400">An LLM can contain millions, billions, or even more learned parameters. These numerical values are adjusted during training and collectively determine how the model responds to its input.</div>
          </div>
          <div className="rounded-xl border border-blue-400/20 bg-blue-400/[0.06] p-5">
            <div className="mb-3 font-semibold text-blue-200">Large Dataset</div>
            <div className="text-sm leading-relaxed text-slate-300">LLMs are trained on very large collections of text and other training data. Depending on the model, this can include books, websites, code, documents, and other sources.</div>
          </div>
        </div>

        <div className="rounded-xl border border-white/10 bg-white/[0.03] p-5">
          <strong className="text-white">Important:</strong> An LLM is not a traditional database that stores a sentence for every possible question. Its learned behavior is represented mainly through numerical parameters learned during training.
        </div>
      </div>
    </section>

    <section>
      <h2 className="mb-6 border-l-4 border-violet-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">2. Why Do We Need LLMs?</h2>
      <div className="space-y-6 text-[16px] leading-8 text-slate-300">
        <div>Human language is extremely flexible. The same idea can be expressed in many different ways, and users can ask questions or give instructions that were never explicitly written as rules by a programmer.</div>
        <div>Traditional software normally follows rules written by people. LLMs instead learn statistical patterns from large datasets and use those learned patterns to process new language inputs.</div>

        <div className="my-6 grid gap-4 md:grid-cols-2">
          <div className="rounded-xl border border-slate-700/50 bg-slate-800/20 p-5">
            <div className="mb-3 font-semibold text-white">Traditional Rule-Based Approach</div>
            <div className="text-sm leading-relaxed text-slate-400">A programmer explicitly defines how different inputs should be handled. This works well when the rules are clear and manageable.</div>
          </div>
          <div className="rounded-xl border border-violet-400/20 bg-violet-400/[0.06] p-5">
            <div className="mb-3 font-semibold text-violet-200">LLM Approach</div>
            <div className="text-sm leading-relaxed text-slate-300">The model learns patterns from examples and large-scale training data, allowing one model to handle many language tasks without a separate hand-written rule for every possible sentence.</div>
          </div>
        </div>
        <div>This is why one LLM can support many language tasks: answering questions, summarizing text, rewriting content, translating languages, generating code, and more.</div>
      </div>
