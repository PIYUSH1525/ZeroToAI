  <section>
    <h2 className="mb-6 border-l-4 border-blue-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
      1. Beginner: What Is a Modern LLM Made Of?
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        The original Transformer from 2017 had two halves: an <strong className="text-white">encoder</strong> that reads and a <strong className="text-white">decoder</strong> that writes. Today&apos;s chatbots such as GPT-style, Llama-style and Mistral-style models keep <strong className="text-white">only the decoder half</strong> and stack it many times. This design is called a <strong className="text-white">decoder-only</strong> Transformer.
      </div>
      <div>
        A decoder-only model is just one block repeated, for example 32 times for a 7B model or 80 times for a 70B model. Each block has two jobs: an <strong className="text-white">attention</strong> part that mixes information between tokens, and a <strong className="text-white">feed-forward</strong> part that processes each token on its own.
      </div>
      <div className="grid gap-5 md:grid-cols-3">
        <div className="rounded-xl border border-blue-500/25 bg-blue-500/[0.04] p-6">

          </div>
          <div className="mt-2 space-y-2 text-xs leading-relaxed text-slate-300">
            <div>Turns each token id into a vector of numbers.</div>
          </div>
        </div>
        <div className="rounded-xl border border-violet-500/25 bg-violet-500/[0.04] p-6">
          <div className="mb-1 flex items-center justify-between">
            <span className="font-bold text-violet-300">N × Decoder Block</span>
            <span className="rounded bg-violet-950/80 px-2 py-0.5 font-mono text-xs text-violet-300">The repeated part</span>
          </div>
          <div className="mt-2 space-y-2 text-xs leading-relaxed text-slate-300">
            <div>Attention + feed-forward, each with a residual shortcut and a normalization step.</div>

  <section>
    <h2 className="mb-6 border-l-4 border-emerald-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
      3. Medium: RMSNorm and SwiGLU, the Two Quiet Upgrades
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        <strong className="text-white">Normalization</strong> keeps the numbers flowing through a deep network at a healthy size. LayerNorm subtracts the average and divides by the spread. <strong className="text-white">RMSNorm</strong> skips the subtraction and only rescales by the root-mean-square (RMS), which is simpler and works just as well in practice.
      </div>
      <div className="rounded-xl border border-white/10 bg-[#060913] p-5 text-center text-white">
        $$\text{RMSNorm}(x) = \frac{x}{\sqrt{\frac{1}{d}\sum_i x_i^2 + \epsilon}} \cdot g$$
      </div>
      <div>
        The <strong className="text-white">feed-forward</strong> part of each block used to be two matrices with a ReLU in the middle. SwiGLU uses <strong className="text-white">three</strong> matrices: a <em>gate</em> decides how much of an <em>up</em> signal is allowed through, then a <em>down</em> matrix returns to the model size.
      </div>
      <div className="rounded-xl border border-white/10 bg-[#060913] p-5 text-center text-white">
        $$\text{SwiGLU}(x) = \big(\text{SiLU}(xW_{gate}) \odot xW_{up}\big)\, W_{down}$$
      </div>
      <div className="rounded-xl border border-amber-500/20 bg-amber-500/[0.05] p-5 text-sm leading-relaxed">
        <strong className="text-amber-300">Plain English:</strong> Think of a water pipe with a tap. The <em>up</em> path is the water, the <em>gate</em> is the tap that decides how much flows, and <em>down</em> collects it into the right size pipe. Because the tap is learned, the network can switch information on and off per token.
      </div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-orange-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
      4. Medium: Pre-Norm Blocks and Residual Shortcuts
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        Each decoder block follows the same recipe. The input is <strong className="text-white">normalized first</strong>, passed through a sublayer, and then <strong className="text-white">added back</strong> to the original input. This add-back is the <em>residual connection</em>, a shortcut that lets information and gradients flow straight through the whole stack.
      </div>
      <div className="space-y-3">
        <div className="flex items-start gap-4 rounded-xl border border-blue-500/20 bg-blue-500/[0.04] p-4">
          <span className="flex h-8 w-8 shrink-0 items-center justify-center rounded-full bg-blue-500/20 font-mono text-sm font-bold text-blue-300">1</span>
          <div className="text-sm leading-relaxed"><strong className="text-white">RMSNorm:</strong> Rescale the incoming vector.</div>
        </div>
        <div className="flex items-start gap-4 rounded-xl border border-violet-500/20 bg-violet-500/[0.04] p-4">
          <span className="flex h-8 w-8 shrink-0 items-center justify-center rounded-full bg-violet-500/20 font-mono text-sm font-bold text-violet-300">2</span>
          <div className="text-sm leading-relaxed"><strong className="text-white">Attention with GQA and RoPE:</strong> Tokens look back at earlier tokens. RoPE is applied to Q and K.</div>
        </div>
        <div className="flex items-start gap-4 rounded-xl border border-emerald-500/20 bg-emerald-500/[0.04] p-4">
          <span className="flex h-8 w-8 shrink-0 items-center justify-center rounded-full bg-emerald-500/20 font-mono text-sm font-bold text-emerald-300">3</span>
          <div className="text-sm leading-relaxed"><strong className="text-white">Add the shortcut:</strong> Result = original input + attention output.</div>
        </div>
        <div className="flex items-start gap-4 rounded-xl border border-orange-500/20 bg-orange-500/[0.04] p-4">
          <span className="flex h-8 w-8 shrink-0 items-center justify-center rounded-full bg-orange-500/20 font-mono text-sm font-bold text-orange-300">4</span>
          <div className="text-sm leading-relaxed"><strong className="text-white">RMSNorm, then SwiGLU feed-forward:</strong> Each token is processed on its own.</div>
        </div>
        <div className="flex items-start gap-4 rounded-xl border border-rose-500/20 bg-rose-500/[0.04] p-4">
          <span className="flex h-8 w-8 shrink-0 items-center justify-center rounded-full bg-rose-500/20 font-mono text-sm font-bold text-rose-300">5</span>
          <div className="text-sm leading-relaxed"><strong className="text-white">Add the shortcut again:</strong> Result = previous result + feed-forward output.</div>
        </div>
      </div>
      <div className="rounded-xl border border-blue-500/20 bg-blue-500/[0.05] p-5 text-sm leading-relaxed">
        <strong className="text-blue-300">Why pre-norm?</strong> Putting the normalization <strong className="text-white">before</strong> the sublayer keeps the shortcut path clean. That makes it much easier to train networks with dozens of layers without the signal blowing up or fading away.
      </div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-cyan-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
      5. Advanced: Mixture of Experts (MoE)
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        Making a model bigger usually makes it slower, because every token passes through every parameter. A <strong className="text-white">Mixture of Experts</strong> model breaks the feed-forward part into several smaller <strong className="text-white">experts</strong> and adds a tiny <strong className="text-white">router</strong>. For each token the router picks only a few experts, such as 2 out of 8, and the rest stay idle.
      </div>
      <div className="grid gap-5 md:grid-cols-2">
        <div className="rounded-xl border border-blue-500/25 bg-blue-500/[0.04] p-6">
          <div className="mb-1 flex items-center justify-between">
            <span className="font-bold text-blue-300">Dense model</span>
            <span className="rounded bg-blue-950/80 px-2 py-0.5 font-mono text-xs text-blue-300">Every parameter works</span>
          </div>
          <div className="mt-2 space-y-2 text-xs leading-relaxed text-slate-300">
            <div><strong className="text-white">Per token:</strong> All parameters are used</div>
            <div><strong className="text-white">Cost:</strong> Grows with total size</div>
            <div><strong className="text-white">Example idea:</strong> A 7B model uses 7B parameters every step</div>
          </div>
        </div>
        <div className="rounded-xl border border-emerald-500/25 bg-emerald-500/[0.04] p-6">
          <div className="mb-1 flex items-center justify-between">
            <span className="font-bold text-emerald-300">Mixture of Experts</span>
            <span className="rounded bg-emerald-950/80 px-2 py-0.5 font-mono text-xs text-emerald-300">Only some experts work</span>
          </div>
          <div className="mt-2 space-y-2 text-xs leading-relaxed text-slate-300">
            <div><strong className="text-white">Per token:</strong> Router picks the top few experts</div>
            <div><strong className="text-white">Cost:</strong> Grows with the <em>active</em> size, not the total size</div>
            <div><strong className="text-white">Example idea:</strong> A model with 8 experts can hold far more knowledge than it uses on any one token</div>
          </div>
        </div>
      </div>
      <div className="rounded-xl border border-amber-500/20 bg-amber-500/[0.05] p-5 text-sm leading-relaxed">
        <strong className="text-amber-300">Trade-off:</strong> MoE models are cheap to <strong className="text-white">run</strong> per token but still need memory for <strong className="text-white">all</strong> experts, and they are trickier to train because the router must spread work evenly. Several well-known recent open and closed models use this design.
      </div>
      <div className="rounded-xl border border-white/10 bg-white/[0.03] p-5">
        <div className="mb-2 font-bold text-white">A quick parameter count</div>
        <div className="text-sm leading-relaxed text-slate-300">A Llama-style 7B model has about 6.74 billion parameters: embeddings (131 million), then 32 blocks of attention (about 67 million each with full multi-head) and SwiGLU feed-forward (about 135 million each), plus an output head. The code below counts them exactly.</div>
      </div>

    <h2 data-type="code" className="mb-6 border-l-4 border-teal-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
      7. Python Implementation: RMSNorm, SwiGLU and a Parameter Counter
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        This script builds the two quiet upgrades from scratch, <strong className="text-white">RMSNorm</strong> and a <strong className="text-white">SwiGLU</strong> feed-forward layer, and then counts the parameters of a Llama-style 7B model. The counter reproduces the well-known figure of about 6.74 billion and shows how GQA makes the model smaller.
      </div>
      <div className="overflow-hidden rounded-2xl border border-white/10 bg-[#060911]">
        <div className="flex items-center justify-between border-b border-white/10 bg-white/[0.03] px-5 py-3">
          <span className="font-mono text-xs font-semibold text-teal-400">modern_llm_block.py</span>
          <span className="font-mono text-[11px] text-slate-400">Python 3.10+ · NumPy only</span>
        </div>
        <pre className="overflow-x-auto p-6 font-mono text-sm leading-7 text-slate-200">
          <code>
            <span className="block">import numpy as np</span>
            <span className="block">&nbsp;</span>
            <span className="block">rng = np.random.default_rng(0)</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def layer_norm(x, eps=1e-5):</span>
            <span className="block">    return (x - x.mean(-1, keepdims=True)) / np.sqrt(x.var(-1, keepdims=True) + eps)</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def rms_norm(x, weight, eps=1e-5):</span>
            <span className="block">    rms = np.sqrt(np.mean(x ** 2, axis=-1, keepdims=True) + eps)</span>
            <span className="block">    return x / rms * weight</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def silu(x):</span>
            <span className="block">    return x / (1 + np.exp(-x))</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def swiglu_ffn(x, W_gate, W_up, W_down):</span>
            <span className="block">    return (silu(x @ W_gate) * (x @ W_up)) @ W_down      # gate decides how much of &quot;up&quot; passes</span>
            <span className="block">&nbsp;</span>
            <span className="block">d_model, d_ff = 8, 16</span>
            <span className="block">x = rng.normal(size=(3, d_model)) * 5 + 2                 # 3 tokens with large, off-center values</span>
            <span className="block">weight = np.ones(d_model)</span>
            <span className="block">&nbsp;</span>
            <span className="block">normed = rms_norm(x, weight)</span>
            <span className="block">print(&quot;RMS of each token after RMSNorm:&quot;, np.round(np.sqrt(np.mean(normed ** 2, axis=-1)), 3))</span>
            <span className="block">print(&quot;Largest mean left after LayerNorm:&quot;, round(float(np.abs(layer_norm(x).mean(-1)).max()), 6), &quot;(LayerNorm also re-centers to zero)&quot;)</span>
            <span className="block">&nbsp;</span>
            <span className="block">W_gate = rng.normal(size=(d_model, d_ff)) * 0.3</span>
            <span className="block">W_up = rng.normal(size=(d_model, d_ff)) * 0.3</span>
            <span className="block">W_down = rng.normal(size=(d_ff, d_model)) * 0.3</span>
            <span className="block">out = swiglu_ffn(normed, W_gate, W_up, W_down)</span>
            <span className="block">print(&quot;SwiGLU output shape:&quot;, out.shape)</span>
            <span className="block">&nbsp;</span>
            <span className="block text-slate-500"># Count the parameters of a Llama-style decoder</span>
            <span className="block text-cyan-300">def count_params(layers, d_model, d_ff, vocab, heads, kv_heads, tied_embeddings=False):</span>
