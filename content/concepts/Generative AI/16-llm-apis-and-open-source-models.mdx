      1. Beginner: What Is an LLM API?
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        An <strong className="text-white">API</strong> (Application Programming Interface) lets your code talk to a model that runs on someone else&apos;s servers. You send a request over the internet and get the model&apos;s answer back. You do not manage GPUs, you only pay for what you use.
      </div>
      <div>
        Almost every provider uses the same basic idea: you send a list of <strong className="text-white">messages</strong> and settings, and you receive a <strong className="text-white">completion</strong>.
      </div>
      <div className="space-y-3">
        <div className="flex items-start gap-4 rounded-xl border border-blue-500/20 bg-blue-500/[0.04] p-4">

          <div className="text-sm leading-relaxed"><strong className="text-white">Build the request:</strong> A JSON body with the model name, the messages and settings such as temperature and max tokens.</div>
        </div>
        <div className="flex items-start gap-4 rounded-xl border border-violet-500/20 bg-violet-500/[0.04] p-4">
          <span className="flex h-8 w-8 shrink-0 items-center justify-center rounded-full bg-violet-500/20 font-mono text-sm font-bold text-violet-300">2</span>
          <div className="text-sm leading-relaxed"><strong className="text-white">Send it securely:</strong> An HTTPS call with your secret API key in a header.</div>
        </div>
        <div className="flex items-start gap-4 rounded-xl border border-emerald-500/20 bg-emerald-500/[0.04] p-4">
          <span className="flex h-8 w-8 shrink-0 items-center justify-center rounded-full bg-emerald-500/20 font-mono text-sm font-bold text-emerald-300">3</span>

    <h2 className="mb-6 border-l-4 border-emerald-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
      3. Medium: Cost, Speed and Keys
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        Providers bill by <strong className="text-white">tokens</strong>, usually per million, with separate prices for <strong className="text-white">input</strong> and <strong className="text-white">output</strong> tokens. Output tokens are normally more expensive. A quick estimate:
      </div>
      <div className="rounded-xl border border-white/10 bg-[#060913] p-5 text-center text-white">
        $$\text{cost} = \frac{\text{input tokens} \times \text{input price} + \text{output tokens} \times \text{output price}}{1{,}000{,}000}$$
      </div>
      <div className="rounded-xl border border-rose-500/20 bg-rose-500/[0.05] p-5 text-sm leading-relaxed">
        <strong className="text-rose-300">Protect your API key:</strong> Treat it like a password. Keep it in an environment variable on a <strong className="text-white">server</strong>. Never put it in browser code, a public repository or a mobile app. Anyone who has it can spend your money.
      </div>
      <div className="rounded-xl border border-white/10 bg-white/[0.03] p-5">
        <div className="mb-2 font-bold text-white">Ways to save money</div>
        <div className="text-sm leading-relaxed text-slate-300">Choose the smallest model that does the job, shorten prompts, cap max tokens, cache repeated prefixes, and send simple tasks to cheaper models.</div>
      </div>
    </div>
  </section>

    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">

              <th className="px-5 py-3">Typical response</th>
              <th className="px-5 py-3">What your code should do</th>
            </tr>
          </thead>
          <tbody className="divide-y divide-white/5 text-slate-300">
            <tr><td className="px-5 py-3 font-semibold text-white">Rate limit (HTTP 429)</td><td className="px-5 py-3">Too many requests</td><td className="px-5 py-3">Wait and retry with <strong className="text-white">exponential backoff</strong>: 1, 2, 4, 8 seconds</td></tr>
            <tr><td className="px-5 py-3 font-semibold text-white">Server error (5xx)</td><td className="px-5 py-3">Provider problem</td><td className="px-5 py-3">Retry a few times, then show a friendly message</td></tr>
            <tr><td className="px-5 py-3 font-semibold text-white">Timeout</td><td className="px-5 py-3">No answer in time</td><td className="px-5 py-3">Set a timeout and retry once or twice</td></tr>
            <tr><td className="px-5 py-3 font-semibold text-white">Invalid request (4xx)</td><td className="px-5 py-3">Your request is wrong</td><td className="px-5 py-3">Do not retry. Fix the request</td></tr>
            <tr><td className="px-5 py-3 font-semibold text-white">Context too long</td><td className="px-5 py-3">Prompt exceeds the window</td><td className="px-5 py-3">Shorten or summarize before sending</td></tr>
