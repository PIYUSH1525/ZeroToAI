              <th className="px-5 py-3">Use for</th>
            </tr>
          </thead>
          <tbody className="divide-y divide-white/5 text-slate-300">
            <tr><td className="px-5 py-3 font-semibold text-white">Accuracy / exact match</td><td className="px-5 py-3">Share of answers that match the expected answer</td><td className="px-5 py-3">Classification, short factual answers</td></tr>
            <tr><td className="px-5 py-3 font-semibold text-white">Perplexity</td><td className="px-5 py-3">How surprised the model is by real text. Lower is better</td><td className="px-5 py-3">Comparing language models on the same text</td></tr>
            <tr><td className="px-5 py-3 font-semibold text-white">pass@k</td><td className="px-5 py-3">Chance that at least one of k tries passes the tests</td><td className="px-5 py-3">Code generation</td></tr>
            <tr><td className="px-5 py-3 font-semibold text-white">ROUGE / BLEU</td><td className="px-5 py-3">Word overlap with a reference text</td><td className="px-5 py-3">Summaries and translation (weak for meaning)</td></tr>
            <tr><td className="px-5 py-3 font-semibold text-white">Elo / win rate</td><td className="px-5 py-3">Ratings from head-to-head comparisons</td><td className="px-5 py-3">Overall chat quality</td></tr>
          </tbody>
        </table>
      </div>
      <div>
        For code, <strong className="text-white">pass@k</strong> is computed from $n$ samples of which $c$ are correct:
      </div>
      <div className="rounded-xl border border-white/10 bg-[#060913] p-5 text-center text-white">
        $$\text{pass@}k = 1 - \frac{\binom{n-c}{k}}{\binom{n}{k}}$$
      </div>
      <div className="rounded-xl border border-emerald-500/20 bg-emerald-500/[0.05] p-5 text-sm leading-relaxed">
        <strong className="text-emerald-300">Perplexity in one line:</strong> It is $e$ raised to the average negative log-probability of the correct tokens. A perplexity of 3 means the model is as unsure as choosing between 3 equally likely words.
      </div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-orange-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
      4. Medium: LLM-as-Judge and Pairwise Comparison
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        Humans find it much easier to say which of <strong className="text-white">two answers is better</strong> than to give a score. Two popular methods build on this. In <strong className="text-white">human or AI pairwise comparisons</strong>, a judge sees two answers and picks a winner; many comparisons are combined into <strong className="text-white">Elo-style ratings</strong>. In <strong className="text-white">LLM-as-judge</strong>, a strong model grades answers using a written rubric, which is cheap and fast.
      </div>
      <div className="overflow-x-auto rounded-2xl border border-white/10">
        <table className="w-full text-left text-sm">
          <thead className="bg-white/[0.04] text-xs uppercase tracking-wider text-slate-400">
            <tr>
              <th className="px-5 py-3">Judge bias</th>
              <th className="px-5 py-3">What happens</th>
              <th className="px-5 py-3">Fix</th>
            </tr>
          </thead>
          <tbody className="divide-y divide-white/5 text-slate-300">
            <tr><td className="px-5 py-3 font-semibold text-white">Position bias</td><td className="px-5 py-3">Prefers the answer shown first (or last)</td><td className="px-5 py-3">Run each pair twice with the order swapped</td></tr>
            <tr><td className="px-5 py-3 font-semibold text-white">Length bias</td><td className="px-5 py-3">Prefers longer answers</td><td className="px-5 py-3">Tell the judge to ignore length, or control for it</td></tr>
            <tr><td className="px-5 py-3 font-semibold text-white">Self-preference</td><td className="px-5 py-3">A model rates its own style higher</td><td className="px-5 py-3">Use a different model as judge</td></tr>
            <tr><td className="px-5 py-3 font-semibold text-white">Vague rubric</td><td className="px-5 py-3">Scores are inconsistent</td><td className="px-5 py-3">Write a clear rubric with examples</td></tr>
          </tbody>
        </table>
      </div>
      <div className="rounded-xl border border-amber-500/20 bg-amber-500/[0.05] p-5 text-sm leading-relaxed">
        <strong className="text-amber-300">Always check the judge:</strong> Compare the judge&apos;s scores with a small set of human ratings. If they disagree a lot, the judge cannot be trusted.
      </div>
    </div>
  </section>

      7. Python Implementation: Intervals, pass@k, Elo and Perplexity
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        This script computes four evaluation tools from scratch: an accuracy confidence interval (Wilson), the pass@k estimator for code, Elo ratings from head-to-head results, and perplexity from token probabilities.
      </div>
      <div className="overflow-hidden rounded-2xl border border-white/10 bg-[#060911]">

          <code>
            <span className="block">import numpy as np</span>
            <span className="block">from math import comb, sqrt</span>
            <span className="block">&nbsp;</span>
            <span className="block text-slate-500"># 1. Accuracy with an honest uncertainty range (Wilson 95% interval)</span>
            <span className="block text-cyan-300">def accuracy&#95;with&#95;interval(correct, total, z=1.96):</span>
            <span className="block">    p = correct / total</span>
            <span className="block">    centre = (p + z &#42; z / (2 &#42; total)) / (1 + z &#42; z / total)</span>
            <span className="block">    half = z &#42; sqrt(p &#42; (1 - p) / total + z &#42; z / (4 &#42; total &#42; total)) / (1 + z &#42; z / total)</span>
            <span className="block">    return p, centre - half, centre + half</span>
            <span className="block">&nbsp;</span>
            <span className="block">for total in &#91;50, 500&#93;:</span>
            <span className="block">    p, lo, hi = accuracy&#95;with&#95;interval(int(0.8 &#42; total), total)</span>
            <span className="block">    print(&quot;80% on&quot;, total, &quot;questions -&gt; true accuracy is probably between&quot;, round(lo &#42; 100, 1), &quot;% and&quot;, round(hi &#42; 100, 1), &quot;%&quot;)</span>
            <span className="block">&nbsp;</span>
            <span className="block text-slate-500"># 2. pass@k: chance that at least one of k tries solves the problem</span>
            <span className="block text-cyan-300">def pass&#95;at&#95;k(n, c, k):</span>
            <span className="block">    if n - c &lt; k:</span>
            <span className="block">        return 1.0</span>
            <span className="block">    return 1 - comb(n - c, k) / comb(n, k)</span>
            <span className="block">&nbsp;</span>
            <span className="block">print(&quot;20 tries, 5 correct -&gt; pass@1:&quot;, round(pass&#95;at&#95;k(20, 5, 1), 3), &quot;| pass@5:&quot;, round(pass&#95;at&#95;k(20, 5, 5), 3), &quot;| pass@10:&quot;, round(pass&#95;at&#95;k(20, 5, 10), 3))</span>
            <span className="block">&nbsp;</span>
            <span className="block text-slate-500"># 3. Pairwise comparisons turned into ratings (Elo)</span>
            <span className="block">ratings = &#123;&quot;model A&quot;: 1000.0, &quot;model B&quot;: 1000.0&#125;</span>
