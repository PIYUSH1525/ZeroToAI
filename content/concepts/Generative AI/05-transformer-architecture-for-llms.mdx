  <section>
    <h2 className="mb-6 border-l-4 border-blue-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">1. Beginner: What Is a Transformer?</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>A <strong className="text-cyan-300">Transformer</strong> is a neural-network architecture built around attention. It allows token representations to interact with one another and has become the foundation of most modern large language models.</div>

      <div>For a decoder-only LLM, the high-level pipeline is:</div>

      <div className="rounded-3xl border border-white/10 bg-[#060913] p-6 sm:p-8">
        <div className="space-y-3 font-mono text-xs">
          <div className="rounded-xl border border-cyan-500/30 bg-cyan-500/10 p-4 text-center text-cyan-200">INPUT TEXT<div className="mt-1 text-xs text-slate-400">"The cat sat on the mat"</div></div>
          <div className="text-center text-cyan-400">↓</div>
          <div className="rounded-xl border border-violet-500/30 bg-violet-500/10 p-4 text-center text-violet-200">TOKENIZATION<div className="mt-1 text-xs text-slate-400">Text → token IDs</div></div>
          <div className="text-center text-violet-400">↓</div>
          <div className="rounded-xl border border-emerald-500/30 bg-emerald-500/10 p-4 text-center text-emerald-200">TOKEN EMBEDDINGS + POSITIONAL INFORMATION</div>
          <div className="text-center text-emerald-400">↓</div>
          <div className="rounded-xl border border-indigo-500/30 bg-indigo-500/10 p-4 text-center text-indigo-200">TRANSFORMER BLOCKS<div className="mt-1 text-xs text-slate-400">Attention + MLP + residual connections + normalization</div></div>
          <div className="text-center text-indigo-400">↓</div>
          <div className="rounded-xl border border-amber-500/30 bg-amber-500/10 p-4 text-center text-amber-200">FINAL HIDDEN REPRESENTATIONS</div>
          <div className="text-center text-amber-400">↓</div>
          <div className="rounded-xl border border-pink-500/30 bg-pink-500/10 p-4 text-center text-pink-200">LANGUAGE MODEL HEAD<div className="mt-1 text-xs text-slate-400">Hidden state → vocabulary logits</div></div>
        </div>
      </div>

      <div>The Transformer does not directly store a sentence as a fixed symbolic representation. Instead, it repeatedly transforms vectors so that each position contains increasingly useful contextual information.</div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-violet-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">2. Beginner: Understanding Transformer Model Families</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>The original Transformer architecture introduced both an <strong className="text-violet-300">encoder</strong> and a <strong className="text-cyan-300">decoder</strong>. Different model families use these components differently.</div>

      <div className="grid gap-5 md:grid-cols-3">
        <div className="rounded-xl border border-cyan-500/25 bg-cyan-500/[0.04] p-6">
          <div className="mb-2 font-bold text-cyan-300">Encoder-only</div>
          <div className="text-sm leading-relaxed text-slate-300">Primarily designed to build contextual representations of an input sequence.</div>
          <div className="mt-3 text-xs font-semibold text-slate-500">Example: BERT</div>
        </div>
        <div className="rounded-xl border border-violet-500/25 bg-violet-500/[0.04] p-6">
          <div className="mb-2 font-bold text-violet-300">Encoder-decoder</div>
          <div className="text-sm leading-relaxed text-slate-300">Uses one network to encode an input and another to generate an output sequence.</div>
          <div className="mt-3 text-xs font-semibold text-slate-500">Example: T5</div>
        </div>
        <div className="rounded-xl border border-emerald-500/25 bg-emerald-500/[0.04] p-6">
          <div className="mb-2 font-bold text-emerald-300">Decoder-only</div>
          <div className="text-sm leading-relaxed text-slate-300">Generates tokens autoregressively while attending to the available context.</div>
          <div className="mt-3 text-xs font-semibold text-slate-500">Example: GPT-style LLMs</div>
        </div>
      </div>

      <div>For modern text-generation LLMs, the architecture you should understand first is the <strong className="text-white">decoder-only Transformer</strong>. It uses causal self-attention so a position cannot use information from future tokens.</div>

      <div className="rounded-xl border border-amber-500/25 bg-[#0A0D16] p-5"><strong className="text-amber-300">Important:</strong><span className="text-slate-300"> "Decoder-only" does not mean the model is incomplete. It means the model uses the decoder-style stack without a separate encoder stack.</span></div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-emerald-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">3. Beginner: What Is a Transformer Block?</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>A Transformer is not one single attention operation. It is usually a stack of repeated <strong className="text-emerald-300">Transformer blocks</strong>.</div>

      <div>A simplified decoder-only block contains:</div>

      <div className="grid gap-3 md:grid-cols-2">
        <div className="rounded-xl border border-cyan-500/25 bg-cyan-500/[0.04] p-5"><div className="font-bold text-cyan-300">1. Normalization</div><div className="mt-1 text-sm text-slate-400">Often pre-normalization in modern LLMs.</div></div>
        <div className="rounded-xl border border-violet-500/25 bg-violet-500/[0.04] p-5"><div className="font-bold text-violet-300">2. Causal Self-Attention</div><div className="mt-1 text-sm text-slate-400">Mixes information across allowed token positions.</div></div>
        <div className="rounded-xl border border-emerald-500/25 bg-emerald-500/[0.04] p-5"><div className="font-bold text-emerald-300">3. Residual Connection</div><div className="mt-1 text-sm text-slate-400">Adds the attention update back to the stream.</div></div>
        <div className="rounded-xl border border-amber-500/25 bg-amber-500/[0.04] p-5"><div className="font-bold text-amber-300">4. MLP / FFN</div><div className="mt-1 text-sm text-slate-400">Transforms each contextualized token representation.</div></div>
        <div className="rounded-xl border border-pink-500/25 bg-pink-500/[0.04] p-5"><div className="font-bold text-pink-300">5. Another Residual Connection</div><div className="mt-1 text-sm text-slate-400">Combines the MLP output with the existing stream.</div></div>
        <div className="rounded-xl border border-indigo-500/25 bg-indigo-500/[0.04] p-5"><div className="font-bold text-indigo-300">6. Normalization</div><div className="mt-1 text-sm text-slate-400">The exact placement depends on the architecture.</div></div>
      </div>

      <div className="rounded-3xl border border-white/10 bg-[#060913] p-6 sm:p-8">
        <div className="space-y-3 font-mono text-xs">
          <div className="rounded-xl border border-cyan-500/30 bg-cyan-500/10 p-4 text-center text-cyan-200">INPUT REPRESENTATIONS</div>
          <div className="text-center text-cyan-400">↓</div>
          <div className="rounded-xl border border-violet-500/30 bg-violet-500/10 p-4 text-center text-violet-200">NORMALIZATION</div>
          <div className="text-center text-violet-400">↓</div>
          <div className="rounded-xl border border-indigo-500/30 bg-indigo-500/10 p-4 text-center text-indigo-200">CAUSAL SELF-ATTENTION</div>
          <div className="text-center text-indigo-400">↓</div>
          <div className="rounded-xl border border-emerald-500/30 bg-emerald-500/10 p-4 text-center text-emerald-200">RESIDUAL ADDITION</div>
          <div className="text-center text-emerald-400">↓</div>
          <div className="rounded-xl border border-amber-500/30 bg-amber-500/10 p-4 text-center text-amber-200">MLP / FEED-FORWARD NETWORK</div>
          <div className="text-center text-amber-400">↓</div>
          <div className="rounded-xl border border-pink-500/30 bg-pink-500/10 p-4 text-center text-pink-200">RESIDUAL ADDITION</div>
          <div className="text-center text-pink-400">↓</div>
          <div className="rounded-xl border border-white/10 bg-white/[0.03] p-4 text-center">OUTPUT REPRESENTATIONS</div>
        </div>
      </div>

      <div>The exact ordering varies across model families. Modern LLMs commonly use <strong className="text-white">pre-normalization</strong> and may use <strong className="text-white">RMSNorm</strong> and gated MLPs such as SwiGLU.</div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-indigo-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">4. Beginner: Causal Self-Attention</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div><strong className="text-indigo-300">Self-attention</strong> allows token representations to use information from other positions in the sequence. In an autoregressive LLM, the attention must be <strong className="text-white">causal</strong>.</div>

      <div>For the sequence:</div>

      <div className="rounded-2xl border border-indigo-500/25 bg-indigo-500/[0.04] p-6">
        <div className="mb-5 text-center font-mono text-sm text-indigo-200">The cat sat on the mat</div>
        <div className="space-y-2 font-mono text-xs">
          <div className="grid grid-cols-6 gap-2">
            <div className="rounded-lg border border-indigo-500/30 bg-indigo-500/10 p-3 text-center">The</div>
            <div className="rounded-lg border border-white/10 bg-white/[0.03] p-3 text-center text-slate-600">×</div>
            <div className="rounded-lg border border-white/10 bg-white/[0.03] p-3 text-center text-slate-600">×</div>
            <div className="rounded-lg border border-white/10 bg-white/[0.03] p-3 text-center text-slate-600">×</div>
            <div className="rounded-lg border border-white/10 bg-white/[0.03] p-3 text-center text-slate-600">×</div>
            <div className="rounded-lg border border-white/10 bg-white/[0.03] p-3 text-center text-slate-600">×</div>
          </div>
          <div className="grid grid-cols-6 gap-2">
            <div className="rounded-lg border border-indigo-500/30 bg-indigo-500/10 p-3 text-center">The</div>
            <div className="rounded-lg border border-indigo-500/30 bg-indigo-500/10 p-3 text-center">cat</div>
            <div className="rounded-lg border border-white/10 bg-white/[0.03] p-3 text-center text-slate-600">×</div>
            <div className="rounded-lg border border-white/10 bg-white/[0.03] p-3 text-center text-slate-600">×</div>
            <div className="rounded-lg border border-white/10 bg-white/[0.03] p-3 text-center text-slate-600">×</div>
            <div className="rounded-lg border border-white/10 bg-white/[0.03] p-3 text-center text-slate-600">×</div>
          </div>
          <div className="grid grid-cols-6 gap-2">
            <div className="rounded-lg border border-indigo-500/30 bg-indigo-500/10 p-3 text-center">The</div>
            <div className="rounded-lg border border-indigo-500/30 bg-indigo-500/10 p-3 text-center">cat</div>
            <div className="rounded-lg border border-indigo-500/30 bg-indigo-500/10 p-3 text-center">sat</div>
            <div className="rounded-lg border border-white/10 bg-white/[0.03] p-3 text-center text-slate-600">×</div>
            <div className="rounded-lg border border-white/10 bg-white/[0.03] p-3 text-center text-slate-600">×</div>
            <div className="rounded-lg border border-white/10 bg-white/[0.03] p-3 text-center text-slate-600">×</div>
          </div>
        </div>
        <div className="mt-5 text-center text-sm text-slate-400">Each position can use itself and earlier positions, but not future positions.</div>
      </div>

      <div>This restriction is implemented with a <strong className="text-indigo-300">causal attention mask</strong>. Without it, a training example could allow the model to see the token it is supposed to predict, which would break the autoregressive learning objective.</div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-cyan-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">5. Intermediate: Query, Key, and Value</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>Self-attention creates three learned projections from the input representations: <strong className="text-cyan-300">Query</strong>, <strong className="text-violet-300">Key</strong>, and <strong className="text-emerald-300">Value</strong>.</div>

      <div className="grid gap-4 md:grid-cols-3">
        <div className="rounded-xl border border-cyan-500/25 bg-cyan-500/[0.04] p-6"><div className="mb-2 font-bold text-cyan-300">Query</div><div className="text-sm leading-relaxed text-slate-300">Represents what information the current position is looking for.</div></div>
        <div className="rounded-xl border border-violet-500/25 bg-violet-500/[0.04] p-6"><div className="mb-2 font-bold text-violet-300">Key</div><div className="text-sm leading-relaxed text-slate-300">Represents what each position offers for matching against a query.</div></div>
        <div className="rounded-xl border border-emerald-500/25 bg-emerald-500/[0.04] p-6"><div className="mb-2 font-bold text-emerald-300">Value</div><div className="text-sm leading-relaxed text-slate-300">Contains the information that is actually combined when attention is applied.</div></div>
      </div>

      <div>A simplified attention calculation is:</div>

      <div className="rounded-xl border border-white/10 bg-[#060913] p-6 text-center font-mono text-sm text-cyan-200">
        Attention = softmax of (Q × K-transpose divided by square-root of d-k) × V
      </div>

      <div>The query-key interaction determines how strongly positions relate to one another. The resulting weights are then used to combine the value vectors.</div>

      <div className="rounded-xl border border-amber-500/25 bg-[#0A0D16] p-5"><strong className="text-amber-300">Why scale by square-root of d-k?</strong><span className="text-slate-300"> The scaling helps prevent attention scores from becoming excessively large as the key/query dimensionality increases.</span></div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-pink-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">6. Intermediate: Multi-Head Attention</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>Transformers normally use multiple attention heads instead of one large attention operation. Each head works in a learned subspace and can capture different relationships.</div>

      <div className="rounded-3xl border border-white/10 bg-[#060913] p-6 sm:p-8">
        <div className="space-y-3 font-mono text-xs">
          <div className="rounded-xl border border-cyan-500/30 bg-cyan-500/10 p-4 text-center text-cyan-200">INPUT REPRESENTATIONS</div>
          <div className="text-center text-cyan-400">↓</div>
          <div className="grid gap-3 md:grid-cols-3">
            <div className="rounded-xl border border-violet-500/30 bg-violet-500/10 p-4 text-center text-violet-200">HEAD 1<div className="mt-1 text-xs text-slate-400">Attention pattern</div></div>
            <div className="rounded-xl border border-pink-500/30 bg-pink-500/10 p-4 text-center text-pink-200">HEAD 2<div className="mt-1 text-xs text-slate-400">Attention pattern</div></div>
            <div className="rounded-xl border border-emerald-500/30 bg-emerald-500/10 p-4 text-center text-emerald-200">HEAD N<div className="mt-1 text-xs text-slate-400">Attention pattern</div></div>
          </div>
          <div className="text-center text-indigo-400">↓ concatenate</div>
          <div className="rounded-xl border border-indigo-500/30 bg-indigo-500/10 p-4 text-center text-indigo-200">OUTPUT PROJECTION</div>
          <div className="text-center text-indigo-400">↓</div>
          <div className="rounded-xl border border-white/10 bg-white/[0.03] p-4 text-center">ATTENTION OUTPUT</div>
        </div>
      </div>

      <div>Different heads can learn to emphasize different relationships, such as local dependencies, long-range relationships, syntactic patterns, or references between entities.</div>

      <div>Modern LLMs can also use attention variants such as <strong className="text-white">Multi-Query Attention</strong> and <strong className="text-white">Grouped-Query Attention</strong>. These reduce key/value memory requirements during inference while retaining multiple query heads.</div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-amber-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">7. Intermediate: Feed-Forward Network / MLP</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>Attention mixes information across token positions. The <strong className="text-amber-300">feed-forward network</strong>, commonly called the MLP, then transforms the representation at each position.</div>

      <div className="rounded-2xl border border-amber-500/25 bg-amber-500/[0.04] p-6">
        <div className="mb-4 text-center font-mono text-xs font-bold uppercase tracking-widest text-amber-300">Simplified MLP</div>
        <div className="grid gap-3 md:grid-cols-5 md:items-center">
          <div className="rounded-xl border border-cyan-500/30 bg-cyan-500/10 p-4 text-center text-cyan-200">INPUT</div>
          <div className="text-center text-amber-400">→</div>
          <div className="rounded-xl border border-violet-500/30 bg-violet-500/10 p-4 text-center text-violet-200">EXPANSION + ACTIVATION</div>
          <div className="text-center text-amber-400">→</div>
          <div className="rounded-xl border border-emerald-500/30 bg-emerald-500/10 p-4 text-center text-emerald-200">PROJECTION</div>
        </div>
      </div>

      <div>A simplified form is:</div>

      <div className="rounded-xl border border-white/10 bg-[#060913] p-6 text-center font-mono text-sm text-amber-200">
        MLP of x = W2 × activation of (W1 × x + b1) + b2
      </div>

      <div>The MLP is applied independently at each position, but the input representation already contains contextual information produced by attention.</div>

      <div>Modern LLMs often use gated MLP variants such as <strong className="text-white">SwiGLU</strong> instead of a simple activation function. The exact dimensions and activation design vary across model families.</div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-emerald-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">8. Intermediate: Residual Connections</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>A residual connection adds a layer's output back to the representation that entered the layer.</div>

      <div className="rounded-3xl border border-white/10 bg-[#060913] p-6 sm:p-8">
        <div className="space-y-3 font-mono text-xs">
          <div className="rounded-xl border border-cyan-500/30 bg-cyan-500/10 p-4 text-center text-cyan-200">INPUT x</div>
          <div className="text-center text-cyan-400">↓</div>
          <div className="rounded-xl border border-indigo-500/30 bg-indigo-500/10 p-4 text-center text-indigo-200">ATTENTION OR MLP: f of x</div>
          <div className="text-center text-indigo-400">↓</div>
          <div className="rounded-xl border border-emerald-500/30 bg-emerald-500/10 p-4 text-center text-emerald-200">ADD x + f of x</div>
          <div className="text-center text-emerald-400">↓</div>
          <div className="rounded-xl border border-white/10 bg-white/[0.03] p-4 text-center">UPDATED REPRESENTATION</div>
        </div>
      </div>

      <div>In simplified mathematical notation, the idea is:</div>

      <div className="rounded-xl border border-white/10 bg-[#060913] p-5 text-center font-mono text-sm text-emerald-200">x-new = x + f of x</div>

      <div>Residual pathways help information and gradients travel through very deep networks. Instead of forcing every layer to completely replace the existing representation, each sub-layer can learn an update to it.</div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-teal-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">9. Intermediate: Layer Normalization and RMSNorm</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>Normalization helps control the scale of activations and makes optimization more stable.</div>

      <div className="grid gap-5 md:grid-cols-2">
        <div className="rounded-xl border border-teal-500/25 bg-teal-500/[0.04] p-6">
          <div className="mb-2 font-bold text-teal-300">LayerNorm</div>
          <div className="text-sm leading-relaxed text-slate-300">Normalizes activations using statistics based on the mean and variance of the features.</div>
        </div>
        <div className="rounded-xl border border-cyan-500/25 bg-cyan-500/[0.04] p-6">
          <div className="mb-2 font-bold text-cyan-300">RMSNorm</div>
          <div className="text-sm leading-relaxed text-slate-300">Uses the root-mean-square magnitude of the activations without explicitly centering by the mean.</div>
        </div>
      </div>

      <div>Many modern decoder-only LLMs use RMSNorm. The exact normalization design is architecture-specific.</div>

      <div className="rounded-xl border border-amber-500/25 bg-[#0A0D16] p-5"><strong className="text-amber-300">Pre-norm vs post-norm:</strong><span className="text-slate-300"> The position of normalization relative to attention, MLP, and residual operations is an architectural choice. Modern LLMs commonly use a pre-norm style.</span></div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-blue-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">10. Intermediate: One Token's Representation Through a Block</h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>Consider the token <strong className="text-cyan-300">"cat"</strong> in the sequence:</div>

      <div className="rounded-xl border border-white/10 bg-white/[0.03] p-5 text-center font-mono text-sm text-slate-200">The cat sat on the mat</div>

      <div>Its initial representation comes from its token embedding plus positional information. Inside a Transformer block, that representation is repeatedly updated.</div>

      <div className="grid gap-3 md:grid-cols-2">
        <div className="rounded-xl border border-cyan-500/25 bg-cyan-500/[0.04] p-5"><div className="font-bold text-cyan-300">Step 1</div><div className="mt-1 text-sm text-slate-300">Normalize the representation.</div></div>
        <div className="rounded-xl border border-violet-500/25 bg-violet-500/[0.04] p-5"><div className="font-bold text-violet-300">Step 2</div><div className="mt-1 text-sm text-slate-300">Use causal self-attention to retrieve useful context.</div></div>
        <div className="rounded-xl border border-emerald-500/25 bg-emerald-500/[0.04] p-5"><div className="font-bold text-emerald-300">Step 3</div><div className="mt-1 text-sm text-slate-300">Add the attention update through the residual path.</div></div>
        <div className="rounded-xl border border-amber-500/25 bg-amber-500/[0.04] p-5"><div className="font-bold text-amber-300">Step 4</div><div className="mt-1 text-sm text-slate-300">Normalize before the MLP in a pre-norm architecture.</div></div>
        <div className="rounded-xl border border-pink-500/25 bg-pink-500/[0.04] p-5"><div className="font-bold text-pink-300">Step 5</div><div className="mt-1 text-sm text-slate-300">Transform the representation through the MLP.</div></div>
        <div className="rounded-xl border border-indigo-500/25 bg-indigo-500/[0.04] p-5"><div className="font-bold text-indigo-300">Step 6</div><div className="mt-1 text-sm text-slate-300">Add the MLP update through another residual path.</div></div>
      </div>

      <div>After many Transformer blocks, the representation of "cat" is no longer simply the original embedding. It contains information shaped by the surrounding context and by the computations performed throughout the network.</div>
    </div>
  </section>

  <section>

    <div className="space-y-6 text-[16px] leading-8 text-slate-300">

        </div>

      <div>The resulting logits are then passed to the decoding process you learned in the previous module: probabilities are formed and a token is selected using greedy decoding or a sampling strategy.</div>

      <div className="rounded-xl border border-cyan-500/25 bg-cyan-500/[0.04] p-5"><strong className="text-cyan-300">Connection to Module 04:</strong><span className="text-slate-300"> The Transformer architecture computes the hidden representations and logits. The generation algorithm then turns those logits into the next token.</span></div>
