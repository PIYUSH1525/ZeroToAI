  <section>
    <h2 className="mb-6 border-l-4 border-blue-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
      1. Beginner: The Model Only Gives Probabilities
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        An LLM does not produce a sentence directly. At every step it produces a <strong className="text-white">score for every word</strong> in its vocabulary, which is turned into a <strong className="text-white">probability distribution</strong>. Something then has to pick one word. That choice rule is called a <strong className="text-white">decoding strategy</strong> or <strong className="text-white">sampling method</strong>.
      </div>
      <div>
        The same model can sound careful, boring, creative or chaotic depending only on this rule. No retraining is needed.
      </div>
      <div className="grid gap-5 md:grid-cols-3">
        <div className="rounded-xl border border-blue-500/25 bg-blue-500/[0.04] p-6">
          <div className="mb-1 flex items-center justify-between">
            <span className="font-bold text-blue-300">Step 1</span>
            <span className="rounded bg-blue-950/80 px-2 py-0.5 font-mono text-xs text-blue-300">Scores (logits)</span>
          </div>
          <div className="mt-2 space-y-2 text-xs leading-relaxed text-slate-300">
            <div>The model scores every possible next token.</div>
          </div>
        </div>
        <div className="rounded-xl border border-violet-500/25 bg-violet-500/[0.04] p-6">
          <div className="mb-1 flex items-center justify-between">
            <span className="font-bold text-violet-300">Step 2</span>
            <span className="rounded bg-violet-950/80 px-2 py-0.5 font-mono text-xs text-violet-300">Probabilities</span>
          </div>
          <div className="mt-2 space-y-2 text-xs leading-relaxed text-slate-300">
            <div>Softmax turns the scores into numbers that add up to 1.</div>
          </div>
        </div>
        <div className="rounded-xl border border-emerald-500/25 bg-emerald-500/[0.04] p-6">
          <div className="mb-1 flex items-center justify-between">
            <span className="font-bold text-emerald-300">Step 3</span>
            <span className="rounded bg-emerald-950/80 px-2 py-0.5 font-mono text-xs text-emerald-300">Pick one</span>
          </div>
          <div className="mt-2 space-y-2 text-xs leading-relaxed text-slate-300">
            <div>A rule chooses a token. It is added to the text and the loop repeats.</div>

    </div>

  <section>
    <h2 className="mb-6 border-l-4 border-violet-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
      2. Beginner: Greedy Decoding and Why It Is Not Enough
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        The simplest rule is <strong className="text-white">greedy decoding</strong>: always take the most likely token. It is fast and gives the same answer every time, which is great for facts and code.
      </div>
      <div>
        But greedy has two problems. It can get stuck in <strong className="text-white">repetitive loops</strong>, and it makes writing feel flat because it never takes a less obvious but still good word. Sampling fixes this by choosing <em>randomly according to the probabilities</em>, so likely words win most of the time but not always.
      </div>
      <div className="rounded-xl border border-amber-500/20 bg-amber-500/[0.05] p-5 text-sm leading-relaxed">
        <strong className="text-amber-300">Beam search:</strong> Another classic method keeps the best few partial sentences at once. It works well for translation, but for open-ended chat it tends to produce dull text, so chat models usually sample instead.
      </div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-emerald-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">

    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        <strong className="text-white">Temperature</strong> $T$ divides the scores before the softmax. It reshapes the probabilities without changing their order:
      </div>
      <div className="rounded-xl border border-white/10 bg-[#060913] p-5 text-center text-white">
        $$p_i = \frac{e^{z_i / T}}{\sum_j e^{z_j / T}}$$
      </div>
      <div className="overflow-x-auto rounded-2xl border border-white/10">
        <table className="w-full text-left text-sm">

              <th className="px-5 py-3">Effect</th>
              <th className="px-5 py-3">Good for</th>
            </tr>
          </thead>
          <tbody className="divide-y divide-white/5 text-slate-300">
            <tr><td className="px-5 py-3 font-semibold text-white">Close to 0</td><td className="px-5 py-3">The top token gets almost all the probability. Behaves like greedy.</td><td className="px-5 py-3">Facts, extraction, code, math</td></tr>
            <tr><td className="px-5 py-3 font-semibold text-white">Around 0.7</td><td className="px-5 py-3">Mostly the top choices, with some variety</td><td className="px-5 py-3">General chat and writing</td></tr>
            <tr><td className="px-5 py-3 font-semibold text-white">1.0</td><td className="px-5 py-3">The model&apos;s natural distribution</td><td className="px-5 py-3">Brainstorming</td></tr>
            <tr><td className="px-5 py-3 font-semibold text-white">Above 1.5</td><td className="px-5 py-3">Rare tokens become likely. Text may turn into nonsense.</td><td className="px-5 py-3">Rarely useful</td></tr>
          </tbody>

      <div className="rounded-xl border border-emerald-500/20 bg-emerald-500/[0.05] p-5 text-sm leading-relaxed">
        <strong className="text-emerald-300">Remember:</strong> Low temperature does not make the model smarter. It only makes it <strong className="text-white">more predictable</strong>.
      </div>
    </div>
  </section>

  <section>
    <h2 className="mb-6 border-l-4 border-orange-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
      4. Medium: Top-k and Top-p, Cutting Off the Bad Tail
    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        Even at a sensible temperature, a vocabulary of 100,000 tokens has a long tail of silly words. Each one has a tiny probability, but together they can add up and occasionally derail a sentence. Two filters remove the tail:
      </div>
      <div className="grid gap-5 md:grid-cols-2">
        <div className="rounded-xl border border-blue-500/25 bg-blue-500/[0.04] p-6">
          <div className="mb-1 flex items-center justify-between">
            <span className="font-bold text-blue-300">Top-k</span>
            <span className="rounded bg-blue-950/80 px-2 py-0.5 font-mono text-xs text-blue-300">Fixed size list</span>
          </div>
          <div className="mt-2 space-y-2 text-xs leading-relaxed text-slate-300">
            <div><strong className="text-white">Rule:</strong> Keep only the $k$ most likely tokens (for example 40), then renormalize.</div>
            <div><strong className="text-white">Weakness:</strong> Same $k$ even when the model is very sure or very unsure.</div>
          </div>
        </div>
        <div className="rounded-xl border border-emerald-500/25 bg-emerald-500/[0.04] p-6">
          <div className="mb-1 flex items-center justify-between">
            <span className="font-bold text-emerald-300">Top-p (nucleus)</span>
            <span className="rounded bg-emerald-950/80 px-2 py-0.5 font-mono text-xs text-emerald-300">Adaptive size</span>
          </div>
          <div className="mt-2 space-y-2 text-xs leading-relaxed text-slate-300">
            <div><strong className="text-white">Rule:</strong> Keep the smallest group of tokens whose probabilities add up to $p$ (for example 0.9).</div>
            <div><strong className="text-white">Strength:</strong> Few tokens when the model is confident, more when it is unsure.</div>
          </div>
        </div>
      </div>
      <div className="rounded-xl border border-cyan-500/20 bg-cyan-500/[0.05] p-5 text-sm leading-relaxed">
        <strong className="text-cyan-300">Practical default:</strong> Many applications use temperature around 0.7 with top-p around 0.9 to 0.95. Change <strong className="text-white">one</strong> knob at a time so you can see what it does.
      </div>
    </div>
  </section>

        <pre className="overflow-x-auto p-6 font-mono text-sm leading-7 text-slate-200">
          <code>
            <span className="block">import numpy as np</span>
            <span className="block">&nbsp;</span>
            <span className="block">words = &#91;&quot;the&quot;, &quot;a&quot;, &quot;cat&quot;, &quot;dog&quot;, &quot;banana&quot;&#93;</span>
            <span className="block">logits = np.array(&#91;3.0, 2.5, 2.0, 1.0, -1.0&#93;)    # raw scores from a model</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def softmax(z, temperature=1.0):</span>
            <span className="block">    z = z / temperature</span>
            <span className="block">    z = z - z.max()</span>
            <span className="block">    e = np.exp(z)</span>
            <span className="block">    return e / e.sum()</span>
            <span className="block">&nbsp;</span>
            <span className="block text-cyan-300">def show(title, p):</span>
            <span className="block">    print(title.ljust(22), &#123;w: round(float(x), 3) for w, x in zip(words, p)&#125;)</span>

            <span className="block">    show(&quot;temperature &quot; + str(T), softmax(logits, T))</span>
            <span className="block">&nbsp;</span>
            <span className="block text-slate-500"># 2. Top-k: keep only the k most likely words, then renormalize</span>
            <span className="block text-cyan-300">def top&#95;k(p, k):</span>
            <span className="block">    keep = np.argsort(p)&#91;::-1&#93;&#91;:k&#93;</span>
            <span className="block">    out = np.zeros&#95;like(p)</span>
            <span className="block">    out&#91;keep&#93; = p&#91;keep&#93;</span>
            <span className="block">    return out / out.sum()</span>
            <span className="block">&nbsp;</span>
            <span className="block">show(&quot;top-k (k=2)&quot;, top&#95;k(softmax(logits), 2))</span>
            <span className="block">&nbsp;</span>

            <span className="block text-cyan-300">def top&#95;p(p, threshold):</span>
            <span className="block">    order = np.argsort(p)&#91;::-1&#93;</span>
            <span className="block">    cumulative = np.cumsum(p&#91;order&#93;)</span>
            <span className="block">    cutoff = np.searchsorted(cumulative, threshold) + 1</span>
            <span className="block">    out = np.zeros&#95;like(p)</span>
            <span className="block">    out&#91;order&#91;:cutoff&#93;&#93; = p&#91;order&#91;:cutoff&#93;&#93;</span>
            <span className="block">    return out / out.sum()</span>
            <span className="block">&nbsp;</span>
            <span className="block">show(&quot;top-p (p=0.9)&quot;, top&#95;p(softmax(logits), 0.9))</span>
            <span className="block">&nbsp;</span>
            <span className="block text-slate-500"># 4. Greedy vs sampling over 1,000 draws</span>
            <span className="block">rng = np.random.default&#95;rng(0)</span>
            <span className="block">p = softmax(logits)</span>
            <span className="block">draws = rng.choice(words, size=1000, p=p)</span>
            <span className="block">print(&quot;Greedy always picks:&quot;, words&#91;int(np.argmax(p))&#93;)</span>
