      <div className="space-y-5 text-[16px] leading-8 text-slate-300">
        <div>One of the central challenges in RL is deciding whether to use an action that is already known to work or try something new that might work even better.</div>

        </div>
        <div>Practical RL methods use different strategies to balance these two behaviors. The exact strategy depends on the environment and algorithm.</div>

      <div className="space-y-5 text-[16px] leading-8 text-slate-300">

          <div className="rounded-xl border border-violet-400/20 bg-violet-400/[0.05] p-5"><div className="mb-2 font-bold text-violet-300">Q-Value</div><div className="text-sm leading-relaxed text-slate-400">Estimates the usefulness of taking a particular action in a particular state.</div></div>
        </div>
        <div>You do not need the full mathematics at this stage. The key intuition is that RL can learn estimates of future usefulness and use those estimates when choosing actions.</div>

        <div>The reward function tells an RL system what outcomes are desirable. Because the agent optimizes what the reward system measures, reward design is an important part of an RL problem.</div>
        <div>A poorly designed reward can encourage behavior that technically maximizes the score while missing the real objective. This is sometimes described as a <strong>reward hacking</strong> problem.</div>
        <div className="grid gap-4 md:grid-cols-2">
          <div className="rounded-xl border border-emerald-400/20 bg-emerald-400/[0.05] p-5"><div className="mb-2 font-bold text-emerald-300">Useful reward</div><div className="text-sm leading-relaxed text-slate-400">Encourages behavior that is closely aligned with the actual goal.</div></div>
          <div className="rounded-xl border border-rose-400/20 bg-rose-400/[0.05] p-5"><div className="mb-2 font-bold text-rose-300">Misleading reward</div><div className="text-sm leading-relaxed text-slate-400">Can make the agent optimize an easy-to-measure signal while ignoring the intended outcome.</div></div>
