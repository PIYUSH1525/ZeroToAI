The Machine Learning approach is different: show your friend many mangoes, tell them which ones were ripe, and let them discover the useful pattern. The goal is that they can then recognize a ripe mango they have never seen before.
          </div>

    <section>
      <h2 className="mb-6 border-l-4 border-blue-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
        1. The Origin & The Paradigm Shift
      </h2>

      <div className="space-y-5 text-[16px] leading-8 text-slate-300">
        <div>
          In 1959, an IBM researcher named <strong>Arthur Samuel</strong> coined the term "Machine Learning." He was trying to build a computer program that could play checkers. He quickly realized that explicitly programming every possible board position was mathematically impossible.
        </div>

        <div>
          Instead, he wrote a program that allowed the computer to play tens of thousands of games against itself. By analyzing which moves led to wins and which led to losses, the computer could improve its strategy through experience. This helped demonstrate the central idea behind Machine Learning: <strong className="text-white">the system can improve its behavior from data and experience rather than receiving every rule directly from a programmer.</strong>
        </div>

        <div>
          This created a major paradigm shift in computer science. The programmer no longer has to describe every individual decision. The programmer designs a learning system, provides useful data, defines what the system should learn, and evaluates how well the resulting model works on data it has not seen before.
        </div>

        <div className="my-6 grid gap-4 md:grid-cols-2">
          <div className="rounded-xl border border-slate-700/50 bg-slate-800/20 p-5">
            <div className="mb-3 font-semibold text-white">Traditional Programming</div>
            <div className="text-sm leading-relaxed text-slate-400">
              You input the <strong>Data</strong> and the <strong>Rules (Code)</strong> into the computer. The computer processes them and outputs the <strong>Answers</strong>. If a new edge-case appears, a human must write or modify a rule.
            </div>
          </div>

          <div className="rounded-xl border border-blue-400/20 bg-blue-400/[0.06] p-5">
            <div className="mb-3 font-semibold text-blue-200">Machine Learning</div>
            <div className="text-sm leading-relaxed text-slate-300">
              You input the <strong>Data</strong> and the <strong>Answers (Labels)</strong> into the computer. The learning algorithm processes them and produces a <strong>Model</strong> containing learned parameters. That model can then be used on new inputs.
            </div>
          </div>
        </div>

        <div className="rounded-xl border border-white/10 bg-white/[0.03] p-5">
          <div className="mb-3 font-semibold text-white">The important distinction</div>
          <div className="text-slate-400">
            Machine Learning does not mean that the computer suddenly writes readable human-style rules such as <em>"if color is orange and firmness is medium, then ripe."</em> The learned "rules" are generally represented by numerical parameters, weights, thresholds, or other mathematical structures inside the model.
          </div>
        </div>
      </div>
    </section>

    <section>
      <h2 className="mb-6 border-l-4 border-cyan-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
        2. Why Machine Learning Exists
      </h2>

      <div className="space-y-6 text-[16px] leading-8 text-slate-300">
        <div>
          Machine Learning becomes useful when a problem contains too many rules, too many variations, or patterns that are difficult for a person to describe explicitly.
        </div>

        <div className="grid gap-4 md:grid-cols-3">
          <div className="rounded-xl border border-cyan-400/20 bg-cyan-400/[0.05] p-5">
            <div className="mb-3 font-semibold text-cyan-200">Too many rules</div>
            <div className="text-sm leading-relaxed text-slate-400">
              Some tasks have enormous numbers of possible situations. Separating cat photos from dog photos is not practical as a giant collection of manually written visual rules.
            </div>
          </div>

          <div className="rounded-xl border border-violet-400/20 bg-violet-400/[0.05] p-5">
            <div className="mb-3 font-semibold text-violet-200">Unexpected cases</div>
            <div className="text-sm leading-relaxed text-slate-400">
              Hand-written rules only cover cases someone anticipated. Real-world data constantly produces variations that were not explicitly considered.
            </div>
          </div>

          <div className="rounded-xl border border-emerald-400/20 bg-emerald-400/[0.05] p-5">
            <div className="mb-3 font-semibold text-emerald-200">Existing data</div>
            <div className="text-sm leading-relaxed text-slate-400">
              Organizations often have large collections of past sales, clicks, transactions, images, documents, or other observations that can be used to learn patterns.
            </div>
          </div>
        </div>

        <div>
          The central idea is therefore not "use Machine Learning because it is newer." The useful question is: <strong className="text-white">is there a pattern in the data that can be learned more effectively than it can be manually specified?</strong>
        </div>
      </div>
    </section>

    <section>
      <h2 className="mb-6 border-l-4 border-indigo-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
        3. The Machine Learning Workflow
      </h2>

      <div className="space-y-6 text-[16px] leading-8 text-slate-300">
        <div>
          A Machine Learning system can be understood as a sequence: <strong className="text-white">data → learning process → model → prediction → evaluation</strong>. The exact details differ between algorithms, but the basic idea remains consistent.
        </div>

        <div className="grid gap-4 md:grid-cols-2">
          <div className="rounded-xl border border-white/10 bg-slate-800/20 p-5">
            <div className="mb-2 font-semibold text-white">1. Collect data</div>
            <div className="text-sm leading-relaxed text-slate-400">
              Gather examples relevant to the problem. For a house-price problem, the dataset could contain historical houses and their attributes.
            </div>
          </div>

          <div className="rounded-xl border border-white/10 bg-slate-800/20 p-5">
            <div className="mb-2 font-semibold text-white">2. Represent the input</div>
            <div className="text-sm leading-relaxed text-slate-400">
              Identify the measurable properties the model will use. These properties are called <strong>features</strong>.
            </div>
          </div>

          <div className="rounded-xl border border-white/10 bg-slate-800/20 p-5">
            <div className="mb-2 font-semibold text-white">3. Train the model</div>
            <div className="text-sm leading-relaxed text-slate-400">
              The learning algorithm adjusts internal parameters so that its outputs become closer to the desired answers.
            </div>
          </div>

          <div className="rounded-xl border border-white/10 bg-slate-800/20 p-5">
            <div className="mb-2 font-semibold text-white">4. Evaluate and generalize</div>
            <div className="text-sm leading-relaxed text-slate-400">
              Test the trained model on new examples. A useful model should work beyond the exact examples it memorized during training.
            </div>
          </div>
        </div>

        <div className="rounded-xl border border-blue-400/20 bg-blue-400/[0.05] p-5">
          <strong className="text-blue-300">The key goal:</strong> training performance alone is not enough. The real goal is <strong>generalization</strong> — performing well on examples the model did not see during training.
        </div>
      </div>
    </section>

    <section>
      <h2 className="mb-6 border-l-4 border-emerald-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
        6. The Three Main Branches of ML
      </h2>

      <div className="space-y-6 text-[16px] leading-8 text-slate-300">
        <div>
          Almost every introductory Machine Learning system can be understood through three major learning settings: <strong>Supervised Learning</strong>, <strong>Unsupervised Learning</strong>, and <strong>Reinforcement Learning</strong>. They differ mainly in what information is available during learning and how feedback is provided.
        </div>

        <div className="grid gap-5 md:grid-cols-3">
          <div className="rounded-xl border border-blue-400/20 bg-blue-400/[0.05] p-5">
            <div className="mb-3 text-center text-xs font-semibold uppercase tracking-wider text-blue-300">Supervised Learning</div>
            <div className="text-center text-sm leading-6 text-slate-400">
              <strong>Learning with a teacher.</strong> The data is labeled. The model makes predictions, compares them with the known answers, and adjusts its parameters during training.
            </div>
          </div>

          <div className="rounded-xl border border-violet-400/20 bg-violet-400/[0.05] p-5">
            <div className="mb-3 text-center text-xs font-semibold uppercase tracking-wider text-violet-300">Unsupervised Learning</div>
            <div className="text-center text-sm leading-6 text-slate-400">
              <strong>Learning without a teacher.</strong> The data has no supplied answer labels. The model searches for structure, relationships, or groupings in the data.
            </div>
          </div>

          <div className="rounded-xl border border-emerald-400/20 bg-emerald-400/[0.05] p-5">
            <div className="mb-3 text-center text-xs font-semibold uppercase tracking-wider text-emerald-300">Reinforcement Learning</div>
            <div className="text-center text-sm leading-6 text-slate-400">
              <strong>Learning by trial and error.</strong> An agent takes actions in an environment and learns from rewards or penalties associated with the consequences.
            </div>
          </div>
        </div>

        <div className="my-8 overflow-x-auto rounded-2xl border border-white/10">

    <section>
      <h2 className="mb-6 border-l-4 border-amber-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
        7. Supervised Learning
      </h2>

      <div className="space-y-5 text-[16px] leading-8 text-slate-300">
        <div>
          In supervised learning, every training example comes with a known answer called a <strong>label</strong>. The model uses these examples to learn a relationship between the input features and the desired output.
        </div>

        <div className="rounded-xl border border-amber-400/20 bg-amber-400/[0.05] p-5">
          <div className="mb-2 font-semibold text-amber-200">Example: spam detection</div>
          <div className="text-slate-400">
            Give the model many emails and label each one as <strong className="text-slate-200">spam</strong> or <strong className="text-slate-200">not spam</strong>. During training, the model adjusts its parameters so that its predictions increasingly match those labels. Later, a new email can be passed through the trained model.
          </div>
        </div>

        <div>
          The same idea applies when the target is a number rather than a category. Predicting a house's sale price from its features is also supervised learning because historical examples provide the correct target value.
        </div>
      </div>
    </section>

    <section>
      <h2 className="mb-6 border-l-4 border-violet-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
        8. Unsupervised Learning
      </h2>

      <div className="space-y-5 text-[16px] leading-8 text-slate-300">
        <div>
          Unsupervised learning works with data where the desired answers are not supplied. Instead of being told which group each example belongs to, the algorithm looks for structure within the data.
        </div>

        <div>
          Imagine a business has information about thousands of customers but has not defined customer groups in advance. An unsupervised learning method can search for similarities and differences and form groups based on the patterns it finds.
        </div>

        <div className="grid gap-4 md:grid-cols-2">
          <div className="rounded-xl border border-violet-400/20 bg-violet-400/[0.05] p-5">
            <div className="mb-2 font-semibold text-violet-200">No supplied answer</div>
            <div className="text-sm leading-relaxed text-slate-400">
              There is no label saying "this customer belongs to group A." The structure has to be discovered from the data.
            </div>
          </div>

          <div className="rounded-xl border border-fuchsia-400/20 bg-fuchsia-400/[0.05] p-5">
            <div className="mb-2 font-semibold text-fuchsia-200">Find hidden structure</div>
            <div className="text-sm leading-relaxed text-slate-400">
              The useful output can be groups, relationships, or other patterns that were not explicitly specified beforehand.
            </div>
          </div>
        </div>
      </div>
    </section>

    <section>
      <h2 className="mb-6 border-l-4 border-emerald-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
        9. Reinforcement Learning
      </h2>

      <div className="space-y-5 text-[16px] leading-8 text-slate-300">
        <div>
          Reinforcement Learning is based on interaction. Instead of receiving a correct answer for every example, an <strong>agent</strong> takes actions in an environment and receives feedback in the form of rewards or penalties.
        </div>

        <div className="rounded-xl border border-emerald-400/20 bg-emerald-400/[0.05] p-5">
          <div className="mb-2 font-semibold text-emerald-200">Think of training a dog with treats.</div>
          <div className="text-slate-400">
            You do not need to explain every internal rule for what makes an action good. You provide feedback after actions, and behavior can be adjusted based on the consequences. Reinforcement Learning applies a mathematical version of this trial-and-error idea to an agent interacting with an environment.
          </div>
        </div>

        <div>
          The central objective is not simply to maximize the immediate reward. The agent can learn behavior that produces useful rewards over time, which makes reinforcement learning different from ordinary supervised learning.
        </div>
      </div>
    </section>

    <section>
      <h2 className="mb-6 border-l-4 border-pink-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
        10. Parameters, Weights, and Training
      </h2>

      <div className="space-y-5 text-[16px] leading-8 text-slate-300">
        <div>
          One of the most important ideas in Machine Learning is that the model's learned behavior is usually represented numerically. The model does not normally store a readable list of human-written rules.
        </div>

        <div>
          <strong className="text-white">Parameters</strong>, often called <strong className="text-white">weights</strong> in many models, are internal numerical values that can be adjusted during training. Training changes these values so that the model's predictions become more useful according to the learning objective.
        </div>

        <div className="rounded-xl border border-pink-400/20 bg-pink-400/[0.05] p-5">
          <div className="mb-2 font-semibold text-pink-200">Training in one sentence</div>
          <div className="text-slate-400">
            Training repeatedly exposes the model to examples and adjusts its parameters so that its predictions move closer to the desired outcomes.
          </div>
        </div>

        <div>
          This is why it is useful to say that <strong className="text-white">the data writes the rules</strong>. It is a conceptual shortcut: the data and learning algorithm determine the parameter values that define the trained model's behavior.
        </div>
      </div>
    </section>

    <section>
      <h2 className="mb-6 border-l-4 border-cyan-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
        11. Generalization: The Real Goal
      </h2>

      <div className="space-y-5 text-[16px] leading-8 text-slate-300">
        <div>
          A model that performs perfectly on its training examples but poorly on new examples has not solved the real problem. It may have simply memorized patterns specific to the training data.
        </div>

        <div className="grid gap-4 md:grid-cols-2">
          <div className="rounded-xl border border-rose-400/20 bg-rose-400/[0.05] p-5">
            <div className="mb-2 font-semibold text-rose-200">Memorization</div>
            <div className="text-sm leading-relaxed text-slate-400">
              The model performs well on examples it has already seen but struggles when the input changes.
            </div>
          </div>

          <div className="rounded-xl border border-emerald-400/20 bg-emerald-400/[0.05] p-5">
            <div className="mb-2 font-semibold text-emerald-200">Generalization</div>
            <div className="text-sm leading-relaxed text-slate-400">
              The model learns patterns that remain useful when it receives new, unseen examples.
            </div>
          </div>
        </div>

        <div>
          Generalization is therefore one of the most important ideas in Machine Learning. The purpose of training is not merely to remember the dataset; it is to learn a pattern that remains useful beyond it.
        </div>
      </div>
    </section>

    <section>
      <h2 className="mb-6 border-l-4 border-red-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
        12. Data Quality Matters
      </h2>

      <div className="space-y-5 text-[16px] leading-8 text-slate-300">
        <div>
          More data is not automatically better. The examples must also be relevant and useful. If the training examples contain systematic mistakes or bias, the model can learn those patterns too.
        </div>

        <div className="rounded-xl border border-red-400/20 bg-red-400/[0.05] p-5">
          <strong className="text-red-300">A simple rule:</strong> a learning algorithm can only learn from the information it receives. If the examples are incomplete, misleading, or biased, the resulting model can reproduce those problems rather than magically correcting them.
        </div>

        <div>
          This is why "more and better examples usually beat cleverer hand-written rules" is useful as a learning principle, but the word <strong className="text-white">better</strong> matters. Data quality, relevance, and representation are critical parts of a Machine Learning system.
        </div>
      </div>
    </section>

    <section>
      <h2 className="mb-6 border-l-4 border-slate-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
        13. Traditional Programming vs Machine Learning
      </h2>

      <div className="space-y-6 text-[16px] leading-8 text-slate-300">
        <div className="my-6 grid gap-5 md:grid-cols-2">
          <div className="rounded-xl border border-slate-700/50 bg-slate-800/20 p-6">
            <div className="mb-4 text-lg font-bold text-white">Traditional Programming</div>
            <ul className="space-y-3 text-sm leading-relaxed text-slate-400">
              <li>● You write the rules.</li>
              <li>● Rules + data go in.</li>
              <li>● Answers come out.</li>
              <li>● New cases may require new rules.</li>
              <li>● The logic is explicitly written by a programmer.</li>
            </ul>
          </div>

          <div className="rounded-xl border border-blue-400/20 bg-blue-400/[0.06] p-6">
            <div className="mb-4 text-lg font-bold text-blue-200">Machine Learning</div>
            <ul className="space-y-3 text-sm leading-relaxed text-slate-300">
              <li>● The learning process discovers the rules.</li>
              <li>● Data + answers go in for supervised learning.</li>
              <li>● A trained model comes out.</li>
              <li>● The model can handle patterns not explicitly listed as rules.</li>
              <li>● Learned behavior is represented mainly through parameters.</li>
            </ul>
          </div>
        </div>

        <div className="my-8 overflow-x-auto rounded-2xl border border-white/10">
          <table className="w-full min-w-[700px] border-collapse text-left text-sm">
            <thead className="bg-white/[0.06] text-white">
              <tr>
                <th className="border-b border-white/10 px-5 py-4 font-semibold">Question</th>
                <th className="border-b border-white/10 px-5 py-4 font-semibold">Traditional Programming</th>
                <th className="border-b border-white/10 px-5 py-4 font-semibold">Machine Learning</th>
              </tr>
            </thead>
            <tbody className="text-slate-300">
              <tr className="border-b border-white/10">
                <td className="px-5 py-4 font-semibold text-white">Who defines the rules?</td>
                <td className="px-5 py-4">Programmer</td>
                <td className="px-5 py-4">Learning algorithm + data determine learned parameters</td>
              </tr>
              <tr className="border-b border-white/10">
                <td className="px-5 py-4 font-semibold text-white">What is provided?</td>
                <td className="px-5 py-4">Rules and data</td>
                <td className="px-5 py-4">Data and, depending on the learning setting, labels or rewards</td>
              </tr>
              <tr>
                <td className="px-5 py-4 font-semibold text-white">What is produced?</td>
                <td className="px-5 py-4">Answers</td>
                <td className="px-5 py-4">A trained model that can produce predictions</td>
              </tr>
            </tbody>
          </table>
        </div>
      </div>
    </section>

    <section>
      <h2 className="mb-6 border-l-4 border-orange-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
        14. When Should You Use Machine Learning?
      </h2>

      <div className="space-y-5 text-[16px] leading-8 text-slate-300">
        <div>
          Machine Learning is not automatically the correct solution to every programming problem. If a task can be solved reliably with a few clear rules, traditional programming may be simpler and easier to maintain.
        </div>

        <div className="grid gap-4 md:grid-cols-2">
          <div className="rounded-xl border border-emerald-400/20 bg-emerald-400/[0.05] p-5">
            <div className="mb-3 font-semibold text-emerald-200">Machine Learning can make sense when...</div>
            <ul className="space-y-2 text-sm leading-relaxed text-slate-400">
              <li>● The rules are too numerous or difficult to specify.</li>
              <li>● Useful historical examples are available.</li>
              <li>● The problem contains patterns that can be learned from data.</li>
              <li>● New variations are expected after deployment.</li>
            </ul>
          </div>

          <div className="rounded-xl border border-slate-700/50 bg-slate-800/20 p-5">
            <div className="mb-3 font-semibold text-slate-200">Traditional programming can make sense when...</div>
            <ul className="space-y-2 text-sm leading-relaxed text-slate-400">
              <li>● The rules are simple and explicit.</li>
              <li>● There is little or no useful training data.</li>
              <li>● The behavior must exactly follow a known specification.</li>
              <li>● A learning system would add unnecessary complexity.</li>
            </ul>
          </div>
        </div>
      </div>
    </section>

    <section>
      <h2 className="mb-6 border-l-4 border-yellow-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
        15. Key Points
      </h2>

      <div className="space-y-4 text-[16px] leading-8 text-slate-300">
        <div className="rounded-xl border border-white/10 bg-white/[0.03] p-5">
          <ul className="space-y-3">
            <li><strong className="text-emerald-400">✓</strong> Machine Learning is useful when explicit rules are impractical to write.</li>
            <li><strong className="text-emerald-400">✓</strong> Traditional programming uses rules written by a programmer; Machine Learning learns parameterized behavior from data.</li>
            <li><strong className="text-emerald-400">✓</strong> Supervised learning learns from labeled examples.</li>
            <li><strong className="text-emerald-400">✓</strong> Unsupervised learning searches for structure without supplied labels.</li>
            <li><strong className="text-emerald-400">✓</strong> Reinforcement learning learns through actions, consequences, and rewards.</li>
            <li><strong className="text-emerald-400">✓</strong> Features are measurable inputs used by a model to make predictions.</li>
            <li><strong className="text-emerald-400">✓</strong> Labels are the known answers in supervised learning.</li>
            <li><strong className="text-emerald-400">✓</strong> Parameters or weights are numerical values adjusted during training.</li>
            <li><strong className="text-emerald-400">✓</strong> Generalization to unseen data is more important than simply memorizing training examples.</li>
            <li><strong className="text-emerald-400">✓</strong> More and better examples can improve learning, but poor or biased data can teach poor or biased patterns.</li>
          </ul>
        </div>
      </div>
    </section>

    <section>
      <h2 className="mb-6 border-l-4 border-red-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
        16. Common Mistakes
      </h2>

      <div className="space-y-4 text-[16px] leading-8 text-slate-300">
        <div className="rounded-xl border border-red-500/20 bg-red-500/[0.05] p-5">
          <ul className="space-y-4">
            <li>
              <strong className="text-red-400">✕ Assuming Machine Learning always needs labels.</strong>
              <div className="mt-1 text-sm text-slate-400">Labels are central to supervised learning, but unsupervised learning works without supplied labels, while reinforcement learning uses reward-based feedback.</div>
            </li>
            <li>
              <strong className="text-red-400">✕ Treating a trained model as if it understands human-readable rules.</strong>
              <div className="mt-1 text-sm text-slate-400">The learned behavior is generally represented through mathematical parameters and computations rather than a list of readable if-then statements.</div>
            </li>
            <li>
              <strong className="text-red-400">✕ Using Machine Learning for every problem.</strong>
              <div className="mt-1 text-sm text-slate-400">A small set of deterministic rules can be the better engineering choice when the problem is simple and well specified.</div>
            </li>
            <li>
              <strong className="text-red-400">✕ Judging a model only on training data.</strong>
              <div className="mt-1 text-sm text-slate-400">A model should be evaluated on new examples because generalization is the actual goal.</div>
            </li>
            <li>
              <strong className="text-red-400">✕ Assuming more data automatically means a better model.</strong>
              <div className="mt-1 text-sm text-slate-400">The quality and relevance of examples matter. Poor or biased examples can teach the model poor or biased patterns.</div>
            </li>
          </ul>
        </div>
      </div>
    </section>

    <section>
      <h2 className="mb-6 border-l-4 border-pink-500 pl-4 text-2xl font-bold tracking-tight text-white sm:text-3xl">
        17. Interactive Knowledge Check
      </h2>

      <div className="space-y-6 text-[16px] leading-8 text-slate-300">

        {/* Quiz 1 */}
        <div className="rounded-xl border border-white/10 bg-slate-900/50 p-6">
          <div className="font-bold text-pink-400 mb-4">Quiz 1: The Core Difference</div>
          <p className="text-white mb-6">If you want to build a program that filters out spam emails, why can Machine Learning be useful compared with Traditional Programming?</p>

          <div className="grid gap-4 md:grid-cols-2">
            <details className="group">
              <summary className="flex cursor-pointer items-center justify-between rounded-lg border border-white/10 bg-white/[0.03] px-4 py-3 font-semibold text-slate-300 transition-colors hover:bg-white/[0.06] marker:content-['']">
                <span>A) ML writes faster "if-then" rules.</span>
                <span className="transition group-open:rotate-180 text-pink-400">▼</span>
              </summary>
              <div className="mt-3 rounded-lg border border-rose-500/30 bg-rose-500/10 p-4 text-sm leading-relaxed text-slate-300">
                <strong className="mb-2 block text-rose-400">Incorrect.</strong>
                Machine Learning does not simply generate a readable collection of "if-then" statements. Traditional programming would require humans to manually specify rules such as <em>"If email contains 'Free Money', mark as spam."</em> Spammers can change wording and create cases that the rule did not cover.
              </div>
            </details>

            <details className="group">
              <summary className="flex cursor-pointer items-center justify-between rounded-lg border border-white/10 bg-white/[0.03] px-4 py-3 font-semibold text-slate-300 transition-colors hover:bg-white/[0.06] marker:content-['']">
                <span>B) ML can learn patterns from many examples.</span>
                <span className="transition group-open:rotate-180 text-pink-400">▼</span>
              </summary>
              <div className="mt-3 rounded-lg border border-emerald-500/30 bg-emerald-500/10 p-4 text-sm leading-relaxed text-slate-300">
                <strong className="mb-2 block text-emerald-400">Correct!</strong>
                By learning from many examples of spam and normal emails, a supervised model can learn statistical patterns that help it classify new messages without requiring a human to manually write a rule for every possible variation.
              </div>
            </details>
          </div>
        </div>

        {/* Quiz 2 */}
        <div className="rounded-xl border border-white/10 bg-slate-900/50 p-6">
          <div className="font-bold text-pink-400 mb-4">Quiz 2: Dataset Anatomy</div>
          <p className="text-white mb-6">You are analyzing a spreadsheet of cars to predict their top speed. The columns are: <em>Weight</em>, <em>Horsepower</em>, and <em>Top Speed</em>. Which of these are the Features ($X$)?</p>

          <div className="grid gap-4 md:grid-cols-2">
            <details className="group">
              <summary className="flex cursor-pointer items-center justify-between rounded-lg border border-white/10 bg-white/[0.03] px-4 py-3 font-semibold text-slate-300 transition-colors hover:bg-white/[0.06] marker:content-['']">
                <span>A) Weight and Horsepower</span>

                <strong className="mb-2 block text-emerald-400">Correct!</strong>
                Features are the independent input variables the model analyzes. Here, Weight and Horsepower are the inputs used to predict the final answer. <em>Top Speed</em> is the Label or Target ($y$).
              </div>
            </details>

            <details className="group">
              <summary className="flex cursor-pointer items-center justify-between rounded-lg border border-white/10 bg-white/[0.03] px-4 py-3 font-semibold text-slate-300 transition-colors hover:bg-white/[0.06] marker:content-['']">
                <span>B) Top Speed</span>
                <span className="transition group-open:rotate-180 text-pink-400">▼</span>
              </summary>
              <div className="mt-3 rounded-lg border border-rose-500/30 bg-rose-500/10 p-4 text-sm leading-relaxed text-slate-300">
                <strong className="mb-2 block text-rose-400">Incorrect.</strong>
                Top Speed is the final answer you want the model to predict. In this supervised learning example, it is the Label or Target ($y$), not a Feature.
              </div>
            </details>
          </div>
        </div>

        {/* Quiz 3 */}
        <div className="rounded-xl border border-white/10 bg-slate-900/50 p-6">
          <div className="font-bold text-pink-400 mb-4">Quiz 3: Learning Type</div>
          <p className="text-white mb-6">A company gives an algorithm customer data without predefined customer groups and asks it to discover similar groups. Which learning setting matches this description?</p>

          <div className="grid gap-4 md:grid-cols-2">
            <details className="group">
              <summary className="flex cursor-pointer items-center justify-between rounded-lg border border-white/10 bg-white/[0.03] px-4 py-3 font-semibold text-slate-300 transition-colors hover:bg-white/[0.06] marker:content-['']">
                <span>A) Unsupervised Learning</span>
                <span className="transition group-open:rotate-180 text-pink-400">▼</span>
              </summary>
              <div className="mt-3 rounded-lg border border-emerald-500/30 bg-emerald-500/10 p-4 text-sm leading-relaxed text-slate-300">
                <strong className="mb-2 block text-emerald-400">Correct!</strong>
                No predefined labels are supplied. The goal is to discover structure or groupings within the data, which is the central idea of unsupervised learning.
              </div>
            </details>

            <details className="group">
              <summary className="flex cursor-pointer items-center justify-between rounded-lg border border-white/10 bg-white/[0.03] px-4 py-3 font-semibold text-slate-300 transition-colors hover:bg-white/[0.06] marker:content-['']">
                <span>B) Supervised Learning</span>
                <span className="transition group-open:rotate-180 text-pink-400">▼</span>
              </summary>
              <div className="mt-3 rounded-lg border border-rose-500/30 bg-rose-500/10 p-4 text-sm leading-relaxed text-slate-300">
                <strong className="mb-2 block text-rose-400">Incorrect.</strong>
                Supervised learning requires known target answers for its training examples. In this case, the groups are not provided in advance; they are being discovered.
              </div>
            </details>
          </div>
        </div>

        {/* Quiz 4 */}
        <div className="rounded-xl border border-white/10 bg-slate-900/50 p-6">
          <div className="font-bold text-pink-400 mb-4">Quiz 4: Generalization</div>
          <p className="text-white mb-6">A model performs extremely well on its training examples but poorly on new examples. What does this tell you?</p>

          <div className="grid gap-4 md:grid-cols-2">
            <details className="group">
              <summary className="flex cursor-pointer items-center justify-between rounded-lg border border-white/10 bg-white/[0.03] px-4 py-3 font-semibold text-slate-300 transition-colors hover:bg-white/[0.06] marker:content-['']">
                <span>A) Training performance alone is not enough.</span>
                <span className="transition group-open:rotate-180 text-pink-400">▼</span>
              </summary>
              <div className="mt-3 rounded-lg border border-emerald-500/30 bg-emerald-500/10 p-4 text-sm leading-relaxed text-slate-300">
                <strong className="mb-2 block text-emerald-400">Correct!</strong>
                The model needs to perform well on unseen examples. Strong training performance with weak performance on new data indicates poor generalization and may mean the model has learned patterns that are too specific to its training examples.
              </div>
            </details>

            <details className="group">
              <summary className="flex cursor-pointer items-center justify-between rounded-lg border border-white/10 bg-white/[0.03] px-4 py-3 font-semibold text-slate-300 transition-colors hover:bg-white/[0.06] marker:content-['']">
                <span>B) The model is automatically ready for deployment.</span>
                <span className="transition group-open:rotate-180 text-pink-400">▼</span>
              </summary>
              <div className="mt-3 rounded-lg border border-rose-500/30 bg-rose-500/10 p-4 text-sm leading-relaxed text-slate-300">
                <strong className="mb-2 block text-rose-400">Incorrect.</strong>
                Training performance does not demonstrate that the model will work on new data. Generalization must be considered separately.
              </div>
            </details>
          </div>
        </div>

      </div>
    </section>

        18. The Big Picture
      </h2>

        <div className="rounded-xl border border-cyan-500/20 bg-cyan-500/[0.05] p-6">
          <div className="mb-3 text-lg font-bold text-cyan-300">Traditional programming</div>
          <div className="text-center text-slate-400">
            <strong className="text-white">Rules + Data → Answers</strong>
          </div>
        </div>

        <div className="rounded-xl border border-blue-500/20 bg-blue-500/[0.05] p-6">
          <div className="mb-3 text-lg font-bold text-blue-300">Supervised Machine Learning</div>
          <div className="text-center text-slate-400">
            <strong className="text-white">Data + Answers → Learned Model → Predictions</strong>
          </div>
        </div>

        <div>
          The important conceptual shift is that the programmer is no longer required to manually describe every pattern. Instead, the programmer creates a learning setup in which data can be used to discover a parameterized model. The quality of that model is ultimately judged by how well it generalizes to new examples.
        </div>

        <div className="rounded-xl border border-white/10 bg-white/[0.03] p-5">
          <strong className="text-white">Remember:</strong> Machine Learning is not magic and it is not simply "letting a computer think." It is a mathematical approach to learning useful patterns from data, represented through a model whose parameters are adjusted during training.
        </div>
      </div>
