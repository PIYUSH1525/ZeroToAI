    </h2>
    <div className="space-y-6 text-[16px] leading-8 text-slate-300">
      <div>
        When beginners first use Matplotlib, they often get confused because there are two ways to write code: the quick way (<code>plt.plot()</code>) and the professional way (<code>fig, ax = plt.subplots()</code>). Understanding one simple picture makes everything click:
      </div>
      <div className="grid gap-5 md:grid-cols-2">
        <div className="rounded-xl border border-blue-500/25 bg-blue-500/[0.04] p-6">
          <div className="mb-1 flex items-center justify-between">
            <span className="font-bold text-blue-300">1. The Figure (fig) — The Blank Page</span>
            <span className="rounded bg-blue-950/80 px-2 py-0.5 font-mono text-xs text-blue-300">Outer Container</span>
          </div>
          <div className="mb-4 text-xs leading-relaxed text-slate-300">
            Think of <code>fig</code> as the <strong className="text-white">entire picture frame or blank window</strong>. It controls the overall image size (e.g., <code>figsize=(10, 5)</code>), background color, and saving the final image to a file (<code>fig.savefig(&quot;chart.png&quot;)</code>).
          </div>
          <div className="rounded-lg bg-slate-950 p-3 font-mono text-xs text-slate-200">
            Controls: Window size, DPI resolution, and saving files.

          <div className="mb-1 flex items-center justify-between">

            <span className="rounded bg-violet-950/80 px-2 py-0.5 font-mono text-xs text-violet-300">Drawing Area</span>
          </div>
          <div className="mb-4 text-xs leading-relaxed text-slate-300">
            Think of <code>ax</code> as an <strong className="text-white">individual chart drawn inside the frame</strong> (with its own X-axis, Y-axis, title, and lines). One Figure can hold $1$ chart or a grid of $6$ charts side by side!
          </div>
          <div className="rounded-lg bg-slate-950 p-3 font-mono text-xs text-slate-200">
            Controls: ax.plot(), ax.scatter(), ax.set_title(), ax.legend()
          </div>
        </div>
      </div>
      <div className="rounded-xl border border-white/10 bg-white/[0.03] p-5">
        <strong className="text-white">Why You Should Always Use <code>fig, ax = plt.subplots()</code>:</strong> Calling <code>plt.plot()</code> guesses which chart you want to draw on, which gets messy as soon as you have two charts on the same screen. Starting every plot with <code>fig, ax = plt.subplots()</code> gives you direct, predictable control over every chart!

      Common Mistakes
    </h2>
    <div className="rounded-2xl border border-rose-500/25 bg-rose-950/[0.15] p-6 sm:p-8">
      <div className="space-y-6">
        <div>
          <div className="mb-1.5 font-bold text-rose-400">
            ✕ Passing a PyTorch GPU tensor with requires_grad=True directly into Matplotlib.
          </div>
          <div className="text-sm leading-relaxed text-slate-300">
            Matplotlib only understands CPU NumPy arrays. Passing a GPU or autograd tensor crashes with a <code>RuntimeError</code>. Always call <code>tensor.detach().cpu().numpy()</code> before plotting.
          </div>
        </div>
        <div>
          <div className="mb-1.5 font-bold text-rose-400">
            ✕ Plotting RGB images with Channels-First shape (3, H, W) instead of (H, W, 3).
          </div>
          <div className="text-sm leading-relaxed text-slate-300">
            PyTorch stores color channels in axis $0$, whereas <code>ax.imshow()</code> requires color channels in the last axis. Reorder axes with <code>img.permute(1, 2, 0)</code> or <code>np.transpose(img, (1, 2, 0))</code>.
          </div>
        </div>
        <div>
          <div className="mb-1.5 font-bold text-rose-400">
            ✕ Creating hundreds of figures inside a training loop without calling plt.close(fig).
          </div>
          <div className="text-sm leading-relaxed text-slate-300">
            Matplotlib retains references to every created Figure in memory until explicitly closed, which will steadily eat gigabytes of RAM during long training runs.
          </div>
        </div>
        <div>
          <div className="mb-1.5 font-bold text-rose-400">
            ✕ Calling fig.savefig() AFTER calling plt.show(), resulting in a blank white image file.
          </div>
          <div className="text-sm leading-relaxed text-slate-300">
            <code>plt.show()</code> displays and then clears the active figure canvas. Always call <code>fig.savefig(&quot;chart.png&quot;)</code> <em>before</em> calling <code>plt.show()</code>.
          </div>
        </div>
      </div>
